# 潜雪僵尸实现计划

1. 在尾部追加 `ZombieType` 与 `AnimationType`，登记独立 reanim 键、工厂、数据表名称、开发者菜单和 AutoTest 名称。
2. 新建 `SnowBurrowZombie`，实现首次潜雪、自然/强制出雪、半血前摇、提交后再潜雪、啃食/死亡/魅惑/断肢与存档修复。
3. 在 `Zombie` 增加地面能力强制出雪虚接口，并让地刺在真实伤害命中后调用；普通品种保持无操作。
4. 为 Board 增加潜雪僵尸每波与同时上限、8-1 雪穴保底事务及其存档字段；8-1 使用 1/1，8-2 使用 2/2。
5. 扩展第八大关进度和 8-1/8-2 出怪表；植物奖励暂用 `NO_PLANT_REWARD`，等待植物单独实现。
6. 从矿工时间线机械派生 `SnowBurrow.reanim`，生成蓝灰雪地分件与宽雪铲；新增雪尘、出雪、冲击、掉头和掉臂粒子并完成资源注册闭环。
7. 扩展 AutoTest 状态投影与控制命令，覆盖资源键、首次距离、植物截停、150 冲击、南瓜保护、地刺强制出雪、半血前摇中断/重试、硬控暂停、提交清慢、第二次距离、关卡限额和存档恢复。
8. 用 `clang-release` 构建并在桌面可见运行最小专项，检查退出码、`run.log`、状态 JSON 和同步截图。
9. 审计并更新 adding-zombie、adding-particle 与 adapting-classic-reanimation 的可复用契约，运行 skill-creator 校验；同步项目记忆后提交并在上游明确且可快进时推送。
