# 避雷花盆实施计划

1. 在植物/动画枚举末尾追加稳定 ID，登记 6-4 奖励、150/50/700 数据和图鉴文案。
2. 扩展升级规则为 `NORMAL/UNDER` 层，令避雷花盆原位替换花盆并保留全部上层。
3. 以花盆派生类实现承载、同格雷荷/处决保护、同排 2 倍倍率和无帧事件放电反馈。
4. 在 Board 两个结算边沿使用同格 O(1) 查询；放电时固定列扫描取最大倍率，多盆不叠加。
5. 用 imagegen 制作精细本体，确定性导出战场/卡图、紫电光层和 reanim，闭合资源注册。
6. 增加稳定分层 AutoTest 投影、专项与奖励脚本；构建并在默认/`-NoInstance` 可见路径验收。
7. 更新项目记忆与相关植物/雨天气技能，运行 `quick_validate.py`，最后审计并提交。
