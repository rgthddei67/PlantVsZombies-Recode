# 冰墙工程师实现计划

1. 追加稳定僵尸枚举并注册复用路障时间轴的 `IceWallEngineerZombie`；独立工程帽资源覆盖三阶段破损与掉落反馈。
2. 新增 Board 寻址、GameObjectManager 持有的唯一 `IceWall`，实现 600 生命未完成态、1800 生命硬化态、三档绘制、向房屋移动、植物前挡停、回暖融化、销毁和正式存档。
3. 工程师完全进入草坪后立即原子部署施工墙，再用逻辑计时施工且不新增帧事件；实现墙体被拆、魅惑/掉头/断头/死亡中断、原对象硬化及双方扩展存档。
4. 在 `Bullet` 平射移动后加入 O(1) 冰墙线段命中入口，保证墙优先于同行僵尸；火豆使用 2 倍墙伤，投手保持越墙。
5. 让融雪投手持有盐晶时把同行冰墙作为优先目标，并在盐晶落点对墙结算 20 普通伤害和 200 独立腐蚀。
6. 用可复现 PowerShell 脚本生成工程帽、冰墙三档和粒子图集，注册 `manifest.txt`、`resources.xml`、ResourceKeys 与粒子配置。
7. 把工程师接入 7-3、7-4、7-5、7-8、7-9，并给正式波次增加每波一只的可保存上限。
8. 扩展 AutoTest 命令与状态投影，新增专项脚本覆盖远离霜线开工、未完成墙挡弹/随施工者碎裂、硬化、资源、存档、出怪和默认/`-NoInstance` 可见表现。
9. 使用 `clang-debug` 做增量诊断；完成后整体构建 `clang-release`，运行 SaveSchemaTests、专项和受影响的寒潮/融雪投手/子弹回归。
10. 更新项目记忆，审计并校验本次使用的僵尸与粒子技能，提交后常规推送到 `origin/master`。
