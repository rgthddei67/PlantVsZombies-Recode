# 蹦极僵尸实现计划

1. 扩展共享蒙特卡洛候选效果，支持对指定植物的单体移除，并抽取 Board 快照构建逻辑供范围攻击与蹦极共同复用。
2. 为植物基类加入可逆的蹦极抓取/升空关系、暂停行为、碰撞门禁和夹层绘制入口。
3. 新增 `BungeeZombie` 状态机、原版随机与 AI 目标分流、绳索/靶标/前臂夹层绘制、伤害门禁和存档恢复。
4. 注册僵尸枚举、工厂、动画、数值、图鉴及原版图片/音效资源；不接入 5-5 特殊编排。
5. 扩充 AutoTest 状态与断言，完成 `clang-release` 构建和可见运行，检查退出码、日志、状态 JSON 与截图。
6. 审计并更新相关技能和仓库记忆，校验技能后提交；仓库状态与上游允许时推送。
