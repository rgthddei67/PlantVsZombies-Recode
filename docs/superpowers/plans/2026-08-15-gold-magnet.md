# 6-7 磁暴菇实施计划

> 对应规格：`docs/superpowers/specs/2026-08-15-gold-magnet-design.md`

## Task 1：复用磁力菇状态机

1. 将 `MagnetShroom` 改为可派生，暴露充能时长和成功剥离钩子。
2. 僵尸装备路径在接管离体物后调用钩子；场景扶梯路径不调用。
3. `GoldMagnet` 覆写12秒充能和100px/2.5秒EMP，使用行桶和正式 `ApplyParalysis`。

## Task 2：注册、升级与奖励

1. 注册现有 `PLANT_GOLD_MAGNET`、动画类型、资源键和工厂。
2. 在升级规则中把磁暴菇映射到磁力菇的 normal 层原位升级。
3. 配置75阳光、50秒卡冷却、300生命和12秒/100px/2.5秒的条件磁吸脉冲画像。
4. 将内部52登记为6-7植物奖励，并补图鉴文案。

## Task 3：动画与EMP资源

1. 从本地经典资源副本导入并记录 `GoldMagnet.reanim` 的 SHA-256，不新增帧事件。
2. 新增 `GoldMagnetEMP.xml`，使用预加载的圆环/星点粒子并显式设置回收时长。
3. 闭合 manifest、resources.xml、ResourceKeys和运行时资源断言。

## Task 4：测试与交付

1. 扩展通用Monte Carlo快照与事件，模拟合法磁性目标、护甲层消费、当前充能和EMP范围，不按植物类型分支。
2. 新增核心/推演/奖励/NoInstance AutoTest，覆盖规格交互和正式存档往返。
3. `clang-release` 构建并在当前桌面可见运行最小专项及磁力菇、接地僵尸、绝缘僵尸回归。
4. 逐张检查真实屋顶花盆合成、昼眠和EMP截图，必要时只调资源坐标与粒子数值；最终锁定世界包围盒相对同格逻辑中心。
5. 审计并更新植物/粒子技能和项目记忆，运行技能校验，提交并在安全时推送。
