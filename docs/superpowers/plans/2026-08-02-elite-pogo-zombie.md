# 精英跳跳僵尸实施计划

1. 让 `PogoZombie` 提供阻拦结算、受损贴图与断杆粒子的窄虚入口，保持普通路径默认行为。
2. 新增 `ElitePogoZombie`，复用父类 Setup/帧事件/四阶段状态机并保存一次性缓冲器状态。
3. 追加僵尸与动画枚举、工厂、资源键、开发者表和 AutoTest 名称表。
4. 用哈希锁定脚本生成独立服装、跳杆、受损资源、reanim 与断杆粒子贴图。
5. 注册 reanim/粒子纹理/粒子 XML，补 gamedata、图鉴文本和 4-9 出怪表。
6. 在 Board 正式波次解析器加入每波 1 只上限，并保存/恢复/重置计数。
7. 补精英行为、上限、4-7～4-9 出怪、选卡/图鉴弹跳预览与图鉴边界 AutoTest，并扩充只读状态投影。
8. 默认 `clang-release` 配置构建，在主人当前桌面可见运行最小相关回归并检查截图、状态、日志和退出码。
9. 更新项目记忆，审计并校验本次使用的 zombie/particle 技能，提交后按仓库状态决定 push。
