# 适应头盔僵尸实现计划

1. 新增 `PlantDamageOrigin`，以现有紫卡基础株映射规范化植物谱系，并把原发射植物身份贯通 `Board::CreateBullet`、`Bullet` 对象池、命中入口和 `GameInfoSaver`。
2. 审计当前全部植物数值伤害入口：弹丸、直伤、范围/溅射、灰烬、寒冰菇固定伤害、窝瓜和延迟状态伤害；每条显式传玩家语义来源，保留非植物来源的中性默认值。
3. 在 `Zombie::TakeDamage` 增加来源感知的窄虚钩子，保持既有倍率、额外层、护盾、头盔、本体和白光顺序；由 `AdaptiveHelmetZombie` 原子完成免疫或等血碎甲且禁止溢出。
4. 注册 `ZOMBIE_ADAPTIVE_HELMET`，复用普通僵尸 reanim 和帧事件；实现 800 本体、100 头盔、不可磁吸、不可魅惑、普通断肢/断头，以及适应槽存档。
5. 制作并注册静态头盔、熄灭胸徽和冷蓝点亮胸徽资源；用命名 follower 跟随 `anim_head1` 与 `Zombie_body`，覆盖破甲、死亡和读档终态。
6. 在 Board 唯一正式波次 resolver 中实现 8-3/8-4 每波最多 4 只且不设同时或累计上限；首轮白毛风结束后保证 8-3 首次独立投放。追加 8-3/8-4 权威出怪表，保持现有 8-1/8-2 用户修改。
7. 扩展 AutoTest 命令与状态投影，新增 `smoke_adaptive_helmet_zombie.json` 和关卡编排专项；更新项目记忆及本次实际暴露的技能契约。
8. 使用 `clang-release` 构建，从 `build/clang-release` 在主人桌面可见运行专项，检查退出码、日志、状态、资源键和同步截图；通过后只提交任务文件并普通推送到明确上游。
