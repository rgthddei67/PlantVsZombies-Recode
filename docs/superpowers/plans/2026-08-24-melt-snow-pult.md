# 融雪投手实现计划

1. 追加稳定植物、动画和双弹型枚举，注册 `MeltSnowPult` 工厂、卡图、reanim、gamedata、图鉴与 7-2 奖励。
2. 实现复用卷心菜投手时间线的独立植物状态机；攻击起手锁定弹型，第 43 帧创建解析抛物线并保存完整周期/库存/pending 状态。
3. 给 Board 增加可保存的本轮寒潮预报干扰状态和唯一语义入口；植物基类提供默认 no-op 通知，融雪投手清理库存与未发射 pending。
4. 扩展通用 `Bullet` / `BulletPool` 支持融雪弹与盐弹，补纹理、命中粒子、落空反馈、存档名称和 AutoTest 聚合。
5. 给 `Zombie` 增加默认无效、不可溢出本体的 `ApplyWinterCorrosion` 虚入口；当前普通僵尸作为中性对照，未来冰制装备品种自行覆写。
6. 用可复现脚本生成冷蓝投手部件、卡图、双弹贴图和粒子图集；注册资源并断言实际键可取。
7. 增加预报/干扰测试夹具、植物状态投影和 `smoke_melt_snow_pult.json`，覆盖资源、数值、奖励、装填、攻击、干扰、快照、对象池以及默认/`-NoInstance` 可见表现。
8. `clang-debug` 迭代构建和最小诊断后，整体 `clang-release` 构建并从发布目录可见运行专项及受影响的寒潮/卷心菜/子弹回归。
9. 更新项目记忆与本次使用的植物、粒子、僵尸技能，运行 skill-creator 校验，审计 Git 范围后提交并常规 push。
