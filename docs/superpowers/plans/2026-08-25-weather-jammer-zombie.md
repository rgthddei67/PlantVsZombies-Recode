# 气象干扰僵尸实现计划

1. 在 `ZombieType` 哨兵前追加稳定枚举，注册复用 `BucketZombie` 时间轴的 `WeatherJammerZombie`，补齐 gamedata、开发者面板、AutoTest 名称表和图鉴文本。
2. 为 Board 增加 30 游戏秒整栏黑障计时，以及雨雪/台风、雾势与寒潮三类公开预报的代际干扰状态；主动截获窗口中新广播，保持真实锁定计划不变，并让 UI 只显示统一干扰文案、被干扰揭晓不触发失败提示。
3. 实现 `READY/CHANNELING/REBOOTING/SPENT` 状态机、施法优先于啃食、4 秒减速计时、5 秒重启、通用动作中断以及死亡/断臂/断头/魅惑的原子终止与存档修复。
4. 继续继承标准 270 本体与 1100 铁桶，保留铁桶破损、掉落和磁力菇吸取；设备不承担生命且失去铁桶后仍可施法。
5. 使用非写实、夸张手绘卡通透明母图制作箱式气象欺骗台、雷达盘和手持终端；用确定性 PowerShell 脚本生成最终资源与设备 reanim，并闭合 `resources.xml`、ResourceKeys、manifest 与加载断言。
6. 给正式 resolver 增加每波一只且可保存的上限，在 7-6 第 3 波增加额外保底，并按定案精简 7-6、接入 7-8/7-9；保持 7-7 留白。
7. 扩展 AutoTest 命令和状态投影，新增专项覆盖无预报主动施法、30 秒窗口、窗口内新广播截获、同类排队、全栏目实况隐藏、真实计划不变、雨雪/台风/雾势/寒潮代际恢复、啃食优先级、减速/硬控、中断重启、铁桶磁吸、断肢魅惑、双方存档、正式上限和 7-6 保底。
8. 使用 `clang-release` 构建，按当前桌面可见方式运行专项、天气预报/雾势/融雪投手/伏霜雷、铁桶磁吸、存档和冒险出怪回归；检查退出码、`run.log`、状态 JSON及默认实例化/`-NoInstance` 同步截图。
9. 更新冬日花园内容、天气和气象干扰僵尸项目记忆，审计并完善本次使用的僵尸、天气与图片生成技能；校验改动过的仓库技能后提交，并在工作区范围和上游状态允许时常规推送。
