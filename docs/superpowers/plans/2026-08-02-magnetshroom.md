# 磁力菇实施计划

1. 为僵尸基类增加目标资格与磁性装备剥离虚接口，并在六类装备僵尸及变体中返回当前装备贴图、起飞位置和植物侧目标偏移。
2. 实现 `MagnetShroom` 的搜索、吸取、飞行动画、15 秒充能、绘制和存档恢复。
3. 注册植物类型、动画、卡片、声音及所有磁吸装备资源键，补充游戏数据和图鉴文本。
4. 扩展 TestDriver 的磁力菇/磁性装备状态导出与资源断言，添加最小确定性 AutoTest 脚本。
5. 使用 `clang-release` 配置、构建并在当前桌面可见运行测试；核对日志、状态文件与截图。
6. 根据最终源码更新项目记忆，审计植物/僵尸技能中的可复用装备剥离契约，验证后提交并按仓库状态决定推送。
