# 接地僵尸实施计划

> 对应规格：`docs/superpowers/specs/2026-08-15-grounding-zombie-design.md`

## Task 1：通用控制免疫框架

1. 在 `Zombie` 基类增加独立控制类型、按类型计时、位掩码发放/查询和未来永久免疫虚接口。
2. 把冻结、黄油、麻痹、减速入口接入统一门禁，保持伤害与减速尾巴语义。
3. 实现发放时清除已有硬控、逐帧计时与实体存读档；强化不依赖护具是否仍在。
4. 在 AutoTest 状态投影导出四类免控剩余时间及有效掩码。

## Task 2：接地僵尸与电紫天线路障

1. 在枚举尾部追加 `ZOMBIE_GROUNDING`，注册工厂、动画类型、reanim 键、图鉴和开发者生成表。
2. 实现 `GroundingZombie : ConeZombie`，保留 270 本体、50 啃咬和普通速度，把路障生命改为 1200。
3. 为 `ConeZombie` 提取窄的护具图片和掉落效果虚接口；接地僵尸复用三阶段护具、掉落和现有动画帧事件。
4. 暴露“天线是否存在”和天线视觉锚点；路障掉落后失去未来引雷资格。

## Task 3：稀有候选索引与 Board 锁定

1. 在 `EntityManager` 增加按 ID 有序的通用引雷候选弱索引，接入正常生成、指定 ID 恢复和周期清理。
2. 满电预警开始时构造全部普通行候选和按稳定 ID 收集的接地引导候选；开启轻量蒙特卡洛时，用独立 32 次 rollout、10 秒时域统一比较普通友伤、延迟行停机、引导免伤与强化效果。
3. 关闭或推演失败时，有接地候选则正式 RNG 均匀选一只引导，否则沿用随机行；蒙特卡洛并列只用局部 seeded RNG。
4. Board 保存本轮受引导、选中实体 ID、选择模式、统计与行；死亡、换行、掉路障和后来生成都不重抽。
5. 存档恢复只修复实体引用，不改变已公开的行和受引导结果。

## Task 4：植物专属放电与 30 秒编队强化

1. 受引导放电沿用既有目标行植物停机与保护规则，跳过全部僵尸伤害/麻痹。
2. 放电瞬间若锁定实体仍有效且天线路障仍在，以其碰撞箱中心为圆心，向 130 像素内同阵营活动僵尸发放 30 秒 `SLOW | FROZEN | BUTTER` 免疫并清除对应已有控制。
3. 发放后强化分别跟随受益僵尸本体计时；后续路障掉落、引雷者死亡或目标离开范围不取消剩余时间，麻痹、灰烬和普通伤害仍有效。
4. 放电结束重置本轮锁定字段，为下次满电重新选择。

## Task 5：资产、注册与小型引雷动画

1. 新增可复现资源脚本，把普通路障三阶段确定性变为电紫色并绘制铜色短天线。
2. 复制 `ConeZombie.reanim` 为 `GroundingZombie.reanim`，只替换护具图片键；复制掉落粒子并替换图片键。
3. 完成 manifest、`resources.xml`、`ResourceKeys` 和资源加载断言。
4. 在既有雷荷绘制入口按锁定 ID 添加天线周围的程序化短电弧，不增加动画帧事件或持久视觉状态。

## Task 6：出怪、图鉴与确定性 AutoTest

1. 配置 2000 成本、第 6 波可用、每波上限 2、生存第 9 轮开放；把 6-8 作为教学池并在 6-9 组合复现。
2. 新增专项脚本覆盖基础数值、资源、蒙特卡洛与随机回退选择、锁定、植物专属放电、四类控制、掉帽后强化延续、存档和出怪边界。
3. 为纯数值推演补充延迟放电候选，测试停机收益、保护、路障存活、免控收益、共同随机数、局部并列 RNG 和详细实体上限。
4. 对默认实例与 `-NoInstance` 做资源测试；对引雷、护具破损和掉落做同步截图。

## Task 7：契约、构建与交付

1. 更新接地僵尸项目记忆、第六区域 backlog 和 `MEMORY.md` 索引。
2. 审计 `adding-zombie`、`adding-rain-weather`、`adding-particle` 及相关 references；若契约发生可复用变化则同步技能并用 `quick_validate.py` 校验。
3. 运行 `clang-release` 配置与构建，从 `build/clang-release` 在主人当前桌面可见运行专项和相关雷荷/路障回归。
4. 检查退出码、`run.log`、状态 JSON、断言和截图；审查 diff 与资源哈希后提交，并在上游安全时推送。

## 完成定义

- 规格中的数值、随机锁定、植物专属放电、通用免控、掉帽延续、资源、存档和出怪全部实现。
- 不新增动画帧事件；常态 UI/Draw 不扫描全部僵尸。
- `clang-release` 构建通过，专项与相关回归在当前桌面可见运行并退出 0。
- 最终低分辨率截图可辨认电紫路障、铜色天线和小型引雷动画。
