# 冰像处刑者实现计划

1. 在稳定僵尸枚举末尾追加 `ZOMBIE_ICE_STATUE_EXECUTIONER`，注册独立类、扶梯时间轴、数值、图鉴、AutoTest 名称和冬日花园出怪数据。
2. 为 `Plant` 增加来源绑定的冰封状态和三条专用入口：建立/释放冰封、来源拥有者的普通锤击伤害、来源拥有者的最终处决；把暂停、承伤、死亡、压扁、移动、蹦极和铲除边界统一收口。
3. 为 Board 增加稳定高价值候选选择、封存提交前的附近植物保护请求和读档双向关系终检；炉芯花覆写默认失败的植物保护接口，成功时让目标从未进入冰封并原子耗尽处刑者能力。
4. 实现处刑者状态机：完全进场后锁定，使用 `anim_placeladder` 约 2.5 秒播完作为提交边沿，三次 40 点普通伤害和最多三格进度；回暖可重试，死亡/断头/断臂/魅惑永久终止，警铃只重置当前前摇。
5. 使用独立黑色橄榄球头盔三档图片建立命名静态 follower `ice_executioner_helmet` 并挂到 `anim_head1`，将 Animator 稀疏轨道 follower 扩为可共存的命名向量；隐藏扶梯，以确定性脚本从已锁定母图生成独立冰锤运行资源，并用专属单粒子表现破帽掉落。断头仍复用扶梯头部粒子，不新增帧事件。
6. 保存植物拥有者 ID、僵尸目标 ID/进度/阶段/能力状态及 Board 每波计数；对旧档和损坏档执行中性默认与双向原子修复。
7. 扩展状态投影和专项脚本，覆盖资源、头盔三态/磁吸、目标价值与 ID 并列、三锤、警铃重置、炉芯花提交前硬阻断、回暖、死亡/断肢/魅惑、全面隔离、存档和每波上限。
8. 用 `clang-release` 构建，在当前桌面可见运行专项及相关冬季回归；检查退出码、日志、状态 JSON、断言和默认实例/`-NoInstance` 截图，按截图校准 `anim_head1` 头盔与冰锤轴心。
9. 审计并更新僵尸与 reanim 技能、项目记忆，运行 skill-creator 校验，提交并在安全 fast-forward 条件下推送。
