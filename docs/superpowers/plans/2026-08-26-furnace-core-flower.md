# 炉芯花实现计划

1. 在稳定植物枚举末尾追加炉芯花，注册独立类、独立 reanim 名称、数值、卡图、图鉴和 7-7 奖励。
2. 保存炉芯库存与未完成充能；按 Board 实际温度和游戏时间推进，停机、冰封和零度以下不充能。
3. 在冰像处刑者建立冰封的提交边沿前，经 Board 稳定 ID 聚合调用植物窄接口；成功时消费一枚炉芯、保持目标未冰封，并把来源能力原子置为 `SPENT`。
4. 从同一获批美术源确定性生成卡图与场上炉膛分件，复用向日葵时间轴并用两个命名静态 follower 表现炉芯，不增加帧事件或子 Animator。
5. 扩展 AutoTest 名称、状态投影和确定性夹具，覆盖充能、暂停、重叠、自身排除、耗尽回退、存档、奖励及两条渲染路径。
6. 使用 `clang-release` 构建并可见验证，审计项目记忆与相关技能，校验技能后提交推送。
