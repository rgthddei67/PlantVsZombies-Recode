# 精英扶梯僵尸实施计划

1. 派生 `EliteLadderZombie`，接入类型、工厂、动画、图鉴和生存数据；复用经典扶梯帧事件。
2. 实现五秒一次性行扫描、严格阈值、投手/射手分类、生命与动画分支及完整存档。
3. 扩展经典扶梯的资源虚接口与放置保留钩子，让无限能力不复制父类状态机。
4. 为 Board 共享扶梯增加外观样式，贯通绘制、磁吸和旧档兼容存档。
5. 生成深蓝工装/安全金扶梯资源与独立断梯粒子，并锁定生成哈希。
6. 接入每波最多一只的正式波次限额、存档、换波复位与 AutoTest 状态投影。
7. 补专项、无实例化视觉专项、每波上限专项和经典扶梯回归。
8. 完成 `clang-release` 构建、主人桌面可见验证、截图审查、技能/项目记忆审计、提交与安全推送。
