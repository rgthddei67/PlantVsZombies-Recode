# 搬搬藤

## 主人已批准的玩法

- 9-1 通关奖励；75 阳光，20 游戏秒卡片冷却。一次成功使用搬运一个植物组合。
- 选择卡片、点击来源植物、点击目的空格。全场瞬间搬运，不受中间岩壁阻挡；成功才扣费并进入冷却，取消与非法目标不消耗。
- 同格 under/normal/pumpkin/overlay 整组移动；多格植物按完整 footprint 连同各格承载一起移动，方向不变。目的完整占地必须为空且符合地形规则，不能交换。
- 保留实体身份、当前血量、攻击/生产进度、能力冷却与已有状态；不回血，不重新出生，不附带无敌时间。
- 搬运提交时解除所有旧啃食关系并平衡被啃计数，尚未结算的啃食不得追击远处植物；目的地重新走正常接触判定。
- 被蹦极抓住、特殊能力隔离锁定、已进入一次性攻击过程的植物不能搬运。
- 附着扶梯随整组移动，保留攀爬效果。
- 搬搬藤不允许被模仿者模仿；场上已有模仿者仍可搬运。
- 外形为卷曲藤臂托着叶片吊篮；卡图与手持预览同一身份。参考缠绕海草的分件时间轴，不新增动画帧事件；搬运即时提交，收拢/展开只作反馈。

## 实现与验收

Board 持有整组查询、合法性检查与原子移动入口，CardSlotManager 只保存未提交的来源稳定 ID。植物通过窄虚接口声明当前阶段是否可搬；僵尸通过目标 ID 解除自身啃食关系。不能销毁重造植物或把出生配额/升级前置要求应用到已有植物上。

沿用正式实体/卡片存档保留移动后的格位与冷却，界面未提交选择作为瞬态取消，不在读档时自动搬运。专项覆盖真实三段点击、失败/取消不扣费、跨墙、各层、多格、扶梯、啃食解除、状态保存、非法介质与锁定/一次性动作限制，并验证奖励图鉴与资源。使用默认 clang-release 可见 AutoTest。
