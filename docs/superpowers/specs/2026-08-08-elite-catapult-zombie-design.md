# 导流投篮车僵尸设计

日期：2026-08-08 ｜ 状态：主人已批准，进入实现

## 目标

新增精英投篮车“导流投篮车僵尸”。它保留普通投篮车的十二发篮球、75 点篮球伤害、3 秒装填、碾压、地刺爆胎和保护伞交互，只通过更高耐久与屋顶径流联动形成差异。

## 数值与出怪

- 本体生命：1000；基础车速沿用普通投篮车的 23～37 px/s 随机范围。
- 篮球库存、伤害、飞行与装填全部沿用普通投篮车。
- 正式波次每波最多生成一只；直造、预览和读档不消耗计数。
- `gamedata.json` 进入生存模式池，但本次不扩展尚未制作的 5-7 冒险关。

## 径流导向

- 屋顶径流自然积累到 100 并锁行时，Board 查找仍存活、活动、未爆胎且已经进入坡段的导流投篮车。
- 多只候选时选择世界 X 最小、即最靠近房屋者；X 相同用僵尸 ID 较小者稳定决胜。
- 若候选行未被本次随机行组覆盖，就随机替换一个已选行；行数仍保持原来的 1～3 行，权重仍为 50/35/15。
- 锁定后的行掩码是唯一事实并照常入档。导流车在 WARNING 阶段死亡不重抽；锁行后出生的导流车不改变本次事件。

## 径流位移

- 普通地面僵尸继续承受现有 `-60 px/s` 径流附加速度。
- 未爆胎导流投篮车的径流倍率为 `5/3`，总附加速度为 `-100 px/s`；该倍率只作用于自身。
- 被地刺扎破后倍率立即回到 1，仍承受普通 `-60 px/s` 径流，同时继续既有 2.8 秒爆胎死亡流程。

## 资源与继承

- `EliteCatapultZombie` 继承 `CatapultZombie`；普通投篮车开放材质与爆炸效果选择扩展点，不复制射击状态机，也不新增动画帧事件。
- 复用普通投篮车时间线和第 46 帧投篮事件；新增深青蓝车身、青色侧板和冷色金属舱盖材质，以及独立 `EliteCatapultExplosion` 粒子配置。
- 烧焦残骸继续复用普通投篮车的黑色 `Catapult_Charred`。

## 存档与验证

- 新类型实体复用父类完整的 phase、弹药、车速、目标和计时存档。
- Board 新增当前波正式生成计数并存读档，旧档默认 0、加载夹紧到 0～1。
- AutoTest 覆盖资源闭环、1000 生命、普通投篮行为继承、自然锁行导向、WARNING 死亡不重抽、仅自身 `-100` 径流、爆胎退回倍率 1、独立爆炸和每波上限存档/重置。
