# 经典矿工僵尸设计规格

## 已确认资源与帧事件

- 主人提供 `Zombie_digger.reanim`，资源帧率为 16 FPS。
- 啃食命中帧使用全局帧 66、81；死亡回收帧使用全局帧 127。帧号按主人给出的值直接注册，不再做减一换算。
- 主人补充确认灰烬回收帧：`anim_crumble` 为 36，`anim_crumble_noaxe` 为 73。
- 按主人确认的“按原版”要求实现断臂、掉头、掉安全帽与丢镐后的专属表现。

## 状态机

1. `TUNNELING`：播放 `anim_dig`（12 FPS），以原版 0.66～0.68 px/tick 向左地下穿行；不可被普通弹丸、植物、魅惑或水草选中。
2. `RISING`：到达当前棋盘首格起点右侧 30px 的出土线后，播放 `anim_drill`（20 FPS），在 1.3 秒内按原版高度曲线从地下升起；最后 0.3 秒切到 `anim_landing`（12 FPS）。
3. `STUNNED`：播放 `anim_dizzy`（12 FPS）两轮；可以受伤，但不能移动或啃食。
4. `WALKING_WITH_PICKAXE`：播放 `anim_walk`，以原版 0.12 px/tick 向右折返；可受伤、啃食、被魅惑。
5. `TUNNELING_PAUSE_WITHOUT_PICKAXE`：地下丢镐后暂停 2 秒；0.5 秒时出现问号；不可受击或碰撞。
6. `RISING_WITHOUT_PICKAXE`：原地按相同 1.3 秒曲线出土，最后 0.3 秒播放落地动画。
7. `WALKING_WITHOUT_PICKAXE`：按普通僵尸 0.23～0.37 px/tick 向左前进。

地下、出土与停顿阶段禁止触发房屋失败线；只有无镐且向左行走时才能触发游戏失败。移动方向同时驱动位移、台风顺逆风、目标提前量与水平镜像。

地下与两条出土阶段都隐藏组件影子和 reanim 自带 `_ground` 轨道；完整出土进入 `STUNNED` 或无镐行走后才显示组件影子。读档后同样重建这一边界。

## 防具、断肢与死亡

- 本体生命 270；安全帽生命 100，按 2/3 与 1/3 阈值依次换成 `hardhat2`、`hardhat3`。
- 安全帽破裂时隐藏本体安全帽，并抛出专属安全帽粒子。
- 断臂隐藏外臂小臂与手，将外臂大臂替换为断臂贴图，并抛出矿工断臂粒子。
- 掉头隐藏两条头部轨道和眼睛轨道，并抛出矿工头粒子。
- 正常倒地播放 `anim_death`，按原版 18 FPS，在主人指定的第 127 帧回收。
- 地下、出土和无镐停顿阶段遇到灰烬按原版直接回收，不让安全帽吸收后残留；已完整出土的可交互阶段使用专属矿工灰烬动画，并按是否仍持镐选择 `anim_crumble` 或 `anim_crumble_noaxe`，分别在第 36、73 帧回收。

## 音效、粒子与附属动画

- 多只地下矿工共享 `digger_zombie` 循环声的引用计数；最后一只离开地下、丢镐或死亡时才停止。
- 出土播放 `dirt_rise`；持镐自然出土额外播放 `wakeup`。
- 地下移动用跟随当前位置周期发射的短寿命尘土爆发，避免固定世界原点的长寿命粒子落在身后。
- 出土使用 `DiggerRise` 粒子和 `DiggerRisingDirt` 一次性动画；丢镐停顿使用 `ZombieSurprise` 一次性动画。
- 断臂、掉头和掉帽分别使用独立粒子配置。

## 存档契约

保存并恢复阶段、阶段剩余时间、高度、持镐状态、地下速度、无镐行走速度、眩晕剩余时间、问号是否出现及地下尘土计时。读档只重建持续视觉、碰撞、镜像与循环声所有权，不重放出土音效或粒子爆发。

- 注册工厂、动画资源、图鉴文本与 `gamedata.json`；纳入生存模式权重池。
