# 仙人掌帧伤尖刺设计

## 目标

实现经典仙人掌及其尖刺子弹，但把原版单次命中改成主人确认的帧伤：

- 仙人掌沿用原版 125 阳光、7.5 秒冷却、300 生命和约 1.5 秒攻击间隔。
- 平地状态播放 `anim_shooting`，在主人给定的全局第 26 帧发射。
- 尖刺与僵尸碰撞重叠期间，以 1x 下每个逻辑碰撞帧 3 点为基准，沿正式植物伤害链结算。项目固定为每秒 60 个逻辑步，渲染帧率不会改变伤害。
- 固定逻辑步的次数不会随 `timeScale` 改变，因此每个目标单独累计 `damage × GetDeltaTime()/GetFixedStep()` 的小数伤害额度：0.5x 每帧累计 1.5 点、1x 每帧消费三个独立 1 点额度、2x 每帧消费六个独立 1 点额度，保证相同游戏时长在三档倍速下总伤害及免伤次数等逐击语义一致。
- 加固铁门仍存在时，其目标侧受击钩子把尖刺的 1x 每碰撞帧基础伤害降为 1；铁门掉落后恢复普通的 3 点。该修正发生在倍速额度累计前，因此两种状态下都保持三档倍速等伤。
- 尖刺按僵尸实体 ID 记录不同目标；首次接触第四只不同僵尸时，先结算该接触帧的伤害，再立即消失。
- 尖刺对目标的地面/空中身份不作伤害差异。当前气球僵尸尚未实现，低姿态先使用通用僵尸碰撞链。

## 动画与后续空中对接

`Cactus.reanim` 的包装轨道区间彼此不重叠：

- `anim_shooting`：全局 15～32 帧，第 26 帧只会在平地射击轨触发。
- `anim_shootinghigh`：全局 63～76 帧，主人给定的空中发射帧为第 70 帧。

当前只注册第 26 帧事件。代码保留明确 TODO：气球僵尸落地后，按正式空中状态契约接入升高/降低状态机与第 70 帧发射事件；高低姿态均发射同一种 `BULLET_SPIKE`。

## 子弹与存档契约

- `BULLET_SPIKE` 使用 `ProjectileCactus.png`，基础伤害为 3，台风响应沿当前显式配置保持 `NONE`。
- 普通子弹仍在首次命中后消失；只有尖刺注册 `onTriggerStay` 帧伤路径。
- 每枚尖刺保存已穿透的僵尸 ID 数组，以及与 ID 对齐的未结算小数伤害额度。旧存档缺字段时恢复为空/0，不需要提升存档 schema。
- 对象池复用必须清空穿透 ID 和伤害余额、恢复 3 点基础伤害和尖刺贴图，防止上一枚尖刺状态污染下一枚。

## 验证

- 注册、数值、卡图、待机与平地射击轨。
- 第 26 帧生成 `BULLET_SPIKE`，伤害为 3。
- 同一僵尸重叠时逐帧掉血，但只计作一个不同目标。
- 0.5x 运行 60 个逻辑帧、1x 运行 30 帧、2x 运行 15 帧后，同一重叠目标均承受 90 点总伤害。
- 持门加固铁门在 1x 下每个碰撞帧只承受 1 点尖刺伤害；破门后的同类型恢复每帧 3 点。
- 穿透计数和目标 ID 可随关卡快照往返；第三只目标后读档仍保留三个名额，重叠目标不会重复占用。
- 第四只不同僵尸承受接触帧伤害后子弹消失。
- 可见截图校对仙人掌本体、影子、发射姿态与尖刺贴图。
