# 南瓜头九宫格范围伤害保护设计

日期：2026-08-04　状态：已获主人批准

## 目标

保持南瓜头 100 阳光、30 秒冷却与 4000 生命不变，把已接入的特殊僵尸范围伤害保护从同格扩大为自身逻辑九宫格，使单次种植能保护一小片阵型。普通小丑仍按既有规则直接摧毁爆区植物，不接入保护。

## 结算规则

- 先沿攻击原有几何收集实际命中的植物层，保护范围不会让未被爆炸命中的植物凭空承伤。
- 每个命中植物在逻辑行列各相差不超过 1 的范围内选择活动南瓜头；优先距离平方更小者，并依次按行、列、实体 ID 稳定打破并列。
- 南瓜头命中时只选择自己，不由相邻南瓜保护；转移后的伤害不再次转移。
- 同一次爆炸按保护南瓜的实体 ID 归并：一枚南瓜无论保护多少格、多少植物层，都只承受一次对应倍率伤害。
- 南瓜被这次伤害击碎时，已经由它接管的植物仍然存活；没有保护者的命中层保持原伤害。
- 默认特殊范围伤害按基础伤害 `×5` 扣除南瓜生命；爆破工头使用独立 `×4`。普通小丑仍直接 `Die()` 爆区植物。

## 一致性边界

- `Board` 正式结算、精英小丑贪心评分与 `PlantDefenseMonteCarlo` 必须使用同一九宫格、最近者、稳定并列和按保护者归并语义。
- 不新增存档字段；范围能力完全由当前活动植物、格位和生命状态派生。
- 不新增粒子或动画帧事件；南瓜正式 `TakeDamage` 的既有受击反馈继续表示代挡。

## 验收

更新 `smoke_pumpkin_zombie_area_damage.json`，覆盖：

1. 精英小丑爆炸由斜向相邻南瓜按 `50×5` 代挡，九宫格外同次命中植物仍扣 50；
2. 爆破工头命中多株时，同一南瓜只承受一次 `150×4`，重叠保护按最近/稳定并列选择，保护圈外植物仍扣 150；
3. 水池 `under+normal` 由相邻行南瓜按 `50×5` 一次保护；
4. 普通小丑继续直接清空同格普通植物与南瓜。
