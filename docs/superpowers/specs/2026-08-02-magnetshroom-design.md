# 磁力菇实现规格

## 目标

按 C# 参考实现夜间持续型磁力菇：从自身上下两行内选择最近的合法金属装备，立刻从僵尸身上剥离，播放吸取动画并把装备飞向磁力菇；完成后进入 15 秒充能，再恢复搜索。

## 行为契约

- 花费 100 阳光，卡片冷却 7.5 秒，基础生命 300；白天沿用蘑菇睡眠规则。
- 常规搜索半径为 270px（3.375 格），目标正在啃食时为 320px（4 格）；候选评分为直线距离加每跨一行 80px 惩罚。
- 合法目标必须存活、未魅惑、有头、处于活动状态且未离开棋盘，并由僵尸自己的虚接口声明和剥离金属装备。
- 覆盖铁桶、橄榄球头盔、普通铁门、弹跳杆、普通小丑盒和普通矿工镐及适用变体；加固铁门、精英小丑和精英矿工明确免疫磁吸，保留其核心压力。磁吸是独立于受击破甲的剥离路径，不播放掉落粒子，也不触发粉色橄榄球头盔爆裂伤害等破甲副作用。
- 锁定目标时立即剥离装备并播放 `anim_shooting`，轨道结束后停留在 `anim_nonactive_idle2`；不增加动画帧事件。
- 飞行装备按固定步长的 5% 指数趋近磁力菇。装备贴图、世界坐标、目标偏移、缩放、阶段和充能剩余时间全部参与存档。
- 放置梯子不在当前项目的对象模型中，本次不虚构新的梯子格物系统。

## 资源与呈现

- 使用已导入的 `Magnetshroom.reanim`、磁力菇卡片/分层贴图及 `magnetshroom.ogg`。
- 吸来的装备使用目标当前损伤阶段对应贴图，从装备动画轨道的世界位置起飞；当前宽屏资源的落点统一向右校正 25px，抵达后显示在磁体中央偏右位置。
- 资源闭环必须覆盖 `resources.xml` 注册、资源键、植物工厂和 AutoTest 的卡片/动画/声音/装备贴图断言。

## 验证

- AutoTest 覆盖最近目标筛选、装备立即消失、吸取/充能/就绪阶段、读档保持与音效计数。
- 代表性覆盖普通及变体装备，并验证磁吸不触发普通破甲的额外能力。
- 使用 `clang-release` 构建，并从其构建目录在当前桌面可见运行最小相关 AutoTest；检查退出码、`run.log`、状态 JSON 和截图。
