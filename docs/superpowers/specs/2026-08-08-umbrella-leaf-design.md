# 叶子保护伞设计

## 目标

实现经典 `PLANT_UMBRELLA`，忠实覆盖当前项目已经存在的两类空中威胁：蹦极僵尸与投篮车篮球。主人提供的 `Umbrellaleaf.reanim` 只有 `anim_idle`、`anim_block` 两个包装轨，本实现使用状态计时与一次性轨道完成信号，不新增动画帧事件。

## 数值与表现

- 阳光 100，冷却 7.5 秒，生命 300；防线推演只记录 300 基础生命。
- 待机播放 `anim_idle`。首次威胁把状态切为 `ACTIVATING`，以原版 22 FPS 播放 `anim_block`，并播放原版 `FoleyType.Umbrella` 对应的 `SOUND_THROW2`。
- 0.05 游戏秒后进入 `REFLECTING`；`anim_block` 完成并自动回到 `anim_idle` 后恢复 `IDLE`。重复威胁不会重启动画或重播声音。
- 原版阴影为半尺寸；按本项目以格子中心为逻辑原点的口径设置独立偏移和等比缩放，并用可见截图与向日葵、小喷菇对齐脚底。

## 保护选择

- 植物通过虚接口声明是否覆盖一个空中威胁目标格；`Board` 只负责从活动植物中选择保护者，不维护植物类型表。
- 叶子保护伞覆盖自身逻辑格及周围八格。重叠保护范围按植物实体 ID 选择最早种下的有效保护者，保证结果稳定且一次威胁只触发一株。
- 失活、死亡、压扁或已被蹦极抓取的伞叶不提供保护。

## 交互矩阵

| 威胁 | 保护区内 | 保护区外 |
|---|---|---|
| 蹦极僵尸落地 | 播放 `boing`，触发伞叶，清空待偷植物并直接进入空手上升；不伤害或抓取任何植物 | 保持现有落地、等待、抓取、上升流程 |
| 篮球首次接触 | 触发伞叶并等待 0.05 秒展开，篮球与目标均保留 | 正常对当前投篮层造成 75 僵尸来源伤害 |
| 篮球接触已展开伞叶 | 篮球消失，播放 `splat`，生成 `UmbrellaReflect` 反弹篮球粒子；目标不受伤 | 不适用 |

篮球碰撞同时监听 Enter/Stay，确保激活等待结束后由同一正式碰撞链完成反弹。反弹粒子以篮球当前弹心为世界原点，用本项目粒子 Position 轨迹表达向屋外上抛再下落，不照搬 C# 的 800×600 绝对坐标。

## 存档与兼容

- `UmbrellaLeaf::SaveExtraData/LoadExtraData` 保存激活状态与剩余 0.05 秒计时；Animator 的当前轨道、目标轨和播放状态继续由通用存档负责。
- 旧档缺字段时恢复 `IDLE`；读档只重建状态，不播放声音或重新触发威胁。
- 蹦极被反弹后使用既有 `RISING + NULL_PLANT_ID` 表达空手离场，不新增重复关系字段。

## 验证

- 资源闭环：卡图、reanim、全部伞叶部件、`SOUND_THROW2`、`SOUND_BOING`、篮球纹理均可加载。
- 图鉴/数值：100 阳光、7.5 秒冷却、300 生命推演画像与中文图鉴条目存在。
- 可见截图：待机站位与阴影；篮球反弹粒子；蹦极被弹回；默认实例化与 `-NoInstance` 各跑一次。
- 行为断言：保护区外篮球正常伤害；对角相邻目标免伤并反弹；蹦极空手上升；激活中快照往返不重播声音；现有蹦极和投篮车专项回归保持通过。
