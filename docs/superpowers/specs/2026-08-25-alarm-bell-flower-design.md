# 警铃草设计

## 定位与数值

`PLANT_ALARMBELLFLOWER` 是 7-6 通关奖励、7-7 首次可用的单行即时植物。初始调参为
25 阳光、50 秒冷却、300 生命；不造成伤害，也不依赖天气预报、实际温度或冻土。

低费用允许玩家在看见持续动作后及时作答，长冷却则要求玩家判断哪一行、哪次提交最危险。
没有合法目标时仍会完成响铃并消耗卡牌，不能把警铃草当成无风险的隐藏状态探测器。

## 单行选择与中断

种下后的首个正式逻辑步，警铃草只遍历本行活动、未死亡、未魅惑的僵尸，并读取
`Zombie::GetInterruptibleSpecialActionRemaining()`。负数表示没有可中断动作；候选中选择剩余
提交时间最短的一项，浮点余时相同时按稳定僵尸 ID 取小者。确定唯一候选后只调用一次
`InterruptUncommittedSpecialAction()`，调用失败也不改选第二项。

当前交互矩阵：

| 目标状态 | 结果 |
|---|---|
| 气象干扰僵尸 `CHANNELING` | 取消本次上传，进入 5 秒重启；已经提交的整栏黑障不回滚。 |
| 冰裂钻机 `CHARGING` | 取消本次钻孔并保留能力，仍在冻土时可从完整 3.5 秒重新蓄力。 |
| 冰墙工程师 `BUILDING` | 原子拆除未完成墙、回到可重试状态；已经完工的冰墙不回滚。 |
| 未来冰像处刑者当前锤击 | 由处刑者覆写同一窄接口取消当前未提交锤击；已增加的处决进度不回滚。 |
| READY、MOVING、REBOOTING、SPENT、COMPLETED 或独立已提交对象 | 不进入候选。 |

警铃草不识别任何具体僵尸类型；新动作是否可中断、被中断后能否重试及如何恢复动画，全部由
动作拥有者的两个虚接口决定。

## 生命周期、视觉与存档

警铃草不增加动画帧事件。首次正式更新原子选择并中断后，立即发出覆盖整行的金青双色脉冲，
播放金属铃声，实体保留 1 游戏秒演出余韵再消失。场上动画复用原版三叶草 `Blover.reanim`
的 `anim_idle`、`anim_blow` 与 `anim_loop`：地面轨只承载固定叶座，原版 `stem2/stem1`
组成连续摆动茎，铃头替换 `Blover_head`，铃舌作为同一头轨 follower。待命、响铃和疲惫
三张头图按铃身底部的茎秆插口校准，而不是按 Alpha 包围盒对齐；最后 0.22 秒整体淡出。
卡图独立使用完整参考态，并按主人确认的 0.8 内容比例居中，场上骨架尺寸不随之缩小。

实体保存是否已经发出脉冲、这次是否成功中断以及演出剩余时间。读档不得再次中断第二个目标、
重播声音或重复发射粒子；旧档缺字段按尚未响铃的中性状态恢复。植物触发后免于啃食和普通伤害，
避免演出余韵被当成仍可阻止的持续能力。

## 奖励、资源与验证

7-6（内部关卡 60）奖励警铃草，7-7 首次可用；7-7 暂不加入气象干扰僵尸，让该关把警铃草
作为未来冰像处刑者的单机制答案。独立卡图、三态铃头、叶座、铃舌、reanim 和整行脉冲资源必须闭合
`resources.xml`、运行时资源键、manifest 与 AutoTest 加载断言。

专项至少覆盖 25/50/300 数值、同排最短余时选择、稳定 ID 并列、异排不受影响、无候选仍消耗、
零伤害、干扰僵尸重启、钻机重置、工程师半墙撤销、已提交状态不回滚、演出中快照不重复触发、
7-6 奖励，以及默认实例与 `-NoInstance` 的同步截图。动画专项在 0.35 倍速下覆盖换头前、
换头帧、连续放大帧、余韵和最终淡出，防止只截两端而漏掉茎头偏移。
