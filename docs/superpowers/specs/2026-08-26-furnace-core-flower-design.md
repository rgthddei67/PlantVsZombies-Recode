# 炉芯花设计规格

## 定位与数值

炉芯花是 7-7 通关奖励、7-8 首次可用的局部反处刑支援植物。当前数值为 175 阳光、20 秒卡片冷却、300 生命；种下时没有炉芯，最多保存两枚。

## 温暖充能

- Board 当前实际温度严格高于 0°C 时，每 10 游戏秒生成一枚炉芯。
- 低于或等于 0°C、植物停机或冰封时暂停；已有炉芯和未完成充能进度全部保留。
- 满两枚时停止推进。炉芯数量与进度进入植物存档，读档只恢复表现，不补发音效或发光。

## 阻止冰像封存

冰像处刑者准备建立来源绑定冰封时，必须先调用 Board 聚合入口。Board 按稳定植物 ID 遍历目标 3×3 内的有效提供者；第一株有炉芯的炉芯花消费一枚并返回成功。

成功后目标从未进入冰封、不承受首锤伤害且继续正常行为；发起者的一次性处刑能力原子进入 `SPENT`，随后仅保留普通行走和啃食。炉芯花不能保护自己，已经冰封、停机、被压扁、被蹦极抓取或离开活动态的实例不能响应。炉芯花不解救已经冰封的植物，也不改变 Board 温度、冻土种植规则、豌豆或全场天气。

## 美术与资源

卡槽和场上对象共享橙红花瓣、木质炉膛脸与两枚火焰炉芯的统一身份，但按各自尺寸独立构图。场上复用向日葵时间轴，注册独立 `FurnaceCoreFlower` reanim 名称；木质炉膛替换面部轨，两枚原版火焰使用稳定命名静态 follower 显示库存，不增加子 Animator 或动画帧事件。锁定母图与生成脚本负责确定性输出运行资源。

## 验证

专项覆盖资源键、175/20/300、从零充能、10 秒边界、零度暂停及部分进度保留、两枚上限、存档、稳定 ID 重叠消费、资源耗尽回退、自身排除、冰封提供者停机、7-7 奖励，以及默认实例与 `-NoInstance` 同步截图。
