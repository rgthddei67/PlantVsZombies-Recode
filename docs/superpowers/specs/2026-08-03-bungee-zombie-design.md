# 蹦极僵尸设计

## 范围

实现经典蹦极僵尸的完整下落、停留、抓取、上升和偷走植物流程，并加入常规生存模式候选池。不实现冒险 5-5 的“蹦极闪击”固定五只特殊编排，也不修改现有关卡刷怪表。

## 原版依据与坐标适配

- 行为轨道取自 `Zombie_bungi.reanim`：`anim_drop`、`anim_idle`、`anim_grab`、`anim_hold`、`anim_raise`。
- 状态切换使用 `PlayTrackOnce` 的回切轨道和当前轨道名，不新增动画帧事件。
- 绳索、靶标和三段尖叫音效从本地原版素材目录补齐，并通过 `resources.xml`、资源键和 AutoTest 形成加载闭环。
- 屋顶实机校准后，绳索必须延伸进本体背后的固定点，不得在头顶留断口；本体与携带植物分别保留独立水平偏移，避免修整身站位时再次破坏双手夹持中心。
- C# 的 800x600 绝对高度不直接照抄；下落起点、退场高度和目标位置由本项目 `SCENE_HEIGHT`、Board 行列与格子中心派生。

## 状态机

1. `DIVING`：选定格子后从屏幕上方下降；途中播放一次随机尖叫；到达地面后切 `anim_idle`。
2. `AT_BOTTOM`：停留五个游戏秒。此阶段可被地面弹丸、普通伤害和寒冷命中。
3. `GRABBING`：用 `PlayTrackOnce(anim_grab -> anim_hold)` 抓住目标格按“普通层、南瓜层、承载层”选择的植物。植物暂停行动、禁用碰撞并标记为被抓。
4. `RISING`：进入 `anim_hold` 后用 `PlayTrackOnce(anim_raise)`，植物由蹦极僵尸夹层绘制并对齐双手中心；上升使用独立高速而非复用下落速度，离开画面后植物与蹦极僵尸一起销毁。

蹦极僵尸在空中不可攻击；落地或抓取中死亡会释放尚未升空的植物，上升中死亡则连同植物一起结算。它不可魅惑、不可被水草拖拽、不触发土豆雷，也不会越过房屋失败线。

## 目标选择

- `mEnableMonteCarloAI == false`：复刻原版加权随机。未被其他蹦极僵尸预订的格子均可选；有植物格权重 10000，空格权重 1；若场上有多个向日葵，避免所有蹦极僵尸同时预订完最后一株未预订向日葵。
- `mEnableMonteCarloAI == true`：复用 `PlantDefenseMonteCarlo` 的当前棋盘、僵尸、卡槽和未来种植快照，把“立即移除候选植物”作为新候选效果，选择令玩家未来效用损失最大的植物。候选只取未被预订的、每格按蹦极顺序可偷走的植物；推演失败或无植物候选时回退到原版加权随机。
- 推演仍只使用局部随机数，不推进 `GameRandom`；同分候选由局部种子打破平局。

## 植物关系与存档

植物基类新增非拥有的蹦极抓取状态、抓取者 ID 和升空视觉偏移。抓取不立即释放格子；取消时恢复碰撞，真正偷走时由植物死亡统一释放对应层。

蹦极僵尸额外存档阶段、高度、计时器、目标格、目标植物 ID、目标模式、尖叫状态和蒙特卡洛统计。读档时植物先恢复，随后蹦极僵尸根据关系 ID 重建植物的抓取或升空状态；动画的一次播放及回切状态继续由通用 Animator 存档负责。

## 验证

新增最小 AutoTest 覆盖资源加载、随机/蒙特卡洛目标分流、完整抓取上升、落地可受伤/空中免疫、死亡释放、存读档关系恢复和截图取证。最终使用 `clang-release` 构建，并从该构建目录在主人当前桌面可见运行。
