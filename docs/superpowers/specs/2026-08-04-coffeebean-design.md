# 咖啡豆（Coffee Bean）设计

日期：2026-08-04　状态：按主人要求忠实完善原版植物

## 目标

完善经典咖啡豆：只能叠种在白天仍处于睡眠、尚未开始唤醒且未被蹦极抓取的蘑菇上。
咖啡豆不占普通植物层；短暂停留后碎裂，唤醒目标蘑菇并自动消失。

## 原版依据与时序

对照 C# `Plant.cs`、`Board.cs` 与 `GameConstants.cs`：

- 数值为 75 阳光、7.5 秒冷却；复杂一次性能力不参与轻量防线推演。
- 落地先等待 `mDoSpecialCountdown=100cs`（1 秒）。
- 等待结束时重新查询同格普通层：目标仍睡眠才写入 `WAKE_UP_TIME=100cs`；同时播放
  `anim_crumble`（22fps）与 `SOUND_COFFEE`。
- 目标唤醒倒计时剩 60cs 时播放 `SOUND_WAKEUP`，归零才切为清醒并恢复品种正式动画。
- 原版最后 70cs 用 `EaseSinWave` 绕植物局部底边做纵向弹性；本项目以最终视觉原点
  `+80px` 为世界缩放枢轴复刻，不改逻辑格或碰撞箱。
- 不新增动画帧事件：碎裂结束由 Animator 一次性播放完成状态判定。

## 格位与交互

`Cell` 增加短时 `overlay` 层，当前只承载咖啡豆：

- `GetTopPlantAt` 仍只返回南瓜、普通、承载层，咖啡豆不会被铲除或啃食逻辑误选。
- `CanPlantAt` 要求 overlay 为空、普通层睡眠、唤醒倒计时为 0、且目标未被蹦极抓取。
- 正式创建、读档重建、死亡清理、渲染顺序、台风整组移动/出界/弹坑丢失全部包含 overlay。
- 咖啡豆移除自身阴影和碰撞体，绘制顺序固定在同格其他植物层之上。
- 南瓜、睡莲、花盆仍保持各自层级；咖啡豆可以跨陆地、水路和屋顶唤醒其普通层蘑菇。

## 睡眠与存档

`Plant` 持有通用 `wakeUpTimer`，`Shroom::SetSleepState` 统一切睡眠/待机轨。
毁灭菇覆写清醒入口，唤醒完成后与夜间种植共用 `anim_explode` 和吸气声路径。

关卡存档保存目标的唤醒剩余时间、咖啡豆 WAITING/CRUMBLING 阶段与等待时间；恢复使用
无反馈入口，禁止重播 `coffee` / `wakeup`，随后由既有 Animator 状态恢复准确续播碎裂轨。
旧档缺 `wakeUpTimer` 时按 0 处理，不提升 schema。
