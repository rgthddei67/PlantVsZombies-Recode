# 南瓜头设计

## 目标

实现经典植物 `PLANT_PUMPKINSHELL`。它是纯防御外壳，可单独种植，也可与普通植物同格；不新增动画帧事件、攻击、产阳光或粒子效果。

## 原版契约

- 卡片：125 阳光，30 秒冷却。
- 本体：4000 耐久；低于最大耐久的 `2/3` 与 `1/3` 时，前脸分别切换到 `pumpkin_damage1` 与 `Pumpkin_damage3`。
- 占格：新增独立 `pumpkin` 层。普通层与承载层不被覆盖；同格只能有一个南瓜头。
- 优先级：铲除与僵尸啃食先选南瓜头；外壳死亡后，同格普通植物继续存在并重新成为顶层。
- 水路：南瓜头需要睡莲承载；允许包住睡莲上的普通植物。现有直接落水植物不能无睡莲套南瓜头。
- 组合移动：台风移动、出界死亡、弹坑死亡和读档恢复都把 `under/normal/pumpkin` 三层视为同一格组合。
- 啃食反馈：对齐 C# `Zombie::AnimateChewSound`，南瓜头与坚果/大坚果使用 `ChompSoft`，普通植物继续使用 `Chomp/Chomp2`。

## 绘制与存档

`Pumpkin_back` 必须画在同格普通植物后方，`Pumpkin_front` 必须画在其前方。南瓜头持有一个只画背片的同步 Animator；普通层植物绘制时先请求背片，南瓜头实体自身只画前脸。这样默认实例化与 `-NoInstance` 都不需要在 Animator 内临时改轨道可见性。

本项目最终站位使用 `gamedata` offset `[-37.6,-34.0]`；相对通用植物下移 10px，避免前脸遮住豌豆头部，同时保持脚底包裹关系。

破损外观只由已保存的生命值派生，不新增存档字段；`LoadExtraData` 只重建终态，不播放反馈。

## 验证

- AutoTest 锁定资源、卡片数值、4000 耐久、三层占格、顶层优先级、两档破损外观和快照往返。
- 用真实普通僵尸啃食证明伤害只落在南瓜头，内层植物生命不变。
- 断言 `SOUND_CHOMPSOFT` 已加载、啃食请求软声且不请求普通双声。
- 验证外壳死亡后内层植物保留并成为顶层。
- 验证泳池睡莲组合与台风三层同步移动。
- 默认实例化与 `-NoInstance` 各检查同一组同步截图。
