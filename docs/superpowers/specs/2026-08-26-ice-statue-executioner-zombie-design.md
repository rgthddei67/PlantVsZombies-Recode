# 冰像处刑者设计规格

## 角色与强度

冰像处刑者是冬日花园后段专属的强力机制僵尸。它不靠巨人体型或橄榄球冲刺制造压迫，而是以正常僵尸体型、接近普通僵尸的行进速度和一套高耐久装备进入战场，远程封存冻土上的高价值植物并持续推进不可回滚的处决进度。

- 本体生命 1000，红色橄榄球头盔生命 1400，总有效耐久 2400。
- 每次锤击前摇约 2.5 游戏秒；每击造成 40 点普通伤害。
- 每名处刑者一生只能成功处决一次；成功后失去特殊能力，作为高耐久普通啃食僵尸继续前进。
- 7-7 首次教学，每波最多一名；7-8、7-9 与其他冬季威胁组合。当前按强版本投放，后续根据实战数据降低权重、耐久或动作速度。

## 目标与冰封关系

处刑者完全进入战场后，在所有实际处于冻土的格子中选择一株仍活动、可持续存在且尚未被冰封的高价值植物。价值沿用战斗推演的阳光、生产潜力和后排权重；同价值按较小植物 ID 稳定决胜。瞬时植物、承载层和非正式实体不进入候选。

锁定后，处刑者 ID 与植物 ID 建立唯一双向关系。冰封属于植物的权威状态，进度属于当前处刑者：

- 植物保留原实体、ID、格位、生命、动画帧、品种计时和所有内部状态。
- 植物完全停止 Animator 和行为更新，效果等同不倒计时的雷击停机。
- 植物不可铲除、不可啃食、不可被僵尸索敌、不可被蹦极或台风移动，碰撞关闭；植物子弹本就不与植物碰撞，因此直接越过冰像。
- 普通伤害、爆炸、碾压、地裂、锤击和其他外部作用不得影响冰像；只允许关系拥有者通过专用处决入口造成三次 40 点普通伤害并推进进度。
- 实际格温回暖并解除冻土时，冰封立即解除且当前处决进度清零；处刑者仍有能力时可重新选择目标，从零开始。
- 处刑者死亡、断头、断臂或被魅惑时，立即解除冰封、清零进度并永久消耗能力。头盔破裂或被磁力菇吸走不会中断处决。
- 读档后交叉校验双方 ID、冻土和终止态；不合法组合原子解除，不凭空继承或恢复进度。

## 三锤处决与反制

处刑者复用扶梯僵尸 `anim_placeladder` 动作。每轮从动作起点播放至结束，播放结束即为提交边沿，不新增动画帧事件：

1. 先对目标结算 40 点普通伤害；这是已提交效果，不能回滚。
2. Board 请求目标周围的植物提供一次处决进度保护。当前默认无响应；未来炉芯花在 3x3 内消耗一枚炉芯并返回成功。
3. 未被保护时进度加一；第三次提交立即处决目标。
4. 尚未达到三次时重新从完整前摇开始下一锤。

警铃草只调用现有通用中断接口。它中断当前尚未提交的锤击并把本轮前摇重置为完整 2.5 秒；已经提交的 40 点伤害和进度不回滚，锁定与冰封也不解除。候选优先级仍按剩余提交时间、再按僵尸 ID。

炉芯花只通过植物侧窄接口参与：实际温度大于 0°C 时充能最多两枚，目标位于其 3x3 内时可消费一枚取消本次进度增加。处刑者不得识别炉芯花类型，炉芯花也不解冻、不改变温度、不阻止本次 40 点伤害。

## 动画与美术

- 身体复用扶梯僵尸的完整时间轴，隐藏梯子；行走、啃食、死亡和已有帧事件继续沿用原资源。
- 服装以冷蓝灰雪原配色覆盖身体分件；武器轨道 `Zombie_ladder_hammer` 替换为独立大型冰制处刑锤。
- 使用原版红色橄榄球头盔及其三档损坏图片，不使用参考图中的黑色帽子或铁门。
- 头盔不能替换 `anim_head1`，因为裸头必须保留在帽子下方。它没有独立时间轴，因此使用命名静态 follower 槽 `ice_executioner_helmet` 跟随 `anim_head1` 的逐帧位移、旋转和缩放，不创建子 Animator；当前穿戴缩放为原图 88%，局部锚点由默认实例与 `-NoInstance` 可见截图共同校准。
- Animator 的稀疏轨道状态允许同一轨道保存多个命名 follower。黄油使用独立槽 `butter_splat`，不得覆盖头盔；绘制保持稳定插入顺序，并由专项同时显示黄油与头盔验证。
- 破帽使用专属单粒子 `ZombieIceExecutionerHelmetOff`：发射中心由 `anim_head1` 轨道原点、头盔局部偏移和运行缩放后的贴图中心共同计算，XML 不再叠固定发射偏移，离体显示比例独立缩至 70%。断头时仍复用扶梯头部粒子，不新增头盔合成断头帧事件。

## 关卡与存档

- 在稳定僵尸枚举末尾追加冰像处刑者，禁止占用既有 ID。
- 7-7 使用精简池保证首次教学并强制较早出现一名；7-8、7-9 加入综合池。
- Board 保存“本波已生成处刑者数量”，换波清零，确保限制是每波最多一名，而不是整局累计一名。
- 僵尸额外存档保存阶段、目标植物 ID、当前已提交进度及能力是否消耗；植物通用存档保存冰封拥有者僵尸 ID。
- AutoTest 同时投影双向关系、冻土、动作剩余时间、进度、普通伤害、可铲/可食/碰撞/暂停状态、装备状态与每波上限。
