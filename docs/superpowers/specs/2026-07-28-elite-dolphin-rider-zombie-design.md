# 精英海豚骑士僵尸设计

日期：2026-07-28 ｜ 状态：已完成并验证

## 1. 定位与关卡节奏

精英海豚骑士是普通海豚僵尸的规则强化变体，用于冒险 3-8（level 26）：

- 3-7 先独立教学普通海豚，并在通关后奖励高坚果。
- 3-8 使用 `{普通, 路障, 铁桶, 普通海豚, 精英海豚}`，让玩家立即用高坚果应对更深的水路越障。
- 3-8 保持 20 波；精英海豚正式波次每波最多 1 只，避免两条水路同时出现多个连续越障者而失去可读性。
- 3-9 尚未编排，本任务不提前加入未完成的最终综合阵容。

## 2. 核心行为

`EliteDolphinRiderZombie : DolphinRiderZombie` 复用普通海豚的完整 reanim、帧事件、声音、入水和跳跃时序：

- 本体生命 700；移动速度、动画倍率、入水速度和弃豚后速度均与普通海豚一致。
- 普通海豚成功越过第一株普通植物后弃豚；精英海豚第一次成功越过普通植物后仍保持骑乘，可以再次寻找目标。
- 精英海豚第二次成功越障后弃豚，进入普通 `SWIMMING` / `WALKING_WITHOUT_DOLPHIN`。
- 海豚只在右岸外 0～20 px 启动 `anim_jumpinpool`，动画完成并提交 70 px 根位移后才切入水中介质；不会先在水中游一段再抛豚。
- 入水绘制复刻 C# 的分段局部裁剪：0.56～0.65 和 0.75～结束使用低于普通水面的海豚专属底线，中间时间窗不裁剪。所有海豚部件轨保持原动画，不使用隐藏轨道或通用水面线切整只僵尸。
- 跳跃落地的世界提交位移按资源身体锚点差分别校准为 104 px（弃豚）和 106 px（保豚），抵消 `anim_dolphinjump` 切换到 `anim_swim/anim_ride` 的视觉倒退。
- 未遇到植物而从左岸上岸时，`anim_ride→anim_walkdolphin` 零混合切换；阶段视觉补偿与姿态同帧撤销，避免 0.2 秒 blend 把旧海豚姿态垂挂到脚下。
- 每次跳跃仍只在既有 30% 动画进度节点检查一次阻拦，不新增帧事件。
- 高坚果无论在第一次还是第二次跳跃阻拦，都会立即迫使精英海豚弃豚；成功跳跃次数不再影响后续状态。
- 阻拦状态、碰撞和啃食恢复后，精英海豚对高坚果造成 500 点
  `DamageSource::ZOMBIE` 伤害。该伤害统一消费生存模式僵尸增伤与植物韧性词条。
- 普通海豚被高坚果阻挡时不造成额外碰撞伤害，保持当前行为。

## 3. 状态与存档

普通海豚父类增加两个可扩展入口：

- `GetDolphinJumpCapacity()`：普通返回 1，精英返回 2。
- `OnDolphinJumpBlocked(Plant&)`：普通为空，精英结算 500 点植物伤害。

父类统一保存：

- 已成功完成的越障次数。
- 当前跳跃成功落地后是否应继续骑乘。

第一次精英跳跃的返回轨道直接设为 `anim_ride`，第二次和普通海豚仍返回 `anim_swim`，避免先切弃豚游泳再切回骑乘造成视觉跳变。跳跃中快照恢复后继续使用已保存的返回语义，不重复计数、声音或伤害。

魅惑、冻结和水草规则沿用父类：

- 保有海豚时不可魅惑，第二次越障或被高坚果挡下弃豚后才可魅惑。
- 入水和跳跃阶段不可冻结。
- 只有弃豚后的稳定阶段可被水草抓取。

## 4. 外观与资源

显示名称为“精英海豚骑士僵尸”，外观采用：

- 骑手：普通红色潜水服精确换为深海蓝，保留肤色、白边、阴影、高光和 Alpha。
- 海豚：普通灰色换为粉白色，保留白腹、眼睛、黑色轮廓、阴影和高光。
- 水花、水影和非目标部件保持原样。

`scripts/recolor_elite_dolphin_rider.ps1` 从普通海豚权威资源可复现生成独立 reanim、骑手部件、海豚部件和陆地掉头贴图，并逐文件锁定 SHA-256。精英掉头使用独立
`EliteDolphinRiderHeadOff` 粒子；水中仍不生成头或手臂掉落粒子。断臂残肢材质通过父类虚拟资源键切换为精英蓝色 `outerarm_upper2`，读档重建必须走同一入口。

不新增声音、不新增动画帧事件。普通海豚与精英海豚共用上述入水、跳跃锚点和上岸换轨修正；其他僵尸仍使用原有通用水中裁剪。

## 6. 验收

- 第一次普通植物越障后：成功次数为 1、仍为 `RIDING/anim_ride`、仍有海豚。
- 跳跃快照往返后仍只结算一次第一次落地。
- 第二次普通植物越障后：成功次数为 2、进入 `SWIMMING/anim_swim`、失去海豚。
- 高坚果阻拦前：仍为 `JUMPING/anim_dolphinjump`，阻拦检查未发生，高坚果仍为 9000，Bonk/星星均为 0。
- 高坚果阻拦后：精英弃豚并开始啃食，高坚果为 8500，Bonk/星星各一次；精英本体不扣血。
- 独立脚本验证每波最多 1 只且跨波归零，计数快照恢复不绕过上限。
- 陆地断头发射蓝色精英头粒子；水中断头不发射粒子；死亡最终消失且无 WATCHDOG。
- 默认实例化与 `-NoInstance` 静止预览均检查粉白海豚和蓝色骑手，世界包围盒一致。
- 普通海豚入水三个时间窗分别截图，确认海豚不沉到泳池底部且骑手不被横切；左岸上岸首帧截图确认无 blend 残影。
- 普通泳池僵尸视觉脚本继续通过，证明海豚专属裁剪覆写没有改变其他僵尸。
