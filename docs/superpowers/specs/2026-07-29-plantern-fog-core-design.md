# 路灯花与四大关迷雾核心设计

日期：2026-07-29　状态：已获主人批准并实现

## 目标

把四大关迷雾从单纯遮挡视野升级成阵容压力：4-2 起，未被照明且雾 alpha 较高的远程植物
不能主动索敌；路灯花消耗击杀僵尸获得的“雾火”维持照明，并按挡位扩大范围、提高周围
产光植物效率。路灯花因此是四大关的核心解题植物，但仍允许玩家用近身植物、瞬发结算与
其他阵容承受雾中信息劣势。

## 关卡与索敌

- 4-1 只保留原版迷雾视觉和植物奖励教学，不启用燃料消耗、照明收益或索敌限制。
- 4-2 起统一读取逐格平滑后的最终雾 alpha；alpha 大于 96 时，射手、小喷菇、海蘑菇、
  大喷菇、胆小菇和三线射手不能主动取得该目标。
- 若目标格自身仍超过阈值，但它朝植物方向的相邻一格已经可见，则把目标视为可见边界外
  第一格薄雾并允许索敌；再深一格仍被阻断。该规则读取实际逐格 alpha，因此同时适用于
  地图基础雾线、路灯花照明边缘和台风驱散过渡，不写死某一列或某个挡位形状。
- 约一格内（横向 100px，行差不超过 1）的僵尸仍能被感知；已在飞行的子弹不失效。
- 接触、吞食、踩压、全场即时结算等被动/近身能力不套远程索敌限制。

## 路灯花与四档

一局同时最多有一株未压扁路灯花；死亡或压扁会释放名额，之后可在正常卡片冷却结束后重种。
限制由当前活动实体 ID 派生，不使用精英胆小菇那种“累计种植次数”。

| 挡位 | 照明范围 | 外圈 | 雾火消耗 | 产光效率峰值 |
|---|---|---|---:|---:|
| 关闭 | 无 | 无 | 0/s | 100% |
| I | 4×3，向僵尸来向多一列 | 全清 | 0.5/s | 110% |
| II | 8×5，在原版裁角范围前沿多一列 | 全清 | 1.0/s | 120% |
| III | 10×7，在扩大裁角范围前沿多一列 | 最外圈保留 28% 薄雾 | 首波 2.0/s → 最终波 4.0/s | 135% |

照明、索敌和产光倍率消费同一个 `Board::GetPlanternIllumination()` 形状；III 档外圈的
72% 照明也按同一比例插值产光收益。偶数宽度新增列统一朝僵尸来向，避免上下偏斜并优先帮助
远端索敌。I、II 挡保持固定消耗，III 挡按本关当前波/总波数的同一 smoothstep 进度升耗，
让前期手感不变、后期只适合短时爆发。燃料耗尽时保留所选挡位，补到燃料后自动恢复工作。

## 雾火经济

- 路灯花容量 100，主人试玩后指定新种初始燃料 30。
- 只有正式波次生成的僵尸会预分配雾火；召唤物、预览、通用直造和魅惑僵尸不产出。
- 雾火经济按每关自己的首波到最终波独立平滑，不复用天气导演，也不写死 4-2 的 20 波：
  单个携带者价值从 15 降到 10，普通僵尸向跨波保底累计器增加的份额从 0.50 降到 0.25，
  高耐久目标最多追加的份额从 0.25 降到 0.15；命中后仍扣除 1.0。
- 每波最多三个携带者，因此单波硬预算随单团价值从 45 降到 30。灰烬伤害只会同时释放
  出生时已经分配的雾火，不能因一次炸死大量僵尸绕过单波预算。
- 灯芯同时在途的雾火也以当前单波预算为上限（45→30）；炸弹可以集中兑现一整波奖励，
  但跨波存活的多批携带者同时死亡时，超出部分直接丢弃，不能把多波存量瞬间灌满 100。
- 僵尸死亡时才发起结算：场上无路灯花则直接废弃；实际燃料加在途预留量已经满仓时也直接
  废弃且不生成飞行动画；仓容或瞬时吸收量部分溢出时只预留可容纳部分，剩余丢弃并触发
  卡牌金色满仓/过载提示。
- 成功预留后创建 `MistFuel`，沿 0.62 秒贝塞尔弧线飞向当前路灯花；卡牌燃料在飞行途中不变，
  只有雾火抵达并被灯芯吞下时才正式增加。飞行中目标死亡则整团消失且不入账。

## UI

路灯花种下后，其卡片转为控制台：左下显示 `0/I/II/III`，中下显示取整后的当前燃料，
右侧显示燃料比例条。点击卡片或路灯花本体展开四个竖排挡位按钮；面板属于
`CardSlotManager` 瞬态，不进存档，并直接对齐路灯花卡槽下方；允许覆盖天气预报面板。
菜单由 `GameScene` 在天气面板之后作为独立 UI overlay 绘制，保证重叠时挡位按钮位于天气板
上方。满仓溢出时数字与卡片边框变金。该 UI 不合并进天气预报栏目，也不在植物脚下重复显示数字。

## 后期雾节奏

增强雾势仍保持 35～55 游戏秒。默认雾休整不再永远固定 50～80 秒，而是随既有天气导演压力
平滑缩短，在满压力时为 20～35 秒；保留短暂喘息，不让后期增强雾永久常驻。

原生雾片有大量透明洞，满逻辑 alpha 仍会泄露僵尸轮廓。绘制时先增加一层错位的冷灰雾片作
遮蔽补洞，再绘制原有雾层；补洞层继续消费相同逐格 alpha，所以路灯花、台风驱散和回流不会
出现残影或第二套范围。禁止改成固定白色矩形底幕。

## 存档与验证

- 路灯花实体额外保存燃料、在途预留量与挡位；旧档缺字段时默认 30 / 0 / I。在途 `MistFuel` 不单独
  持久化，读档时把已预留量结算进燃料，避免奖励丢失或容量永久占用。
- 僵尸保存预分配奖励与已领取标志，避免读档后重复领取。
- Board 保存跨波保底累计器；当前活动路灯花 ID 由实体重建，不单独保存。
- `smoke_plantern_fog_core.json` 以 186 条命令覆盖 4-1 no-op、4-2 启用、唯一性、
  四档形状/耗油/产光、远近索敌、无路灯花浓雾截图、飞行前后到账、在途存档、满仓与部分溢出、
  魅惑/无路灯花丢弃、死亡重种和真实按钮点击；索敌专项锁定固定雾线第一/第二格和 II 挡
  照明边缘外第一格。
- `smoke_plantern_fuel_curve.json` 以 83 条命令分别覆盖 20 波 4-2 与 10 波 4-3，锁定两种
  总波数下相同的首波/最终波端点、4-2 中段插值、III 挡 2→4/s 消耗、正式自然出怪的
  最终波 30 点上限，以及同帧四团 10 点奖励只能形成三团在途雾火。
- 原有 `smoke_fog_weather.json` 回归雾势、台风驱散和雾存档。
