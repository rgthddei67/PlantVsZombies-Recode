# 急救员僵尸设计规格

## 目标

在冒险 6-6（内部关卡 51）加入 `ZOMBIE_HEALER`（急救员僵尸）。它复用普通僵尸骨架、移动与 50 点啃咬，在战场上每 6 秒自动选择群体或单体治疗，以低额群抬和高额抢救支持同阵营僵尸。

本功能不新增动画帧事件。治疗使用逻辑倒计时，施法状态通过机械急救标志区分。

## 数值与出怪

| 项目 | 设计值 |
|---|---:|
| 本体生命 | 800 |
| 移动速度 | 普通僵尸速度 |
| 啃咬伤害 | 50 |
| 完整治疗冷却 | 6.0 秒 |
| 施法前摇 | 1.0 秒 |
| 取消后重试 | 0.5 秒 |
| 群疗半径/阈值/治疗量 | 140 像素 / 3 名伤员 / 每层 60 |
| 单疗半径/治疗量 | 280 像素 / 每层 300 |
| 出怪权重 | 2400 |
| 普通可用波次 | 第 3 波 |
| 生存模式可用轮次 | 第 7 轮 |

6-6 第 3 波额外保证一只急救员，同时保留该波正常预算出怪；之后按普通权重自然生成。急救员没有每波数量上限，只受波次预算约束。

## 自动治疗决策

治疗者只处理与自己 `mIsMindControlled` 相同的阵营。活动、非预览、非垂死、有头且至少有一个可修复生命层的僵尸才是伤员。

以施法者碰撞中心为圆心：

1. 140 像素内至少有 3 名伤员时进入 `AREA`，伤员计数包含自己；结算时重扫范围并治疗全部有效伤员，不设目标数上限。
2. 不满足群疗阈值时进入 `FOCUSED`，在 280 像素内锁定一个目标，单疗不允许选择自己。
3. 与施法者同阵营且有效的黑夜屋顶锁定劫持者拥有单疗第一优先级。
4. 其余目标按本体、头盔、盾牌现存可修复层中的最低剩余比例排序，比例相同按实体 ID 选择。
5. 多名急救员的单疗目标通过专用稀有类型索引预留；同一目标不能同时被多个 `FOCUSED` 施法占用，同帧选择按急救员实体 ID 稳定排序。

`AREA` 与 `FOCUSED` 共享完整冷却。出生时从 6 秒完整冷却开始；只有实际恢复至少 1 点生命后才重置完整冷却。单疗目标在结算时死亡、换阵营或离开 280 像素，则取消并在 0.5 秒后重试。群疗结算时重扫，若没有实际治疗也走 0.5 秒重试。

## 修复生命层

一次治疗对目标仍存在且未满的下列每一层分别增加模式治疗量，并各自夹紧至最大值：

- 本体：当前生命必须大于 0。
- 一类头盔：类型非 `NONE` 且当前耐久大于 0。
- 二类盾牌：类型非 `NONE` 且当前耐久大于 0。

铁桶、路障、橄榄球头盔、报纸、铁门与仍携带的扶梯均可随治疗修复显示阶段。已经破坏、掉落、被磁吸或部署的装备不会重建。气球等 `extra health` 不在治疗口径内。

每个实际获得治疗的目标只生成一个治疗粒子，不因同时修复多层而重复。治疗目标 ID 在结算前排序，保证治疗与粒子生成顺序稳定。

## 状态机、啃食与控制

| 状态 | 行为与标志 |
|---|---|
| `IDLE` | 正常移动/啃食，标志折叠 |
| `AREA` | 停止移动与啃食，绿色圆形三加号标志 |
| `FOCUSED` | 停止移动与啃食，紫色尖形单加号/电气标志 |
| `DISABLED` | 永久禁疗，标志烧焦垂下 |

治疗优先于啃食。急救员可在啃食中启动治疗：先保存当前啃食目标并平衡目标的食客计数，停止啃食完成治疗；结算或非终局取消后，仅当原目标仍存活、仍可啃、仍是同格顶层目标且仍在咬合范围内时恢复同一目标，否则回到正常索敌和移动。

冻结、黄油、麻痹沿用普通僵尸控制，暂停治疗前摇；寒冷通过现有缩放时间延长前摇，不重复叠加天气倍率。魅惑会原子取消旧阵营目标和预留，保留已有冷却，并从新阵营重新决策。

断头始终立即取消治疗并永久进入 `DISABLED`。有效难度 `<=2` 时断臂同样永久禁疗；有效难度 `>2` 时断臂不打断治疗，能力继续工作。预览实体始终静态展示，不推进冷却、决策、预留、治疗、粒子或声音。

## 视觉、粒子与声音

急救员使用普通僵尸骨架，换为灰白急救背心，背负绿色急救包和机械标志。所有医疗符号使用绿色加号；状态枚举是唯一权威，标志图像完全由状态派生。

- 群疗：每个实际目标在稳定身体视觉中心生成一个小型绿色加号，向上约 24 像素，持续 0.9 秒并淡出；最终显示尺寸在首版基础上统一乘 0.7。
- 单疗：加号保持群疗的 1.5 倍，并带浅绿色光环；加号同样乘 0.7，光环尺寸不变，时长和上升距离相同。
- 源图使用白芯和深绿边缘，保持日夜、闪电下的可读性；粒子在结算点取样，不跟随目标继续移动。
- 施法开始每名施法者只播放一次机械扣合声；成功结算每名施法者只播放一次治疗声，群疗较柔和、单疗较清晰，不按目标数叠加。

## 存档合同

实体存储治疗状态、完整冷却剩余、重试剩余、施法剩余、锁定单疗目标、待恢复的植物/僵尸啃食目标与永久禁疗标记。标志图像不单独存储。

读档后以当前实体关系重新验证：无效单疗目标取消并转 0.5 秒重试；`FOCUSED` 状态自动重建预留；断头或低难度断臂强制修复为 `DISABLED`；预览强制为 `IDLE` 且无逻辑副作用。声音声道与粒子不进存档。

## 图鉴文本

> 急救员僵尸每6秒判断一次伤情：附近有至少3名伤员时，为140像素内全体恢复60生命；否则为280像素内一名伤员恢复300生命，并优先抢救劫持者。治疗可同时修复仍存在的本体、头盔与盾牌，但不能重造已损毁装备，也不会修补气球。低难度下断臂会永久失去治疗能力，高难度下则会坚持工作。

## AutoTest 验收矩阵

1. 类型/资源：工厂、开发者表、测试表、gamedata 五字段、身体/四态标志、两种粒子纹理和 XML 均可取得。
2. 基础行为：800 本体生命、普通速度、50 啃咬、出生完整冷却、预览无副作用。
3. 双模式：2 名伤员走单疗，3 名伤员走群疗；边界半径、群疗无目标上限、每层分别夹紧。
4. 护具：铁桶、头盔、报纸、铁门、携带扶梯可修复且损伤图像可逆；掉落装备和气球 extra 不恢复。
5. 预留与优先级：锁定劫持者优先、同目标单疗互斥、同帧按治疗者 ID 稳定。
6. 中断：单疗失效 0.5 秒重试、死亡/魅惑/断头原子取消、低难度断臂禁疗、高难度断臂继续。
7. 啃食恢复：施法前停止啃食，治疗后有效原目标继续啃食，无效目标回到正常状态。
8. 存档：`IDLE/AREA/FOCUSED/DISABLED`、冷却、锁定目标和啃食恢复目标往返一致。
9. 出怪：6-6 第 3 波额外保底，普通池第 3 波起可用且无每波硬上限；生存第 7 轮边界。
10. 粒子/声音：每名实际治疗目标恰好一次效果，0.9 秒后消失；取消和零治疗无结算粒子/声音。

最终在 `clang-release` 当前桌面可见运行，并同时核对退出码、`run.log`、状态 JSON、断言和同步截图。

## 延期候选：蒙特卡洛选疗（未实现）

主人提出未来可让主菜单控制台的轻量蒙特卡洛开关参与“群疗还是单疗、单疗选谁”的选择。当前交付仍使用上文可读且确定性的规则。若后续接入，关闭开关必须完整回退当前规则；开启时只在 6 秒决策边沿比较有限候选，不做逐帧推演。第一版无需复制劫持者完整状态机，可把“当前已锁定劫持者存活到处决边沿”的战略价值作为快照效用项；只有要预测尚未锁定、未来雷荷与处决连锁时，才需要把劫持状态机纳入 rollout。
