# 第七大关寒潮植物与获取顺序设计

## 目标

第七大关不靠简单抬高僵尸生命和攻击制造难度，而是让五种僵尸围绕预报、冻土、持续动作和跨行突击形成组合题；五株新植物依次补上局部解法，但没有任何一株能单卡解决整套寒潮。

## 植物获取顺序

| 通关奖励 | 下一关首次可用 | 植物 | 教学目的 |
|---|---:|---|---|
| 7-1 | 7-2 | 雪锚果 | 先教玩家在寒潮前预埋冻土防线，第一次正面处理雪橇突击队。 |
| 7-2 | 7-3 | 融雪投手 | 用抛物线越过冰墙，并以盐弹腐蚀冰制装备和建筑。 |
| 7-4 | 7-5 | 伏霜雷 | 教玩家阅读准确寒潮预报，预判即将被冻结的格子。 |
| 7-6 | 7-7 | 警铃草 | 7-6 先让气象干扰僵尸完整打断一次预报依赖，随后再给单行中断工具。 |
| 7-7 | 7-8 | 炉芯花 | 7-7 先用警铃草应对首只冰像处刑者，随后再给稳定的局部容错。 |

7-3、7-5、7-8 不发植物，分别承担单机制复习、预报依赖成形和完整配对练习；7-9 不发植物，是全部寒潮组合的期末关。最终顺序固定为：雪锚果 → 融雪投手 → 伏霜雷 → 警铃草 → 炉芯花。

## 五株植物

### 雪锚果

- 定位：提前部署的冻土防线与以生命值为剩余承压能力的冲击整形器，不是免伤坚果。
- 初始调参：100 阳光、30 秒冷却、3000 生命；普通啃食照常生效。
- 只能在未冻结格种植。所在格由 Board 的真实温度规则变为冻土后，雪锚果自动进入锚定姿态；融化后退出姿态。
- 承压资格只要求植物仍活动、生命大于 0 且当前格确实冻结；满足资格时可以反复响应，融化期间暂停，重新冻结后若仍存活则恢复。
- 遭遇雪橇碰撞时，雪橇负责对雪锚果结算重伤并在其前方同排普通下车；雪锚果只返回“已拦截、禁止向后或邻行抛人”的语义结果。
- 遭遇地裂时，钻机负责对雪锚果结算当前完整伤害；雪锚果只返回“已拦截、后续伤害倍率最多为 1/3”，地裂继续影响左侧而不是被完全消除。同一道地裂经过多株雪锚果时取当前倍率与 1/3 的较小值，不叠乘为 1/9、1/27。
- 不克制冰墙工程师、气象干扰僵尸或冰像处刑者，也不免疫普通僵尸、橄榄球和其他啃食压力。
- 植物基类提供通用冬季冲击请求/响应接口，调用方按 `COLLISION` 或 `GROUND_CRACK` 请求；默认植物返回未拦截。调用方拥有动作时序、伤害、音画和队伍落点，禁止识别 `PLANT_SNOWANCHORNUT`。
- 当前是否锚定完全由 Board 冻土、植物活动态与已保存生命派生，不再保存次数字段。旧档中的 `winterBraceSpent` 作为未知旧字段忽略，使既有存档直接采用新合同，无需提升 schema。

### 融雪投手

- 初始调参：125 阳光、7.5 秒冷却、300 生命；约每 2.86～3.0 秒投掷一次。
- 普通融雪弹造成 20 点伤害；它与盐弹都走解析抛物线，可越过冰墙等直线弹道遮挡。
- 每轮准确寒潮预报首次进入有效窗口时，场上每株融雪投手把浓缩盐弹库存补满至三枚；预报窗口内新种下的实例也立即补满。补满是设为三枚而非累加，不能跨轮无限囤积。
- 每轮攻击在起手时锁定普通弹或盐弹；盐弹库存同时扣除并进入 `saltShotPending`。气象干扰会清空剩余库存和仍未越过发射帧的待发盐弹，已生成并在空中飞行的盐弹继续结算。
- 盐弹对普通目标仍造成 20 点常规伤害，并携带 200 点冰制层腐蚀值。僵尸目标通过默认无效的语义接口自行消费腐蚀，只能扣当前冰制装备耐久且不得溢出本体；未来冰墙建筑在自己的命中入口消费同一腐蚀值。植物和子弹不得识别具体冰制目标类型。
- 气象干扰由 Board 原子作废本轮寒潮预报并通知全部植物；它不改变已经锁定的真实寒潮计划、温度或寒潮倒计时。干扰状态随 Board 入档，新一轮寒潮计划生成时清除。
- 融雪投手保存攻击周期、盐弹库存、待发弹型以及是否已经观察并领取当前预报；读档不得补发盐弹、重播装填反馈或把干扰后的预报重新激活。
- 美术复用卷心菜投手的完整动作时间线并使用主人确认的第 43 帧发射事件，但采用独立冷蓝植株、融雪弹、盐晶、卡图和命中特效资源；普通弹与盐弹的手持物、飞行物和命中反馈必须可辨。

### 伏霜雷

- 初始调参为 50 阳光、30 秒冷却、300 生命；准确预报预测所在格将进入冻土范围时完成校准，实际冻结后埋入并永久武装。
- 气象干扰只清除尚未兑现的校准；武装属于已提交埋伏，不随干扰、回暖或下一轮预报撤销。阶段进入植物快照，损坏档中的 `SPENT` 修复为仍可触发的 `ARMED`。
- 武装态不可啃食，首个活动、未魅惑且可受地面机关影响的碰撞目标触发；同帧多目标按最小僵尸 ID 选取，气球等飞行目标不触发。
- 引爆先打断尚未提交的动作，再结算 1000 点目标自有冰制层腐蚀和 600 点标准植物伤害；冰制层腐蚀不得溢出本体。对冰裂钻机可碎掉 900 点钻机层、中断蓄力且不生成地裂，普通杂兵会被炸倒。
- 休眠、校准、武装采用三张完整独立立绘而非换色；卡图、碎冰和霜环粒子均为独立资源。

### 警铃草

- 低费用、长冷却的即时植物；不造成伤害。
- 对一行发出脉冲，只打断尚未提交且剩余完成时间最短的一项特殊动作：上传干扰、钻孔、筑墙或当前锤击。
- 已经提交的预报失效、地裂、冰墙、雪橇冲撞或处决步骤不能回滚；动作主体存活后可以重新尝试。

### 炉芯花

- 175 阳光、20 秒冷却、300 生命的 3×3 支援植物；初始没有炉芯。
- Board 当前实际温度高于 0°C 时，每 10 游戏秒储存一枚炉芯，最多两枚；低于或等于 0°C 时暂停且保留已有炉芯与未完成进度，不依赖天气预报。
- 冰像处刑者准备为 3×3 内另一株植物建立冰封时，Board 在冰封提交前按稳定植物 ID 请求保护者。最早种下且有效的炉芯花消费一枚炉芯后，目标从未进入冰封、不受首锤伤害并继续正常行动；该处刑者的一次性特殊能力直接进入 `SPENT`，之后只作为普通步行/啃食僵尸。
- 炉芯花不能保护自己；已经冰封、停机、被压扁、被蹦极抓取或离开活动态的炉芯花不能充能或提供保护。重叠范围内后种的炉芯花只在前一株没有可用炉芯时接替。
- 只阻止新的冰像封存，不解救已经冰封的植物，不全局解冻、不开放冻土种植、不改 Board 温度，也不改变豌豆弹。
- 炉芯数量与未完成充能进度进入植物存档；读档只恢复状态，不重播充能或消费反馈。

## 僵尸教学边界

五种重点敌人为气象干扰僵尸、冰裂钻机、冰墙工程师、冰像处刑者和雪橇突击队。每关最多首次教学一种重点威胁；首次关使用精简池，综合前至少留出无同场复习。当前五株寒潮植物与五种重点僵尸均已落地；新组合仍应通过目标拥有的窄接口衔接，禁止在调用方堆具体类型判断。
