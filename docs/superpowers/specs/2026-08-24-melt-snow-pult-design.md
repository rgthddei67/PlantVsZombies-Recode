# 融雪投手设计规格

## 目标

融雪投手是 7-2 通关奖励、7-3 首次可用的寒潮投手。它以低于卷心菜投手的常规输出换取按准确寒潮预报获得的三发反冰资源，负责越过未来冰墙并腐蚀冰制装备或建筑；气象干扰可以在发射前摧毁这份准备，但不能让植物完全停火。

## 基础数值与攻击

- 125 阳光、7.5 秒冷却、300 生命。
- 初始攻击周期 3.0 秒，后续周期在 2.86～3.0 秒之间随机；攻击速度、雨势行动倍率和停机规则沿用普通投手。
- 普通融雪弹与浓缩盐弹都造成 20 点常规伤害，飞行时间 1.2 秒、拱高 210px，并按目标公开水平速度预测落点。
- 植物复用卷心菜投手时间线，主人确认在全时间线第 43 帧发射。攻击开始时锁定弹型；第 43 帧只消费已经锁定的待发结果，不重新按天气判断。

## 预报装填

Board 的准确寒潮预报是唯一资格来源。每株植物保存 `observedColdWaveForecast`：

1. 预报首次变为有效且实例尚未观察本轮预报时，把 `saltAmmo` 设为 3，并标记已观察。
2. 在有效窗口中才种下的实例也会在第一次正式更新时获得三发。
3. 寒潮进入降温后，预报窗口结束，但已经获得的库存保留。
4. 新一轮寒潮计划生成后，Board 清除干扰标志；植物在新的有效窗口再次把库存补至 3，而不是在旧库存上累加。
5. 攻击起手有库存时先扣一枚并设置 `saltShotPending=true`；发射后清除 pending。无库存时继续发射普通融雪弹。

## 气象干扰

Board 新增 `DisruptColdWaveForecast()` 作为未来气象干扰僵尸的唯一提交入口：

- 只有当前准确寒潮预报有效时才能成功；重复调用或其他阶段 no-op。
- 成功后把本轮预报标记为已干扰，使 `HasColdWaveForecast()` 立即变为 false，但不修改寒潮强度、最低温、阶段时长、冻融线变体或当前温度。
- 以稳定植物 ID 快照调用 `Plant::OnColdWaveForecastDisrupted()`。基类默认 no-op；融雪投手清空 `saltAmmo` 和尚未发射的 `saltShotPending`，并立即恢复普通手持弹表现。
- 已经生成的盐弹是独立对象，不受后续干扰影响。
- `coldWaveForecastDisrupted` 进入 Board 快照；旧档缺字段时使用中性 `false`。新一轮 `RollNextColdWave()` 清除它。

## 腐蚀语义

盐弹保存独立 `BulletType`，常规伤害仍走现有 `TakeProjectileDamage` 分层链。随后向命中目标调用 `ApplyWinterCorrosion(200)`：

- `Zombie` 基类默认返回 false 且不扣任何额外生命。
- 未来冰制装备品种覆写此接口，只扣当前冰制层，最多扣到 0；未消费的腐蚀绝不溢出到头盔、护盾之外或僵尸本体。
- 返回值只表示本次是否确实腐蚀了冰制层，可供目标专属音画使用；普通盐晶命中特效始终由子弹负责。
- 未来冰墙不是僵尸，由建筑自己的碰撞入口读取盐弹的 `GetWinterCorrosionDamage()`，遵守同样的不溢出契约。

## 资源与表现

- 独立 `MeltSnowPult.reanim` 沿用卷心菜投手轨道结构，以冷蓝叶片、灰蓝盐筐和融雪弹替换原部件。
- 普通融雪弹为蓝灰色湿雪团，盐弹为高亮白色盐晶；待发盐弹时替换手持物贴图，发射或干扰后恢复普通融雪弹。
- 两种弹丸分别使用独立命中特效。盐晶命中以白蓝晶屑和短促盐雾表现，不借用卷心菜绿色碎屑。
- 资源由仓库内可复现 PowerShell 脚本从现有投手素材生成；只写 `build/clang-release/resources` 权威目录。

## 存档与兼容

- 植物保存 `shootTimer`、`shootInterval`、`saltAmmo`、`saltShotPending` 和 `observedColdWaveForecast`。
- Board 保存 `coldWaveForecastDisrupted`。
- 子弹现有通用存档已保存 `type/poolType/damage/trajectory`，新增两种弹型沿该合同恢复；对象池 `Reset()` 必须恢复各自纹理、常规伤害、腐蚀能力和轨迹中性状态。
- 新字段都有中性默认值，因此不提升 schema 版本。

## 验证边界

- 资源闭环：卡图、reanim、普通/盐弹贴图和两种粒子键均可加载。
- 数值与奖励：125/7.5/300、普通 DPS 画像、7-2 奖励。
- 攻击：第 43 帧发射、普通/盐弹类型、20 点常规伤害、200 腐蚀值和解析抛物线。
- 装填：预报前 0、进入预报补 3、连续攻击递减、正常进入寒潮后保留、新轮只补至 3、窗口内新种补 3。
- 干扰：清库存与待发盐弹、普通攻击不中断、已在途盐弹保留、重复干扰 no-op、真实寒潮计划不变。
- 快照：预报中部分库存、待发盐弹、干扰后以及在途盐弹均保持唯一结算。
- 默认实例与 `-NoInstance`：站位、影子、待机、普通发射、盐弹手持/飞行/命中截图一致。
