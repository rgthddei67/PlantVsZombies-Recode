# 劫持者僵尸设计规格

## 目标

在第六大关黑夜屋顶加入 `ZOMBIE_HIJACKER`（劫持者僵尸）。它本身按普通僵尸速度与啃咬行动，但能在黑夜屋顶雷荷达到 75% 时被雷荷系统锁定，并在本轮满电放电前把自身当前生命值转化为一次全场处决线。

该机制必须满足三条底线：

1. 劫持者是正常波次单位，不由 75% 阈值凭空生成；75% 只从已经在场的候选中锁定一只。
2. 处决目标集合在放电前同一帧冻结，再批量结算，不能受遍历顺序、普通放电先后或连锁触发影响。
3. 常态查询使用专用弱索引与实体 ID 直查；禁止为 UI、描边或锁定候选每帧扫描全体僵尸/植物。

## 数值与出怪

| 项目 | 设计值 |
|---|---:|
| 本体基础生命 | 1000 |
| 首次锁定生命增量 | 当前与最大本体生命各 +1000，单实体只应用一次 |
| 场上有效劫持者雨中雷荷增量 | +4.1 点/游戏秒，多只不叠加，晴天为 0 |
| 普通啃咬伤害 | 50 |
| 移动速度 | 普通僵尸速度 |
| 出怪成本/权重 | 2000 |
| 每波普通上限 | 2 |
| 成功处决后的刷新冷却 | 后续 2 个完整正式波次 |
| 6-4 教学波 | 第 7 波保证 1 只，计入上限并消耗整波预算 |
| 普通随机可用 | 第 9 波起 |
| 生存模式解锁 | 第 15 轮 |
| 生存模式处决线上限 | 1200 |

6-4（内部关卡 49）当前出怪池为普通、路障、铁桶、铁门、粉橄榄、蹦极与劫持者；第 7 波仍以固定单体教学保证首次机制可读。6-5（内部关卡 50）使用普通、路障、铁桶、橄榄球、投篮车、绝缘者与劫持者形成组合压力。

第 7 波保证生成只适用于 6-4：该波直接生成一只劫持者，不再用剩余预算补其他僵尸。正常生成仍由第 9 波的 `appearWave`、2000 成本与每波上限控制。

只有劫持者真正到达放电处决边沿时才启动刷新冷却：立即封锁当前波余下的正式劫持者候选，并完整跳过后续两波，最早在第 3 波恢复。冷却候选由正式 `ResolveWaveZombieType` 返回失败哨兵，调用方继续抽取其他类型且不消耗点数预算；直造、预览和读档恢复不消费冷却。提前击杀、掉头或其他取消路径不启动冷却。6-4 第 7 波固定教学不受既有冷却阻止；冷却剩余波数和当前波封锁标志由 Board 持有并入档，生存换轮不得清零。

## 雷荷锁定与时序

### 75%：候选锁定

雷荷在 `CHARGING` 阶段首次从低于 75 跨到 75 或以上时，从当前专用候选索引选择一次：

- 仅考虑已激活、非预览、非垂死、有头、生命大于 0 的劫持者。
- 比较当前可计处决生命，选择最高值。
- 最高值并列时按实体 ID 排序后，用 `GameRandom` 在并列集内随机一次。
- 立即把结果实体 ID 写入 Board 状态；同一次充能不重选。
- 阈值时没有候选则记为本轮“已尝试但未选中”，后来新生成的劫持者不能补选。

首次锁定会把被选中者的当前与最大本体生命各增加 1000；增量标志随实体存档，读档恢复锁定展示时不得重复叠加。锁定后的处决线包含这份当前生命，并继续随承伤实时下降。

只要场上至少存在一只仍满足候选门禁的劫持者，雨势对雷荷的基础正向输入额外增加固定 4.1 点/游戏秒；多只不叠加，晴夜仍只执行原 0.5 点/秒漏电。该增量由 Board 每帧通过劫持者专用弱索引的首个有效候选查询派生，不复制到实体、也不新增存档字段。

### 100%：预警与放电

- 锁定者仍存活且有头：满电后进入固定 7.0 秒全场预警。
- 没有有效锁定者：沿用普通雷荷 4.0 秒预警。
- 7 秒预警最后 1.0 秒，被选中劫持者停止移动、停止啃咬并播放 `anim_hijack`；Board 计时是唯一结算权威。
- 冻结、黄油、麻痹不暂停 Board 预警或最后 1 秒计时，也不延后放电；这些状态仍约束它的普通移动与啃咬。
- 锁定者死亡或掉头立即取消处决资格，不转移、不重选；普通坡面放电按当前预警倒计时继续。
- 掉手不取消；接收器不可被磁力菇吸走。

普通放电的行选择、过载与基础伤害仍由既有 `NightRoofCharge` 处理。处决与普通放电共享同一结算边沿，但目标快照先按放电前状态生成，普通放电伤害不得把新目标压入处决线。

## 处决生命口径

### 劫持者处决线

处决线等于放电边沿被选中劫持者的当前可计生命：

```text
body current + helm current + shield current
```

不计气球等 `extra health`。冒险模式不截断；生存模式使用 `min(current countable health, 1200)`。

### 僵尸目标

- 全场所有活动、非垂死僵尸均参与，不按品种、空间层、飞行、地下或蹦极空中阶段豁免。
- 可计生命同样为本体、头盔与二类护盾当前值之和，不计气球额外生命。
- 当前可计生命 `<= 处决线` 即进入冻结目标快照。
- 劫持者自身不进入目标快照；成功时由专属自毁入口结算。
- 被处决的其他劫持者只走普通死亡入口，不触发新的处决。
- 魅惑不改变能力或目标阵营：魅惑劫持者仍无差别处决全场符合阈值的植物组与僵尸。

### 植物目标

按逻辑格组成处决组：

```text
normal plant current + pumpkin current
```

- 组生命 `<= 处决线` 时，普通植物与南瓜层一起进入目标快照并死亡。
- 花盆、睡莲承载层免疫且不计入组生命。
- 咖啡豆等短时 overlay 不独立计数；宿主死亡时沿既有宿主清理路径一并消失。
- 正在执行一次性技能的植物仍参与；谁先到正式结算边沿谁先结算。处决先到则其待执行动作随植物死亡取消；植物先杀死施法者则处决取消。

### 冻结快照与批量结算

放电边沿执行顺序固定为：

1. 读取施法者当前处决线。
2. 单次遍历全体植物和僵尸，生成植物 ID、僵尸 ID 的只读目标快照。
3. 立即让施法者逻辑死亡并失去碰撞/索敌资格。
4. 按快照逐个走各实体正常死亡入口；每个目标只结算一次。
5. 再结算既有普通雷荷放电目标与伤害。

步骤 2 是低频事件必需的唯一全场扫描；任何日常绘制或 UI 查询都不能复用这条扫描。

## 僵尸状态机

`HijackerZombie : Zombie` 不继承 `JackInTheBoxZombie`，仅复用独立复制后的动画时间线。

| 状态 | 行为 |
|---|---|
| `NORMAL` | 普通走路/啃咬，接受所有普通控制与伤害 |
| `LOCKED` | 75% 后仍按当前走路/啃咬行动，显示紫色锁定标记与低电流声 |
| `FINALIZING` | 最后 1 秒停止移动/啃咬，播放 `anim_hijack` |
| `RESOLVED` | 处决成功后逻辑死亡，专属紫闪后播放现有 `anim_death` |

Board 通过实体 ID驱动 `LOCKED` 与 `FINALIZING`；僵尸在死亡、掉头与读档修复时向 Board 暴露可验证状态，但不自行推进全局计时。

动画资源复制 `Zombie_JackBox.reanim` 为 `Zombie_Hijacker.reanim`，互不影响：

- `anim_idle`：0～16
- `anim_walk`：17～35
- `anim_eat`：36～50
- `anim_hijack`：51～66（由 `anim_pop` 政名，16 帧以 16 FPS 播放，恰好 1 秒）
- `anim_death`：67～89
- `_ground`：17～35

沿用同一时间线已经验证的啃咬命中帧 45 与死亡回收帧 89。处决本身不注册动画帧事件，由 Board 最后 1 秒计时边沿触发。

## 断肢、断头与死亡表现

- 断头：隐藏 `anim_head1` / `anim_head2`，发射包含护目镜的完整专属头部粒子；头部丢失立即取消处决。
- 断臂：隐藏外侧下臂/手并切换专属残肢贴图，发射专属手臂粒子；能力不取消。
- 接收器固定在胸前，天线/线圈在剩余手臂可触达的位置；不实现磁吸接口。
- 成功处决：施法者当帧失去碰撞与索敌资格，发射紫色电气闪光，然后播放既有 `anim_death`；不生成焦黑残骸，也不瞬间消失。
- 被处决目标：同帧各自发射短紫色电气闪光，再进入该对象既有正常死亡路径；不强制灰烬状态。

## 视觉、声音与 UI

造型以小丑动画骨架为基础，但全部关键部件使用独立资源：

- 盒子改为胸挂紫黑接收器，中心为高亮紫色电荷核心。
- 手柄改为铜色线圈与短天线；打开态改为发光核心和伸缩特斯拉叉。
- 头部佩戴粗框电工护目镜/小电表元素。
- 服装为深紫电工作业服，配氧化铜护片；保持低分辨率清晰色块。

最终 reanim 部件必须达到现有正式僵尸资产的绘制完成度，禁止使用纯色矩形、单线圈或儿童画式占位图：接收器表现外壳厚度、铜边、铆钉、玻璃核心、内部电弧与磨损；线圈表现多匝铜环、绝缘握柄和连接线；护目镜表现镜框厚度、镜片高光与小电表；衣服保留布料褶皱、破边、补丁和铜扣。细节在高分辨率母版中完成，再以最终游戏尺寸检查轮廓和明暗层级；微小噪点可以舍弃，但不能把结构退化为基础几何占位。

75% 锁定显示独立紫色标记；100% 后警报增强，最后 1 秒亮度和频率再次提升。普通状态不播放持续声：

- 75%：低电流 hum 循环。
- 100%：hum 增强并加入周期警报脉冲。
- 最后 1 秒：提高音调/急促度。
- 取消或结算：立即释放循环声。
- 成功处决提交：与普通放电雷声同帧额外播放一次短促碎裂声；无论目标数多少只播一次，取消时不播。

天气面板在有效锁定期间显示 `处决线：N`。每个实体在自己的既有绘制入口按 O(1) 阈值判断叠加细紫色脉冲描边，最后 1 秒更亮；植物按所在格的 normal+pumpkin 组值判断。禁止为描边另开全场列表或每帧 `GetAll*IDs()`。

## 专用索引与性能契约

`EntityRegistry` 新增按 ID 有序的劫持者弱索引：

- `AddZombie` 和 `AddZombieWithID` 都以相同 ID 登记或覆盖。
- 非劫持者覆盖同一 ID 时撤销旧登记。
- 既有 30 帧清理周期移除过期弱引用。
- 75% 锁定只遍历该稀有候选集；并列集按 ID 排序后随机。
- Board 保存选择 ID，面板、绘制与状态投影均通过 `GetZombie(id)` O(1) 读取。

只有真正处决发生的单帧允许一次 `GetAllPlantIDs()` + `GetAllZombieIDs()` 快照扫描。不得新增每帧全类型扫描。

## 存档合同

Board 额外保存：

- 本轮是否已经跨过 75% 并完成选择尝试。
- 已锁定劫持者实体 ID（无则为 null ID）。
- 当前预警是否使用劫持者 7 秒时长。
- 当前是否已进入最后 1 秒。

Hijacker 保存自身 `LOCKED/FINALIZING/RESOLVED` 展示状态和循环声声明所需信息；读档后以 Board 的选择 ID 与阶段为权威修复不一致组合：

- Board 选择 ID 不存在、已垂死或无头时，取消处决但保留普通放电流程。
- `FINALIZING` 只在 Board 仍处于对应预警且剩余 `<=1s` 时恢复。
- `RESOLVED` 不得恢复成可行动实体。
- 不保存声音声道；读档后根据权威状态重新声明或释放循环声。

实体 ID 必须在 `CreateZombieWithID` 登记完成后再恢复 Board 交叉引用；快照往返验证不能发生重选。

## 资源注册闭环

- `Zombie_Hijacker.reanim` 进入 manifest，并在 `resources.xml/<Reanimations>` 注册 `ZombieHijacker`。
- `ResourceKeys` 增加明确的 `REANIM_HIJACKER_ZOMBIE = "ZombieHijacker"` 与新增位图键。
- 新 reanim 部件 PNG 位于 `resources/image/reanim/`，由 manifest 扫描形成稳定 `IMAGE_*` 键。
- 紫色闪光与专属头/臂粒子 XML 位于 `resources/particles/config/`；如使用粒子专用 PNG，必须在 `<ParticleTextures>` 注册。
- AutoTest 同时断言 `HasReanimation`、每个新增纹理 `GetTexture(key,false)` 与粒子效果实际计数/包围盒。

## AutoTest 验收矩阵

1. 资源与普通行为：生成、走路、啃咬 50、断臂/断头、死亡、魅惑后技能保留。
2. 75% 锁定：最高可计生命、并列 ID 排序后随机、无候选不补选、新生成不参与。
3. 取消：死亡、掉头取消；断臂、冻结、黄油、麻痹不取消；取消后普通放电继续。
4. 处决口径：护具计入、气球 extra 排除、飞行/地下/蹦极参与、魅惑无差别、巨人无品种免疫。
5. 植物分组：normal+pumpkin 合计、承载层免疫、overlay 随宿主、一次性植物竞态。
6. 同帧快照：普通放电后新降到阈值的目标不被追加处决；其他劫持者不连锁。
7. 生存上限：轮次与词条放大后处决线最多 1200；第 15 轮前后出怪池边界。
8. 出怪：6-4 第 7 波单只保证、第 9 波普通可用、每波最多 2、成功处决后本波余下候选与后续两波封锁、第三波恢复、6-5 配池。
9. 存档：75% 锁定、7 秒预警、最后 1 秒与两波刷新冷却往返，实体 ID 与目标不重选，生存换轮不清冷却。
10. 性能：状态投影导出专用候选数与锁定 ID；静态审计 UI/Draw 不调用全量 ID 枚举，运行时以大量普通僵尸证明锁定查询不随总量线性增长。
11. 资产完成度：逐张检查最终尺寸部件及完整僵尸合成；接收器、线圈、护目镜和服装必须仍能看出材质、层次和磨损，不接受纯色矩形或单线占位。

最终可见验证在 `clang-release`、当前桌面窗口完成，同时检查退出码、`run.log`、状态 JSON、断言与同步截图。
