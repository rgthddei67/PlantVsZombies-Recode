# 忧郁菇（6-2 奖励）设计规格

## 目标

- 冒险 6-1 保持无植物奖励，6-2 奖励原版紫卡植物 `PLANT_GLOOMSHROOM`。
- 忧郁菇是大喷菇的 150 阳光升级，卡片冷却 50 秒，生命 300。
- 行为遵循 C# 原版：每 2 秒发起一次攻击，在一次攻击中向周围三行的 3×3 格近似范围造成四段各 20 点伤害。
- `build/clang-release/resources/reanim/GloomShroom.reanim` 是主人提供的转换版动画；逻辑不依赖单帧事件。

## 升级种植

- 集中提供 `GetUpgradeBasePlantType` / `IsUpgradePlantType`，供 Board 与卡片 UI 共用，首个映射为 `GLOOMSHROOM -> FUMESHROOM`。
- `Board::CanPlantAt` 只有在目标格普通层存在活动、未被蹦极抓取的大喷菇时才允许种植忧郁菇。
- 正式创建时先捕获大喷菇睡眠状态和咖啡豆唤醒剩余时间，再用忧郁菇原子替换普通层；承载层的睡莲/花盆以及南瓜层不变。
- 新忧郁菇继承大喷菇的睡眠状态：清醒大喷菇升级后继续清醒，睡眠或唤醒中的大喷菇保留剩余唤醒时间。升级重置主体生命为 300。
- 卡片在场上没有可升级大喷菇时显示为不可用，和原版 `PlantingRequirementsMet` 一致。

## 攻击

- 基础攻击周期 2.0 秒；攻击倍率只推进攻击计时，并同比例加快 `anim_shooting`，不修改全局 `DeltaTime`。
- 原版射击计数从 200 倒数：云雾在 136/108/80/52，伤害在 126/98/70/42。因此从攻击开始计时：
  - 云雾：0.64、0.92、1.20、1.48 秒；
  - 伤害：0.74、1.02、1.30、1.58 秒。
- 每段伤害扫描自身行及相邻一行，横向范围以逻辑格中心为锚点，左右各 1.5 格（`CELL_COLLIDER_SIZE_X * 1.5`）；命中以僵尸碰撞矩形横向重叠判定。
- 跳过魅惑和不可被地面投射物命中的目标，并复用 Board 的雾中索敌资格；原版范围伤害仍可命中尚未倒下的无头僵尸。
- 每个目标独立结算大喷系伤害修正；加固铁门只让自身门盾吸收溢出，不会阻断环形攻击命中其他僵尸。
- 每次视觉时点发射 `GloomCloud`，锚在植物公共视觉中心；原版东、南、北、西与四个斜向共八个炮口各自作为起点，再沿对应方向向外扩散，不从植物中心聚成一团。

## 动画与资源

- 注册 `ANIM_GLOOMSHROOM`、`IMAGE_GLOOMSHROOM` 与 reanim 键 `GloomShroom`。
- `resources.xml` 注册主人提供的 reanim；卡图与 reanim 分件贴图必须通过 `HasReanimation` / `GetTexture(key, false)` 资源断言。
- 忧郁菇作为升级紫卡，卡片合成层使用主人提供的 `seeds.png` 第二格紫色底板；植物本体图仍独立叠加，普通卡底板不变。
- 使用 `anim_idle`、`anim_sleep`、`anim_shooting`；不新增 `AddFrameEvent`，也不依赖主人尚未确认的发射帧号。
- 默认以转换文件的 12 fps 为基础，射击轨道使用 `14/12` 速度覆盖以匹配原版 14 fps，并乘当前攻击速度倍率。

## 存档

- 保存攻击周期计时、是否正在攻击、攻击内已推进时间，以及下一次云雾/伤害序号。
- 读档钳制所有字段；若旧存档缺字段，回到安全待机状态。读档中途攻击不重放已发生的段数，剩余段继续按原时序执行。
- 通用植物存档继续负责睡眠、唤醒倒计时、停机和 Animator 一次性轨道。

## AutoTest 验收

- 冒险奖励：6-1 无奖励，6-2 为忧郁菇，6-3 仍无奖励。
- 升级规则：空格、其他植物与被蹦极抓取的大喷菇拒绝；大喷菇可升级；睡莲/花盆/南瓜叠层保留；清醒和唤醒状态继承。
- 战斗：前后与上下相邻行范围内目标各承受 4×20，范围外不受伤；魅惑目标不受伤；加固门目标采用大喷系盾牌语义但不阻挡其他目标。
- 倍速：攻击倍率同时缩短四段时间间隔和动画时长，不改变单段伤害。
- 存档：四段攻击中途保存并读取，只继续剩余段；待机计时连续。
- 资源与画面：默认 Vulkan 完整专项及 `-NoInstance` 的 Vulkan/OpenGL 粒子专项留存截图，确认本体、花盆/睡莲、南瓜叠层和孢子环位置。
