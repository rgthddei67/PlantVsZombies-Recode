# 高坚果设计

## 目标

实现经典 `PLANT_TALLNUT`，复用主人已导入的 Tallnut 卡图、reanim 与五张部件图，并补齐坚果家族的啃食碎屑。

## 数值与表现

- 高坚果：125 阳光、30 秒冷却、8000 生命。
- 卡槽与选卡界面的高坚果卡图在通用卡图倍率之上再乘 `0.70`，从既有卡图矩形中心缩放后上移 5px，避开底部阳光文字；草坪本体保持原尺寸。
- 待机使用 `anim_idle`；生命降到不高于 2/3、1/3 时分别把 `anim_idle` 换为 `Tallnut_cracked1/2`。
- 普通坚果保留 4000 生命，并修正其裂纹图资源键。
- 两种坚果在每次僵尸正式啃食命中时喷出 `WallnutEatSmall`；首次跨入两档裂纹状态时喷出 `WallnutEatLarge`。
- 高坚果影子按原版横向放大 1.3 倍；本体和影子最终位置以可见截图校准。

## 跳跃交互

| 跳跃者 | 被高坚果挡住后的行为 |
|---|---|
| 普通撑杆 | 先播放 `anim_jump`，在原版 60% 检查点被挡，随后弃杆转为步行/啃食并播放 `Bonk`、喷出 `TallNutBlock` 星光 |
| 精英撑杆 | 同上；仍在当前位置召唤一只普通撑杆，再对高坚果造成 800 点僵尸来源碰撞伤害，精英自身不扣血 |
| 海豚僵尸 | 在既有 30% 跳跃检查点中止越障、弃豚落在高坚果右侧，播放同一音画反馈 |

撑杆接触植物时只锁定当前格顶层目标并起播 `anim_jump`，到动画进度 60% 才查询一次 `Plant::BlocksZombieJump`；阻拦前不得播放 Bonk、喷星星或结算碰撞伤害。跳跃目标 ID 与“是否已经检查”进入快照，读档后继续原动画进度，不能直接完成跳跃绕过高坚果。精英在阻拦终态恢复后先召唤普通撑杆，再通过植物的正式 `TakeDamage(800, ZOMBIE)` 链伤害高坚果，因此普通关从 8000 降至 7200，生存词条仍按统一的僵尸增伤/植物韧性规则生效。僵尸状态机不依赖 `TallNut` 具体类型。

## 生命周期与验证

- 不新增动画帧事件。
- 高坚果额外状态仅有从生命派生的裂纹阶段；读档通过恢复后的生命直接重建材质，不重播碎屑。
- AutoTest 覆盖注册/生命/裂纹、撑杆阻拦前 `JUMPING/anim_jump` 且无反馈、跳跃快照继续、阻拦后零实际跳距、精英自身 450 血不变且高坚果承受 800、精英召唤、海豚阻挡、`Bonk` 请求计数，以及三种粒子的活动与最终绘制探针。
