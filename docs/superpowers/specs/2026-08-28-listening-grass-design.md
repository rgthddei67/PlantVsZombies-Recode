# 听雪草设计规格

## 定位与数值

- `PLANT_LISTENINGGRASS` 是 8-1（内部关卡 64）通关奖励，从 8-2 起可使用。
- 75 阳光、20 秒卡片冷却、300 生命；普通陆生植物，不攻击、不生产阳光。
- 单株只处理本行地下威胁和雪穴，种下时立即就绪；成功响应后进入 6 游戏秒内部冷却。

## 侦听结算

听雪草就绪时先按距离房屋最近、稳定僵尸 ID 破同距的顺序检查本行敌对僵尸，并依次调用目标自有的
`ForceSurfaceFromGroundHazard()`。首个返回成功的目标被迫出雪；植物不识别潜雪僵尸类型，不造成
伤害，也不清除目标的冻结、黄油、麻痹或减速。潜雪僵尸继续拥有取消 150 点冲击和半血后 3 秒
重试的权威语义。

若本行没有任何僵尸接受迫出请求，听雪草再调用 `Board::SealSnowHole(row)`。形成中和已成形雪穴
都可封闭；已经进入 1 秒预警事务的僵尸保留事务，并在提交时按既有规则退回右侧出生。迫出和封穴
共享同一份 6 秒内部冷却，每次就绪最多成功一项。

侦听不是视觉自动索敌，也不创建弹体，因此不受极夜雪盲三格限制和垂直强风影响。魅惑僵尸不会
被选中；预览、停机、压扁、死亡等非活动状态不结算能力。

## 动画、音画与存档

- 独立 `ListeningGrass.reanim` 完整复用经典 `Umbrellaleaf` 的 `anim_idle`、`anim_block` 和七片叶轨，
  只派生青蓝覆霜材质；不新增动画帧事件。
- 玩法在检测成功的逻辑边沿立即提交，随后播放原版 `anim_block` 作为竖叶侦听反馈并自动回到待机。
- 迫出目标沿用潜雪僵尸自己的出雪音画；植物根部另播放短促听雪脉冲。封穴在原雪穴格中心播放
  独立的压雪粒子。
- 植物只保存 0～6 秒内部冷却；Animator 轨道由通用存档恢复，读档不得重播声音、粒子或再次响应。
