# 热感狙击僵尸设计规格

日期：2026-08-29

状态：主人已完成玩法定案，尚未实现

## 定位与投放

热感狙击僵尸是第八大关“极夜雪原”在 8-5 引入的部署反制型敌人。它不靠额外厚甲或移速压迫，而是在玩家成功种植后，让本行全部处于就绪状态的同类各自发射一枚热脉冲弹，迫使玩家预先布置拦截层、用低生命植物骗枪，并利用短暂装填窗口提交关键植物。

- 8-5：第 3 波独立保底首次出现；保底后才开放自然候选。每波最多 3 只，不设场上同时或全关累计上限。
- 8-6：从第 1 波起进入自然候选，第 2 波额外保底一只。每波最多 4 只，不设场上同时或全关累计上限，并开始与适应头盔僵尸组合。
- 冒险计数只在统一换波边沿清零；开发者直造、读档恢复和雪穴延迟事务不得重复消费或返还本波名额。
- 权重/点数成本为 3000，普通自然候选最早第 4 波；8-5、8-6 的独立保底不受该最早波次限制。
- 生存模式从第 17 轮进入候选，保留完整能力；8-5/8-6 的每波 3/4 只上限不套入生存模式。

## 基础数值与普通交互

- 本体生命：800。
- 独立防具：无。目镜、发射器和能源箱均为视觉装备，不提供额外生命层。
- 移动速度：普通僵尸基础速度的 0.8 倍。
- 啃食伤害：50。
- 断臂不影响热感射击；断头立即取消未离膛射击，并永久关闭能力。无头阶段继续沿用普通僵尸行动与流血。
- 可被魅惑。魅惑提交时取消未离膛射击并永久关闭能力，之后按普通魅惑僵尸向右移动和啃食；已经离膛的子弹不回滚。
- 大嘴花、缠绕水草、小推车、灰烬、普通伤害、减速、冻结、黄油和麻痹全部沿用普通僵尸规则。没有可供磁力菇吸取的装备。

## 种植触发范围

只有玩家通过卡片成功创建植物时才发布热感事件。普通植物、即时植物、南瓜、支撑植物、咖啡豆和紫卡覆盖都计入；读档恢复、关卡预放、僵尸搬运或释放、植物自身生成和形态变化均不触发。

模仿者只在最初种下时触发一次，伤害取其模仿目标的基础最大生命。同一稳定实体 ID 完成变身后仍是原触发植物，但变身本身不再次发布事件；若原实体已死或换成新 ID，新实体不继承原目标的特殊部署拦截资格。

同排每只处于就绪状态的热感狙击僵尸都会独立响应，没有行级共享冷却或齐射数量上限。瞄准和装填期间出现的新种植不排队，也不改变已有锁定。

## 瞄准、提交与装填

正式新生成的僵尸以完整 3 游戏秒装填状态入场；右侧出生与雪穴出生一致。预览不推进玩法状态，读档恢复保存的真实阶段和余时，不伪造首次装填。

1. 就绪僵尸收到本行种植事件后，立即锁定触发植物 ID、原行、原世界位置、射击方向和基础最大生命伤害。
2. 僵尸原子停止移动和啃食，进入 0.3 游戏秒瞄准前摇。期间其他种植不排队、不换目标；原植物被铲除、爆炸、变身或移动也不改变锁定位置。
3. 0.3 秒归零即为提交边沿：创建热脉冲弹，随后僵尸立即恢复普通移动，并进入独立 3 游戏秒装填。
4. 装填可在移动或啃食期间继续；完成时只恢复就绪，不追溯装填期间发生的种植。
5. 若射击抢占了啃食，离膛后不直接恢复旧目标 ID；仍处于接触范围时由下一逻辑步的普通碰撞重新开吃。

冻结、黄油和麻痹暂停瞄准与装填；减速按既有行动倍率延长它们的实际完成时间。死亡、断头和魅惑取消尚未离膛的射击。瞄准阶段同时暴露通用未提交动作接口：警铃草按既有“最短余时、稳定 ID”规则只取消一个候选，被取消者不发弹并立即进入完整 3 秒装填；已经离膛的效果不可中断或回滚。

## 热脉冲弹与拦截

- 速度：1800 像素/秒。配合 0.3 秒前摇，在当前极夜雪原最远合法种植距离上仍早于现有最快灰烬提交。
- 肩载发射器可双向旋转。植物在射手左侧就向左射击，在右侧就向右射击；强风不改变其行、方向或终点。
- 每发子弹从射手当前位置沿锁定方向飞向原植物位置，并以该位置为最远终点。原植物已经消失时仍飞至保存的位置后消散；绝不越过终点攻击更后方植物。
- 飞行路径中若先碰到其他可受击植物，立即对该植物结算伤害并消失，不再飞向原目标。
- 每发齐射弹独立重新解析路径。前一发击碎南瓜、坚果或其他拦截层后，后一发可继续命中刚暴露的下一层；前方坚果被击毁后，剩余子弹可继续飞向锁定终点。
- 同格拦截层级为南瓜外壳、普通植物、花盆或睡莲等承载层。咖啡豆等临时 overlay 不拦截；每发只伤一层。

## 伤害口径

伤害在瞄准开始时快照为触发植物的基础最大生命，不包含生存词条、临时强化或当前受伤状态。生存词条带来的额外生命与减伤仍在正式承伤时生效，因此强化植物可能存活。

热脉冲弹只有在命中保存的原触发植物实体时，才使用窄范围“部署拦截伤害”，绕过樱桃炸弹、火爆辣椒、清醒毁灭菇、寒冰菇等植物在能力提交前的临时充能无敌；它仍结算上述固定数值，不升级为无条件秒杀。沿途坚果、南瓜或其他拦截植物继续走普通植物伤害与防御规则。

原植物已经提交灰烬、冻结或其他一次性结果时，结果不可回滚；后续子弹只按当前路径命中其他拦截者，或在原位置消散。相同 ID 的模仿者变身继续拥有原目标资格，不同 ID 的替换植物只能作为普通拦截者承伤。

## 极夜天气交互

热感射击依靠新植物的热信号，不受白毛风三格雪盲限制，始终监听本行成功种植。热脉冲弹属于高速直射弹，不受强风偏行；温度、湿度和风速不额外修改伤害、前摇或装填。白毛风中仍必须保留清晰的锁定环、警报、曳光和命中反馈。

## 视觉与动画

中文名为“热感狙击僵尸”。主体复用普通僵尸行走、啃食、断肢、断头和死亡时间轴：

- 红光热感目镜使用命名静态 follower 跟随头部。
- 背部能源箱使用命名静态 follower 跟随身体。
- 肩载发射器使用独立子 Animator，包含待机、双向瞄准、开火后坐和装填表现。
- 玩法提交由 0.3 秒逻辑倒计时拥有，不新增动画帧事件；肩炮动画与权威计时同步。
- 能源灯从暗到亮显示 3 秒装填进度，控制状态暂停计时时视觉同步停住。断头后目镜隐藏、发射器永久熄灭；死亡时设备随本体保留至实体正式移除，不提供额外防具掉落。

射击反馈分为三段：

1. 0.3 秒瞄准时，原植物格出现红橙锁定环；每只就绪射手的目镜和枪口蓄亮，并播放短促警报。
2. 热脉冲弹使用亮白核心、橙红外焰、约 100 像素持续曳光和沿途火星，确保 1800 像素/秒下仍可辨认。
3. 命中植物时生成红白冲击环、火星和低烟，保留约 0.45 秒并播放独立重击声；原植物已经消失时，在终点生成较小的橙红空爆环，保留约 0.3 秒。残留效果只说明攻击来源，不延长伤害或碰撞。

## 存档合同

僵尸保存就绪、瞄准、装填或永久失效阶段及其剩余时间；瞄准态另保存原植物 ID、行、终点、方向和伤害快照。在途热脉冲弹保存射手原阵营、方向、速度、终点、剩余路径、伤害与原目标植物 ID。

加载只恢复目镜、能源灯、肩炮姿态和子弹位置，不重播锁定警报、枪声、命中或空爆反馈。原植物不存在时仍向保存终点完成射击，但不得把占据同一位置的新植物误认成原触发实体并绕过其正常防御。读档恢复植物和僵尸不得发布新种植事件。

## 教学与图鉴

8-5 开战前由戴夫明确提示：

> 那些红眼睛的家伙能感觉到新种下的植物！
>
> 先拿坚果挡住热脉冲，或者骗它开枪后趁装填赶快种！

图鉴公开同排全部就绪个体都会响应、伤害取基础最大生命、子弹可被沿途植物拦截，以及 3 秒装填。8-6 不重复戴夫教学。

## 未来实现与验证边界

实现前仍需由主人审核最终分件母图和实机低分辨率合成；玩法不需要新增帧事件，因此无需另报开火帧号。实现必须覆盖资源注册、自然/雪穴出生、同排多只齐射、双向拦截、组合植物逐层受伤、四类即时植物部署拦截、模仿者同 ID 变身、控制与警铃草中断、断臂/断头/魅惑、白毛风、8-5/8-6 上限、生存资格，以及瞄准、僵尸、植物和在途子弹快照往返。

可见专项须在默认 `clang-release` 路径同步验收锁定环、快速曳光、命中残响、终点空爆、双向肩炮、装填灯和断头熄灭；未修改渲染后端时不机械增加 `-NoInstance` 或 OpenGL 矩阵。
