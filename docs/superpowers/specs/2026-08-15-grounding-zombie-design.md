# 接地僵尸设计规格

## 目标

在第六大关黑夜屋顶加入 `ZOMBIE_GROUNDING`（接地僵尸）。它使用普通路障僵尸的骨架、动作与基础本体，但佩戴带铜制短天线的电紫色路障；只要天线仍在，黑夜屋顶雷荷进入满电预警时就可能把本轮闪电引到自己所在行。

引导后的放电只保留对植物的停机效果，对全部僵尸无伤害、无麻痹。被选中的接地僵尸在放电瞬间仍存活且天线路障仍在时，获得 10 游戏秒硬控免疫。

## 数值与外观

| 项目 | 设计值 |
|---|---:|
| 本体生命 | 270 |
| 天线路障生命 | 430 |
| 总生命 | 700 |
| 啃咬伤害 | 50 |
| 移动速度 | 普通僵尸速度 |
| 硬控免疫时长 | 10 游戏秒 |

路障主体使用深电紫到靛紫色，保留原路障的明暗、磨损和破损阶段；顶部安装铜色短天线、绝缘座和浅紫发光端点。三张护具阶段图分别对应完好、重度破损和临界破损，天线随路障一起消失。

动画完整复用 `ConeZombie.reanim` 的普通走路、啃咬、死亡、断肢与断头时间线，不添加动画帧事件。复制出的 `GroundingZombie.reanim` 只替换三张路障部件图，避免改变普通路障僵尸。

## 统一满电推演与结果锁定

雷荷从充电进入满电预警时执行一次统一路线决策，而不是先随机一行、再由接地僵尸覆盖：

- 每个合法逻辑行生成一个“普通行放电”候选，正式效果为该行植物停机，同时该行僵尸承受既有伤害与麻痹。
- 每只有效接地僵尸生成一个“接地引导”候选，锁定它当时所在行；正式效果为该行植物停机、全部僵尸免受本次放电，并在放电时尝试向选中者发放强化。
- 开启轻量蒙特卡洛 AI 时，全部普通候选和接地候选使用共同随机数一起比较。接地僵尸存在不代表必定引导；只有避免友军伤害与强化收益确实胜过普通路线时，模拟才选择它。
- 没有有效接地僵尸时，仍在全部普通行候选之间推演选行，因此黑夜屋顶雷荷本身不再随机选行。
- 关闭开关、阵营模型不适用或推演失败时，保留低配规则：有有效接地僵尸则在稳定 ID 候选集中用正式 `GameRandom` 均匀选择一只并引导；否则沿用正式 `GameRandom` 随机行。

接地候选资格与锁定规则如下：

- 候选必须已激活、未垂死、本体生命大于 0，并且仍有 430 生命体系的天线路障。
- 魅惑不改变资格；魅惑接地僵尸仍可引雷。
- 满电边沿独立使用 32 次 rollout、10 秒时域和共享的详细实体上限，选择对僵尸方未来推进最有利的路线。
- 推演必须表达延迟放电、目标行植物 8/20 秒停机、现有同格/接地保护、候选路障能否活到放电，以及成功后 10 秒硬控免疫；不得用立即伤害或只数植物的近似替代。
- 植物画像同时表达寒冰豌豆/冰气菇/冰瓜的减速频率、玉米投手黄油频率及未来其他冻结/麻痹能力；已进入 `anim_idle` 前摇的寒冰菇作为确定的待结算控制事件进入时间线。当前减速、冻结、黄油、麻痹和临时/永久免控余量一并快照，避免把免控强化只当作静态生命加分。
- 蒙特卡洛候选与快照都按稳定实体 ID 排序，使用共同随机数公平比较；最高分并列由局部 seeded RNG 选择，不消费正式 `GameRandom`。
- 选中时立刻把实体 ID、当前行和“本轮受引导”写入 Board；公开结果后不再重抽。
- 选中者随后换行、死亡、掉路障，或新接地僵尸后来入场，都不改变本轮已经锁定的放电行与受引导结果。
- 满电时没有候选则沿用既有随机行放电；本轮预警中不补选。

接地僵尸只为统一路线决策增加引导候选，不改变雷荷积累速度、过载倍率、预警时长或植物保护规则。

## 引导放电结算

受引导放电沿用既有同一行植物停机流程：

- 普通格植物停机 8 秒。
- 湿润坡面植物停机 20 秒。
- 接地菇、避雷花盆和现有同格保护规则保持不变。
- 不对任何僵尸造成伤害或麻痹，包括被选中的接地僵尸、绝缘者、魅惑僵尸和同排其他僵尸。

放电瞬间通过锁定实体 ID 查找选中者。只有该实体仍存活、未垂死且天线路障仍在时，才向它发放 10 秒强化；资格失效不重选，也不取消本轮植物专属放电。

## 通用控制免疫框架

在 `Zombie` 基类建立可扩展的按控制类型计时框架，而不是把判断写死在接地僵尸内。初始控制类型包括：

- `SLOW`：减速。
- `FROZEN`：冻结定身。
- `BUTTER`：黄油定身。
- `PARALYSIS`：麻痹定身。

每种控制拥有独立剩余时间，可由位掩码批量发放和查询；同时保留虚拟的永久免疫入口，供未来僵尸品种复用。接地强化使用 `FROZEN | BUTTER | PARALYSIS`，明确不包含 `SLOW`。

强化触发时立即清除已有冻结、黄油和麻痹：

- 冰冻伤害照常造成，20 秒减速尾巴照常施加，但不进入冻结定身。
- 黄油弹命中伤害照常造成，但不附加黄油定身。
- 麻痹入口不再附加麻痹定身。
- 减速可在强化期间正常施加、保留和刷新。

10 秒强化一旦发放，就属于僵尸本体而不是路障。之后天线路障被打掉，剩余强化不会被取消；僵尸死亡才随实体生命周期结束。剩余时间进入僵尸存档，旧档缺字段时按 0 恢复。

## 索引、存档与恢复

`EntityManager` 维护按 ID 有序的稀有引雷候选弱索引：

- 正常生成与指定 ID 读档都登记；过期引用随既有周期清理。
- 候选选择只遍历该稀有索引，不在满电或绘制时扫描全部僵尸。
- 类型通过虚拟能力接口声明资格，便于未来其他引雷僵尸复用。

Board 额外保存本轮是否受引导、锁定实体 ID 和锁定行。读档时只恢复交叉引用，不重新抽签；锁定实体缺失或已失去路障时，仍保留已锁定行和植物专属结算，只是不再发放强化与附着天线电弧。

## 小型引雷动画

不新增 reanim 帧事件和持续粒子实体。`GameScene` 根据 Board 锁定 ID 在现有雷荷绘制中叠加程序化短电弧：

- 预警期在天线端点附近绘制 2～3 段约 20～30 像素的紫白短弧，低频脉冲。
- 放电瞬间把短弧提亮，并用一条短引线连接到既有本行闪电表现。
- 天线路障已掉落或实体不存在时不再画附着电弧，但锁定行闪电照常发生。
- 闪烁相位由 Board 帧数和实体 ID 派生，不新增需要存档的视觉状态。

## 资源与掉落

- `GroundingZombie.reanim` 复制普通路障僵尸资源并替换三张电紫天线路障图。
- `GroundingZombieConeOff.xml` 复用普通路障掉落参数，但引用接地僵尸的临界破损护具图。
- 位图由可复现 PowerShell/System.Drawing 脚本从现有三张路障图确定性变色并绘制天线，生成后锁定 SHA-256。
- `resources.xml`、manifest、`ResourceKeys`、工厂注册与 AutoTest 必须形成文件到实际运行键的闭环。

## 出怪编排

接地僵尸在 6-8 首次作为教学敌人出现，6-9 进入第六区域综合池；生存模式第 14 轮起开放。默认出怪成本 1800、普通随机第 5 波起、每波最多 2 只。6-8/6-9 都保留各自既有完整敌人池并追加接地僵尸，避免为教学删掉已经建立的第六区域组合压力。

## 性能预算

正式配置为每候选 32 次 rollout、10 秒时域、0.25 秒步长，即每个候选 1280 个轻量时间步，另有一份共享基线。五行加一只接地僵尸共 6 个候选时，2026-08-15 `clang-release` 最终专项状态记录单次满电决策 288 微秒；每多一只引雷候选近似线性增加一份 1280 步，按该夹具约 0.04ms。该开销只发生在满电锁路边沿，不进入逐帧更新。

## AutoTest 验收矩阵

1. 基础：270 本体、430 路障、50 啃咬、普通速度、三阶段护具、掉落、断肢断头、魅惑。
2. 资源：默认与 `-NoInstance` 均断言 reanim、三张护具图和掉落粒子实际可取。
3. 选择：全部普通行与稳定 ID 接地候选、32 次 rollout、普通友伤与引导免伤、延迟停机评分、并列局部随机、开关关闭时随机回退、魅惑可选、预警中新候选不补选。
4. 锁定：换行、死亡、掉路障都不改已经锁定的行和受引导结果。
5. 放电：目标行植物按 8/20 秒停机与既有保护规则结算；所有僵尸生命和麻痹状态不变。
6. 强化：有效选中者获得 10 秒；立即清除三类硬控；冻结保留伤害与减速、黄油保留命中伤害、减速正常生效。
7. 掉帽：强化发放后打掉路障，剩余免控仍递减；下一轮不再成为候选。
8. 存档：预警锁定与强化计时中途往返，不重抽、不改行、不丢计时。
9. 出怪：6-8/6-9 池、生存解锁和每波最多 2 只。
10. 可见：当前桌面 `clang-release` 截图确认紫色天线路障、破损阶段、掉落物与小型引雷动画。

AutoTest 同时导出本轮选择模式、rollout 数、候选数、样本实体数和最佳分数；纯数值测试锁定“高价值停机行胜出”“保护使行收益下降”“同收益不消费正式 RNG”以及详细实体上限。
