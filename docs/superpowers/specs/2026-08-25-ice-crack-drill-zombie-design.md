# 冰裂钻机僵尸设计规格

## 定位与教学

冰裂钻机是第七大关 7-4 首次登场的“读冻土并中断蓄力”教学敌人。它不是冰墙工程师的高血换皮：完整钻机层带来一眼可辨的横向大钻头、动力背包、飞轮和排气结构，并直接决定它能否制造地裂。

7-4 使用精简池单独教学冰裂钻机；7-5 与既有雪橇/冰墙形成第一次组合，7-8 再复习，7-9 进入期末综合。每个正式波次最多生成三只冰裂钻机；这是“每波上限”，不是全关累计上限。

## 状态机

1. `MOVING`：复用路障僵尸的行走、啃食、断肢断头和死亡时间线；钻头以慢速四相循环巡航。
2. `CHARGING`：完全进入草坪且当前所在格为真实冻土后停步，播放 5 游戏秒高速钻进循环。冻结、黄油和麻痹会自然暂停倒计时和动画。
3. `SPENT`：倒计时归零是唯一提交边沿；提交时生成独立同行地裂，僵尸恢复行走且本实体不再重复蓄力。

蓄力提交前若死亡、断头、魅惑或钻机层碎裂，动作原子取消并消费能力；冻土提前融化只取消本次尝试，仍可在以后重新蓄力。通用 `InterruptUncommittedSpecialAction` 只取消本次尝试、不消费能力，供后续伏霜雷和警铃草复用。提交后的地裂不因来源死亡、魅惑或回暖回滚。

## 钻机层与地裂

- 本体生命 650，冰制钻机层 900；普通伤害先结算钻机层。融雪投手的盐晶额外腐蚀只扣仍存在的钻机层，不向本体溢出。
- 地裂从钻头前端向房屋以 180 px/游戏秒传播，每格最多结算一次 110 点植物伤害，跨大步长仍按列顺序处理。
- 地裂按 `overlay/pumpkin/normal/under` 快照整格活动植物并逐层结算。仍存活且锚定的雪锚果每次都通过 `WinterGroundImpactKind::GROUND_CRACK` 原子返回 1/3 后续倍率：雪锚果所在格仍承受当前完整伤害，左侧后续植物按统一取整承受 37 点；地裂不会被完全停止。同一道地裂经过后续雪锚果时只维持 1/3，不继续叠乘。
- 地裂是 `GameObjectManager` 强持有、Board 弱持有的独立对象。保存行、裂缝前沿 X、下一待结算列和后续伤害倍率；读档不重放提交声效或首段粒子。

## 美术与反馈

- 主体仍复用路障完整骨骼，但新增附着在稳定 `Zombie_body` 锚点的独立钻机 reanim：实机按原图 50% 绘制，握把对齐画面前侧右手，且身体轨早于手掌轨绘制，让手掌自然盖住握把。这样不继承手臂的大幅上下摆动；充能仅保留约 1 px 水平、0.5 px 垂直的轻微高频颤抖。外臂和头部继续使用原路障断肢/断头规则，不新增帧事件；失去持钻手臂会同步脱落钻机。
- 钻机原画为透明源 `scripts/assets/ice_crack_drill_source.png`；脚本生成 220×124 实机贴图、三档破损、每档四相钻齿高光、独立耳罩安全帽、地裂和四枚碎冰粒子。
- 巡航慢转，蓄力高速转动并叠加机身震动、钻头碎冰和发动声；提交时播放破土声及同行裂缝粒子；钻机层碎裂时整套机械飞出并散落碎冰。禁止用全身染色代替这些轮廓和动作差异。

## 初始调参

| 参数 | 初值 | 语义 |
|---|---:|---|
| 本体生命 | 650 | 失去钻机后仍保留普通步行压力 |
| 钻机层生命 | 900 | 盐蚀与后续伏霜雷的主要装备目标 |
| 蓄力 | 5 秒 | 可被预判和中断的提交窗口 |
| 地裂速度 | 180 px/秒 | 约 4～5 秒扫过整行 |
| 地裂伤害 | 110/格 | 保留整排压血压力，不再一轮清空常规植物 |
| 雪锚后伤害 | 37/格 | 110×1/3 后在逐格伤害入口统一四舍五入 |
| 正式生成上限 | 3 只/波 | 只限制同一正式波次，不限制全关累计数量 |
