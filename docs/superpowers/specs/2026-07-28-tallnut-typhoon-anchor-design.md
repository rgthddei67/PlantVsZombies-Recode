# 高坚果抗台风锚定设计

日期：2026-07-28　状态：已获主人批准

## 目标

保留强台风与超强台风的阵型位移威胁，同时给玩家一个需要阳光、站位和高坚果生命值交换的主动反制手段。普通台风仍不移动植物，本功能只参与既有强/超强阵风的逐格植物结算。

## 规则

1. 高坚果在两种风向下都锚定自身格位；强台风和超强台风不能移动高坚果，也不能把它吹入弹坑或吹出棋盘。高坚果独自抵抗自身位移时不扣血。
2. 阵风逐格结算时，若一个植物格将直接进入由高坚果锚定的目标格，则取消本次一格移动，并让高坚果受到 800 点基础环境伤害。
3. 伤害使用 `DamageSource::OTHER`：不受僵尸增伤影响，仍受生存模式植物韧性减伤。
4. 只计算直接撞击，不把后方连续植物链的压力传导给高坚果。后方植物仍按既有“目标格被占用则停止”的规则结算。
5. 超强台风的两格位移逐格独立结算：紧邻高坚果的同一植物可连续被挡两次，使高坚果共受 1600 点基础伤害；相隔一格时先移动一格，再被挡一次并造成 800 点伤害。
6. 水路的睡莲与上层植物继续作为一个植物格组合移动；组合直接撞到高坚果时只算一次 800 点伤害。高坚果仍存活时锚定所在格的上下两层，避免与睡莲撕开。
7. 若高坚果在某一步撞击后死亡，该步仍视为已被阻挡；后续剩余步数重新读取格子状态，因此可进入已经腾出的格位。
8. 同一次阵风对同一株高坚果的伤害逐格结算，以保留“中途死亡后放行”的语义；Bonk 与星星反馈每株高坚果每次阵风最多播放一次，避免超强台风同帧重复音画。

## 接入方式

- `Plant` 声明通用“是否锚定台风格位”与“受到一次直接植物撞击”虚接口。
- `TallNut` 覆写能力与反馈，并在植物侧持有 800 点调参常量。
- `Board::TriggerTyphoonPlantMove` 保持唯一阵风结算钟点：从目标格顶层读取锚定植物、取消直接移动并派发撞击；不得在天气系统中写死 `PLANT_TALLNUT` 类型表。
- 该能力完全由当前植物类型、生命值和既有格子状态派生，不新增存档字段。

## 验收

新增最小可见 AutoTest，至少覆盖：

1. 晴天/普通台风不触发额外伤害；
2. 强台风双向吹动时高坚果不换格，紧邻植物停止，高坚果精确损失 800；
3. 超强台风紧邻植物被连续挡两格，高坚果精确损失 1600，但 Bonk/星星只反馈一次；
4. 超强台风相隔一格时植物先移动再停止，高坚果只损失 800；
5. 连续植物链只让直接相邻植物造成伤害；
6. 高坚果第一步死亡时，第一步仍被挡，第二步允许植物进入腾出的格位；
7. 既有普通植物移动、弹坑与边界损失规则保持不变。

典型无传压布局：风向右时，`向日葵 / 空格 / 豌豆射手 / 高坚果` 遭遇超强台风。第一步向日葵填入空格、豌豆直接撞击高坚果；第二步向日葵被豌豆占格挡住、豌豆再次直接撞击高坚果。最终布局为 `空格 / 向日葵 / 豌豆射手 / 高坚果`，高坚果只因豌豆的两次直接撞击损失 1600 点基础生命。
