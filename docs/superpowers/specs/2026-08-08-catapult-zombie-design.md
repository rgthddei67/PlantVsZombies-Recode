# 投篮车僵尸设计 spec

日期：2026-08-08｜状态：已实现并完成可见验收

## 目标与范围

实现经典 `ZOMBIE_CATAPULT`：车辆移动与碾压、十二发篮球的“射击—装填”循环、车辆损坏、地刺爆胎、普通爆炸死亡和专属化灰残骸。主人提供本体与化灰 reanim，并指定 `anim_shoot` 第 46 帧投篮、化灰第 29 帧回收。

投篮车接入生存权重、开发面板、图鉴资源和 AutoTest 直造，并按主人澄清后的要求保留既有屋顶 5-3、5-4 阵容，另外设计 5-5、5-6：5-5 用基础杂兵与铁桶精简教学投篮车；5-6 在玩家通关 5-5 获得叶子保护伞后，用铁桶、蹦极、扶梯与投篮车做复习综合。叶子保护伞尚未实现，只在篮球命中植物的唯一入口留下可直接接管拦截/反弹的 TODO。

## 本体与状态机

- 整车 850 点本体生命，不做驾驶员断臂/断头；不可魅惑、不可被水草抓取，不在泳池水路生成，但允许在屋顶陆地生成。
- 基础移动速度出生时在 23～37 px/s 随机并入存档；无 `_ground` 根运动，因此车辆手动位移，同时组合能力、寒冷、雨势、台风与场地倍率。
- 车辆不啃食；攻击矩形每帧压扁同排植物。樱桃炸弹、火爆辣椒、三叶草、倭瓜、地刺/地刺王不压扁；寒冰菇与毁灭菇只在睡眠时可压扁。
- 篮球剩余数初始为 12。篮筐仍只有四个可见篮球轨道：剩余数大于等于 5 时保持四球全显，进入 4/3/2/1 后才逐个隐藏。进入战场右侧边界内 150px 后，若同排存在合格植物，进入 `SHOOTING`；`anim_shoot` 第 46 帧发出一球，片段结束后扣库存。
- 尚有篮球时进入 `RELOADING`，播放 `anim_idle` 并等待 3 秒；到时重新索敌并射击。没有目标则回到 `WALKING`；库存为 0 后永久步行碾压。
- 索敌跳过压扁、蹦极抓取中和不可吃植物，按最靠房屋的列优先；同格按 overlay、normal、pumpkin、under 顺序选择。

## 篮球弹丸

- 复用已有 `BULLET_BASKETBALL` 池槽，默认伤害 75，只碰撞植物；固定飞行 1.2 秒、拱高 210px。
- 第 46 帧从车辆稳定视觉原点右侧 100px、上方 3px 发射，冻结目标植物弹心落点；主人目验后把起点向车尾回收 30px。贴图使用 `IMAGE_REANIM_ZOMBIE_CATAPULT_BASKETBALL`，1.1 倍绘制并随机高速自旋。
- 命中时按目标格重新解析投篮层级，避免下层 collider 抢先承伤；随后对植物造成 `DamageSource::ZOMBIE` 伤害并回收。落空到达冻结落点后播放 splat 并回收。
- `Bullet::HandlePlantContact` 中保留 `TODO(叶子保护伞)`：未来在实际扣血前查找保护伞状态并决定等待、触发或反弹；投篮车和弹道层不预埋伪实现。

## 损坏、地刺与死亡

- 生命低于 2/3 时把 `Zombie_catapult_siding` 换为损坏图；低于 1/3 时周期生成 `ZamboniSmoke`，并按是否还有篮球选择 `pole_damage_withball` / `pole_damage`。
- 生命低于 200 后按车辆通用节奏抖动并概率自损。
- 地刺命中由 `Zombie::HandleCaltropHit` 虚入口转交车辆。普通投篮车消耗地刺、播放爆胎声与 `ZamboniTire`、切到 `anim_bounce`，2.8 秒后爆炸；鎏金冰车继续保留“地刺不消失、仅受固定伤害”的既有行为。
- 普通死亡立即发射 `CatapultExplosion` 并播放爆炸声后移除。粒子复用投篮车 reanim 部件、既有爆炸云与 Zomboss 碎片贴图，不新增专用 PNG。
- 灰烬死亡在车辆稳定视觉位置创建 `Catapult_Charred`，播放完整 0～29 帧时间线，并在主人指定的第 29 帧回收；灰烬入口抑制普通爆炸粒子。

## 存档与资源

- `extraData` 保存 phase、阶段计时、篮球数、基础车速、烟雾计时和地刺延迟死亡状态；读档重建动画、篮筐库存显隐、损坏材质和碰撞终态。
- `ZOMBIE_CATAPULT` 追加到既有已实现类型末尾、`NUM_ZOMBIE_TYPES` 之前；增加本体/灰烬 AnimationType、工厂注册和 gamedata 五字段。
- 资源键严格使用主人已登记的 `CatapultZombie` / `Catapult_Charred`；补充 `basketball.ogg` 与 `CatapultExplosion.xml`，并用运行时 reanim/纹理断言验证资源闭环。
- 主人第一次可见目验确认整车偏高后，把 gamedata offset 从 `[-7,-126]` 调为 `[-7,-108]`；碰撞框、出手点、烟雾、爆炸与化灰继续共用稳定视觉原点，无需分别补偿。

## 验收

- 专项脚本覆盖：第 46 帧前无球、越过后篮球出现并扣一发；篮球命中 75、十二发耗尽及装填循环；碾压；两段损坏；地刺 2.8 秒延迟爆炸；普通死亡粒子；专属化灰第 29 帧回收；不可魅惑；存读档中段状态恢复。本次十二发调参按主人要求只更新脚本期望，不执行 AutoTest。
- 同步截图核对车辆碰撞框、球路、压扁、爆炸和灰烬位置；稳定断言使用相对视觉原点与整数投影，不锁运动对象绝对坐标。
