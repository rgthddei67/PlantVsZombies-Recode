# 精英跳跳僵尸设计

## 目标

在经典跳跳之后增加一只可辨识的家族强化变体。它复用普通跳跳的完整动画和四阶段状态机，
不新增帧事件；能力重点回应玩家在 4-7 后已经拥有的高坚果，以及 4-8 前取得的磁力菇。

## 外观

- 深紫运动外套和手臂、青绿色裤装、金色鞋部高光。
- 跳杆采用黑色弹簧与金色框架，表达非磁性碳纤维复合结构。
- 头、皮肤、眼镜、手部与普通跳跳一致；断臂和掉头沿用已经验证的轨道显隐方案。
- 独立 `ElitePogo.reanim` 只替换服装和跳杆部件；断杆粒子使用同色独立贴图与效果名。

## 数值与能力

| 项目 | 设计值 |
|---|---:|
| 本体生命 | 850 |
| 品种动画/持杆推进倍率 | 1.15 |
| 首次高坚果阻拦撞击伤害 | 600 |
| 每波上限 | 1 |
| 生存权重/点数 | 2700 |
| 生存出现轮次 | 14 |

- 持杆时继续沿用普通跳跳的冻结、魅惑、地面秒杀和水路限制。
- 碳纤维跳杆不属于磁性装备，磁力菇不能吸取。
- 第一次在前跳 10% 节点被高坚果阻拦时，照常播放 Bonk/星星反馈，消耗缓冲器并对
  阻拦植物造成 600 点僵尸来源伤害，但不折杆、不停止本次前跳。
- 缓冲器消耗状态进入僵尸存档。之后再次遇到高坚果时完全复用普通跳跳的折杆和啃食路径。
- 断臂后的紫色残臂、受损金杆和断杆粒子由父类虚资源入口选择；普通跳跳资源回归不变。

## 出怪编排

普通跳跳在 4-7 独立教学，4-8 与海豚、气球复习。精英跳跳追加到 4-9（内部 36），
采用 30 波六类型池：普通、路障、铁桶、加固铁门、普通跳跳、精英跳跳。
该池让磁力菇能够处理加固铁门和普通跳杆，再用非磁性精英形成清楚对照；普通跳跳已经提前两关出现。

## 验证边界

- 资源注册、独立受损贴图和独立断杆粒子加载。
- 首次高坚果阻拦前后节点、600 伤害、继续持杆、缓冲器存读档。
- 第二次阻拦折杆并进入啃食，独立粒子坐标与颜色截图。
- 非磁性资格、850 生命、1.15 能力倍率、陆路限定和死亡消失。
- 每波 1 只上限及存档/新波重置。
- 4-7～4-9 完整有序池；普通/精英选卡预览与图鉴详情均运行无副作用的原地弹跳；4-9 图鉴解锁边界。
