# 开凿僵尸与 9-2

主人在本任务逐项批准的最终规则（2026-09-05）：

- 本体 800 生命，普通移速与啃食；矿灯帽仅装饰，凿岩机不可磁吸。普通地图无附加能力。
- 一生最多成功开凿一格，8 游戏秒施工；完成前岩壁仍阻挡，完成后永久敌我共享，不生成入口。成功后工具冒烟并保持损坏外观。
- 从决策点寻找单格开通即可获益的墙，比较“走到施工点＋开通后至家”的总格数，严格小于当前普通路线才接受。净收益优先，并列左、上、下、右，剩余并列用稳定格序。
- 施工点只能沿已连通矿道到达；允许右行绕路，但不进入左两列后折返。选择后立即预留并标亮目标，其他开凿者跳过；锁定后不因其他墙变化换目标。
- 跳过玩家已施工的墙；玩家可对预留墙施工，独立计时。僵尸先完成则取消玩家施工并退 75 阳光；玩家先完成则僵尸取消、保留机会并等待 5 游戏秒。
- 普通受伤不打断；减速同比影响施工，冻结/黄油等硬控暂停并保留进度。特殊动作打断清进度、释放预留、正常行走，5 游戏秒后重试。
- 啃食优先，绕行/施工遇可啃植物立即取消，啃完后才开始 5 秒重试。断臂可施工，断头、死亡或魅惑取消且永久禁用；已开通地形不回滚。
- 动画采用普通僵尸时间轴，复用既有事件；矿灯帽随头、凿岩机挂内侧手臂，外侧断臂沿用原版，头与矿灯帽合成单张飞出粒子。施工沿用动作配合机械振动，不新增帧事件。
- 9-2（内部 74）延续 9-1 布局、200 初始阳光、20 波。1～2 波基础三类，3 波保证一只开凿者配基础怪；4 波起加入粉色橄榄和精英小丑，开凿者每波最多一只、跨波不占名额。两种旧精英沿用既有规则，不另加本关数量特判。

## 实现步骤

1. MineGrid 提供纯寻路与单格收益评估，Board 拥有墙体提交/玩家退款，个体拥有目标、阶段和施工余时；预留由有效个体目标派生。
2. 原节点行走接口增加品种选择入口，保留承诺节点与连续换行；取消任务仍走完已承诺边。
3. 新类型追加枚举，注册独立动画名、工厂、gamedata、图鉴；所有阶段和目标入档，加载以安全中性状态修复失效组合。
4. 可见 clang-release 专项覆盖选择、绕行、控制、啃食、提交/退款、取消、断肢/死亡、存档、资源与正式教学波；独立图测试验证收益与路径边界。

## 复验入口

从 `build/clang-release` 可见依次运行 `smoke_excavator.json`、`smoke_excavator_edges.json`、`smoke_excavator_waves.json`、`smoke_excavator_almanac.json`、`smoke_excavator_visual.json`；原矿道回归为 `smoke_mine_movement.json`。之后运行 `python autotest/verify_excavator.py` 比较余时、预留存档与完整20波。

纯逻辑检查为 `ctest --test-dir build/clang-release -R "^(mine-grid|excavation-planner)$" --output-on-failure`。寻路检查包含单墙变化后的所有起点、严格净收益、相邻连续路径、允许右行与防守区禁入。普通时间轴、身体和外侧断臂均保留；新增帽、正常/损坏工具、预留徽记与带帽头粒子均由实际贴图表现，不使用临时图元代替身份。
