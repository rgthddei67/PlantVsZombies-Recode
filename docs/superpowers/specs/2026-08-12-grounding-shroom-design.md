# 接地菇设计规格

## 定位与解锁

- 内部类型：`PLANT_GROUNDINGSHROOM`。
- 中文名：接地菇。
- 5-9 通关奖励，6-1 起可选。
- 蘑菇植物：黑夜清醒，白天睡眠并可被咖啡豆唤醒。
- 阳光 100，卡片冷却 20 秒，生命 500；屋顶必须种在花盆上。

## 黑夜屋顶雷荷

- 接地菇保护自己以及同排左右各一格内的全部非花盆植物层。
- 被保护植物免除本次离散雷荷的停机；屋顶径流造成的连续暂停仍照常生效。
- 每次放电先按稳定植物 ID 冻结目标与接地菇分配，再让僵尸消费同一批接地范围，最后统一结算接地菇反噬；因此接地菇即使被本次反噬击杀，本次植物保护与绝缘僵尸能力压制仍全部成功。
- 多株接地菇范围重叠时，按与受保护植物的列距离最近者承担；距离相同按更小的稳定植物 ID。
- 同一株接地菇每次放电最多承受一次反噬，与保护了多少植物或植物层无关。
- 接地菇所在列为普通瓦面时直接扣本体生命 100；所在列处于当前径流湿坡时直接扣本体生命 150。该伤害绕过南瓜头与防御词条。

## 绝缘僵尸交互

- 位于接地菇三格水平范围内、与接地菇同排的绝缘僵尸，不能替附近僵尸承接本次雷荷。
- 该绝缘僵尸仍按原规则受到本次直接放电的胸甲伤害，但不会因本次放电进入过载。
- 接地不改变绝缘胸甲对轻型植物弹丸的抗性、湿润增伤或其他既有规则。
- 僵尸普通伤害与麻痹结算仍由现有雷荷系统处理；接地菇只声明保护与抑制能力，`Board` 保持唯一放电结算权威。

## 动画与美术

- 使用独立的低精度整株美术，不直接复用或换色磁力菇素材。
- 战场整株在 112×120 透明画布内按初版生成尺寸等比缩放约 0.8；卡图独立等比缩放约 0.7。
- 动作接口采用磁力菇式结构：`anim_idle` 循环；承接放电时播放一次 `anim_shooting`，随后自动回到 `anim_idle`；白天使用 `anim_sleep`。
- 不新增动画帧事件。雷荷反噬在 `Board` 的放电结算边沿直接触发，动画只负责表现。
- `anim_shooting` 使用带紫色电弧的受电姿势；待机只做轻微上下呼吸，保持原版植物的小幅动作密度。

## 存档与验证

- 植物生命、睡眠和主 Animator 状态沿用通用存档；接地菇不新增需要保存的权威字段。
- 新类型追加在植物与动画枚举末尾，避免旧存档整数 ID 错位。
- AutoTest 覆盖资源与数值注册、5-9 奖励、三格保护边界、湿/干反噬、范围重叠稳定选择、反噬致死仍完成快照保护、径流暂停不被移除，以及绝缘僵尸接地后拒绝承接和拒绝过载。
