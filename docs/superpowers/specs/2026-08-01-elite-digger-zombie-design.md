# 精英矿工僵尸设计

> 日期：2026-08-01
> 状态：主人已确认，进入实现

## 目标

新增“爆破工头”精英矿工，并与普通矿工组成同族递进：保留地下穿行、左侧出土与丢镐分支，完整出土后先以可见眩晕动作预警，再炸毁房屋侧一片后排阵地并持镐向右折返。

## 已确认玩法

| 项目 | 取值 |
|---|---|
| 本体 / 安全帽 | 600 / 250 |
| 地下路径 | 复用普通矿工，从右侧入场并潜行至首格附近出土 |
| 爆破预警 | 复用 `STUNNED` 的 3.5 秒 `anim_dizzy`，不新增动画帧事件 |
| 爆破范围 | 固定列 0～2，行 `所在行-1`～`所在行+1`，越界裁剪；中间行最多 9 格、边缘行最多 6 格 |
| 爆破伤害 | 范围内每个存活植物层受到 150 点 `DamageSource::ZOMBIE` 伤害，无衰减 |
| 爆破次数 | 每只至多一次；死亡、读档和阶段恢复均不能重复结算 |
| 爆破后行为 | 保留镐，按普通持镐折返速度的 125% 向右行走、啃食后排 |
| 丢镐克制 | 地下丢镐沿用普通分支；爆破预警期丢镐立即取消爆破并无镐向左推进 |
| 波次上限 | 正式波次每波最多 1 只 |

爆破使用逻辑格而非圆形碰撞。当前格宽 80 像素，三列即从房屋侧向草坪内覆盖 240 像素；行高 100 像素。粒子视觉中心放在第 1 列的格心，使表现与 0～2 列的固定伤害 footprint 对齐，水路视觉偏移不参与伤害判定。

## 类型、状态与继承边界

- 在 `NUM_ZOMBIE_TYPES` 前追加 `ZOMBIE_ELITE_DIGGER`，不插入旧枚举中间。
- `EliteDiggerZombie` 派生自 `DiggerZombie`。普通类只开放窄虚拟钩子：持镐步速、眩晕结束、丢镐后处理、受损安全帽/断臂贴图和掉落粒子名。
- 精英类不复制七阶段状态机。眩晕结束钩子先结算爆破，再进入 `WALKING_WITH_PICKAXE`；预警期丢镐钩子直接进入 `WALKING_WITHOUT_PICKAXE`。
- 子类额外保存 `blastResolved`。旧存档缺字段默认为 `false`；父类先恢复矿工阶段，再恢复精英字段和专属材质终态。
- 预警期不能被魅惑，沿用普通矿工 `CanBeCharmed()` 边界，因此无需定义敌我倒置爆破。

## 美术与粒子

- 复制 `Zombie_digger.reanim` 为独立 `EliteDigger.reanim`，只重映射衣服、袖子、安全帽和镐的派生贴图；头、腿、泥土和灰烬动画继续复用普通资源。
- 衣服转为工程警戒橙黄，安全帽为橙黄，镐头加入青蓝色金属点缀；保留原透明度、轮廓、阴影和格纹明暗。
- 新建 `EliteDiggerBlast.xml`，结构借鉴 `JackExplode`，但独立命名与参数：橙红爆炸云为主体，青蓝火花/碎片为辅，横向可见范围覆盖约三列。不得修改小丑的 `JackExplode`。
- 精英安全帽和袖子使用独立掉落粒子，避免掉落瞬间变回普通白帽/红袖。

## 集成

- 工厂、动画键、开发者面板、AutoTest 名称表、图鉴文本、`gamedata.json` 全部注册。
- 冒险 4-5 保持普通矿工首次教学；4-6 的出怪池在普通矿工后加入精英矿工。
- 图鉴按 4-6 过关后解锁精英条目，当前关卡预览不提前泄露。
- 生存数据采用 `weight=2400`、`appearWave=10`、`survivalRound=13`，并受正式波次每波 1 只上限约束。

## 验收

- 专项 AutoTest 覆盖 3×3 伤害和边界外对照、预警前后存档、只爆一次、爆后向右且步速提升、预警丢镐取消、地下丢镐、装备掉落和死亡。
- 波次测试覆盖同波第二只被拒绝、存档计数恢复、下一波重置。
- 冒险/图鉴测试覆盖 4-5 普通矿工、4-6 普通+精英矿工与解锁边界。
- 在默认实例化和 `-NoInstance` 两条可见渲染路径检查精英换色、预警、爆破范围和透明边界；同时核验 exit code、`run.log`、状态 JSON 与截图。
