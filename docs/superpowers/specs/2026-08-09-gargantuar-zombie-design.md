# 巨人僵尸与小鬼设计

## 范围

- 新增经典巨人僵尸与仅由巨人投出的经典小鬼；小鬼的出怪权重为 0。
- 巨人接入冒险 5-7、5-8；小鬼不写入随机出怪池，也不新增图鉴/预览的特殊展开逻辑。
- 复用现有四份 reanim，并补齐原版低吼、砸击、挥动、小鬼叫声和巨人死亡音效。

## 数值与帧契约

- 巨人本体生命 3000；生命首次降至一半或以下且位置允许时，只投掷一次小鬼。
- 每只巨人出生时独立随机 `0.4～0.6` 整体动画倍率，并随关卡存档恢复；组件影子缩放为 `1.3`。
- 巨人右手持物统一按原版概率出生：电线杆 65%、鸭子过街路牌 25%、普通僵尸 10%；图鉴、预览、5-8 与实战不设特殊分支，随机结果作为独立存档字段恢复。
- 小鬼本体生命 270。
- 主人提供的帧均已按项目帧事件规则直接使用：巨人砸击 93、投掷脱手 124、死亡回收 196、化灰回收 42；小鬼啃食 44/55、死亡回收 81、化灰回收 34。
- 第 130 帧是小鬼已经飞离画框后的投掷收尾，不负责生成；第 124 帧同时隐藏巨人背上的小鬼、创建小鬼并播放挥动/叫声音效。

## 行为状态机

- 巨人：`WALKING -> SMASHING -> WALKING`，或在半血时 `WALKING -> THROWING -> WALKING`。
- 砸击锁定植物格或敌对阵营僵尸；第 93 帧压扁目标格全部植物层，或对敌对僵尸造成一次重击，并触发纵向屏幕震动。
- 投掷距离由当前棋盘格中心推导；屋顶沿用原版缩短 180px 的语义。小鬼以独立高度和竖直速度飞行，逻辑脚点仍由 Board 统一贴合坡面。
- 小鬼：`THROWN -> LANDING -> WALKING`；飞行和落地演出期间关闭地面碰撞、啃食、地雷、水草、黄油/冻结与地面弹丸命中，落地轨完成后统一恢复。
- 巨人若带有减速，脱手瞬间把剩余减速秒数原样传给小鬼；减速会同时缩放小鬼飞行、落地动画及后续移动。
- 魅惑会原子终止巨人正在执行的砸击或投掷；魅惑巨人之后投出的小鬼继承阵营。巨人普通断肢/断头关闭，小鬼保留专属断肢断头。

## 死亡、资源与存档

- 巨人与小鬼分别使用独立化灰 reanim；巨人化灰时若小鬼已经投出，烧焦残影隐藏 `imphead`/`impblink`。
- 巨人没有 35 血临界值或无头流血阶段；本体生命扣到 0 时才中断动作并进入普通死亡。
- 巨人按原版 `<2/3`、`<1/3` 本体生命切换两档伤痕/创口贴贴图；该外观由生命值派生，读档无需保存冗余阶段。
- 普通死亡开始前，致死伤害会原子清理一次性动作，使旧动作帧事件不能在死亡轨前抢跑。
- 巨人存档保存阶段、是否仍持有小鬼、当前目标和帧事件防重标志；小鬼存档保存阶段、高度、水平/竖直速度与投掷方向。读档时修复垂死、魅惑和轨道不匹配的旧状态。
- 资源验收必须覆盖四份 reanim、两份小鬼离体粒子、六个新增音效及实体运行资源键。

## 冒险出怪

- 5-7 用普通、路障、铁桶、小丑、蹦极、投篮车和巨人构成教学组合。
- 5-8 用普通、路障、撑杆、蹦极、扶梯、精英扶梯、投篮车、导流投篮车和巨人组成屋顶综合复习。
