# 气象干扰僵尸设计规格

## 定位与教学

气象干扰僵尸是第七大关 7-6 首次登场的全预报栏干扰敌人。它让玩家第一次失去对未来天气的可靠信息，并在通关后获得警铃草，形成“先遭遇完整干扰，再获得动作中断工具”的奖励顺序。

7-6 使用精简池教学本体，并在第 3 波额外保底生成一只；7-7 暂退给警铃草与下一种新威胁单独教学，7-8、7-9再进入综合关。每个正式波次最多生成一只，这是每波上限，不是整局累计上限。

## 状态机

气象干扰僵尸继承标准铁桶僵尸的本体、铁桶、断肢、断头、死亡、啃食、磁力菇和受击契约，不新增动画帧事件。能力使用四态状态机：

1. `READY`：正常移动和啃食。完全进入战场后，只要 Board 存在至少一项仍公开的未来天气预报，即可起手。
2. `CHANNELING`：施法优先级高于啃食。起手时原子结束当前啃食、清除目标并平衡植物 `eaterCount`，随后原地循环 `anim_idle` 4 游戏秒；期间禁止移动、索敌和重新啃食。冻结、黄油和麻痹暂停动作，寒冰减速让倒计时按 0.5 倍推进。
3. `REBOOTING`：警铃草、伏霜雷或通用外部入口中断尚未提交的动作后，设备重启 5 游戏秒；能力不消耗，僵尸恢复移动和啃食，重启结束后才可再次起手。重启按普通游戏时间推进，不因正在啃食而永久停住。
4. `SPENT`：成功提交，或死亡、断臂、断头、魅惑使能力永久失效。已经提交的预报干扰不回滚。

提交边沿只干扰提交瞬间仍公开的预报。若倒计时结束时已经没有任何公开预报，则返回 `READY` 且不消耗能力；以后出现新预报仍可重试。普通铁桶被击落或被磁力菇吸走不影响能力，失去铁桶后仍可施法。

## Board 全预报栏干扰

Board 提供单一原子入口，分别锁定并作废当前公开的以下未来信息：

- 降雨或降雪预报；
- 与大雨预报绑定的公开台风等级；
- 冬日花园寒潮强度、最低温和预计冻土范围；
- 独立雾势预报。

干扰只改变玩家可见信息，不修改已经锁定的真实雨势、降雪表现、台风强度、雾势、寒潮计划、温度、阶段计时或随机结果。揭晓时仍按真实计划结算；被干扰的雨势/台风组合不再触发“预报失败”提示，提交时已经出现在屏幕中央的大雨/暴雪专用预警也立即撤下，避免隐藏信息通过提示泄露；大波、突击令和低燃料等其他中央提示不受影响。当前天气、正在生效的台风与风向、实际温度、冻土、屋顶径流和黑夜屋顶雷荷等实况继续显示。

雨势、雾势和寒潮各自保存本轮干扰标志，并在对应维度锁定下一轮新计划时独立清除。UI 在仍处于被干扰预报窗口时显示“天气预报：气象信号受干扰”，不再显示本轮被干扰维度的具体内容；未被本次提交命中的未来新预报仍可按自身新代际正常公开。寒潮分支继续沿 Board 现有稳定植物 ID 通知，原子清除融雪投手未提交盐弹与伏霜雷未兑现校准。

## 铁桶与中断契约

- 本体生命 270，标准铁桶生命 1100；移动、啃食伤害和铁桶破损均沿用 `BucketZombie`。
- 铁桶仍是唯一可被磁力菇吸取的装备。干扰设备设定为防寒复合外壳，不进入磁力菇装备选择，也不提供额外生命层。
- 手持终端跟随外臂；断臂时终端消失并永久消费能力。
- 断头、死亡或魅惑会原子结束啃食/施法并永久消费能力；魅惑单位永不干扰玩家预报。
- `GetInterruptibleSpecialActionRemaining()` 只在 `CHANNELING` 返回剩余秒数；`InterruptUncommittedSpecialAction()` 只取消尚未提交的动作并进入 5 秒重启。
- 读档修复终止状态与未完成动作的矛盾组合；已经 `SPENT` 的实体不得恢复次数，`CHANNELING`、`REBOOTING` 的剩余时间与设备表现均按档恢复且不重播一次性声音。

## 美术与反馈

主体复用铁桶僵尸骨骼，新增改变低分辨率轮廓的独立设备：背负厚重箱式气象欺骗台，顶部伸出小型雷达盘、天线、警示灯与外露线缆；前侧手持带发光屏的控制终端。造型采用《植物大战僵尸》式夸张手绘卡通语言，保留厚壳、倒角、铆钉、玻璃高光、磨损和分层阴影，禁止写实风格、平涂矩形或仅靠全身换色识别。

背包设备附着到稳定 `Zombie_body` 语义轨道，手持终端附着到 `Zombie_outerarm_hand`：

- `READY`：雷达慢速扫动，终端低亮；
- `CHANNELING`：雷达快速摆扫，警示灯与终端脉冲闪烁，身体只循环 `anim_idle`；
- `REBOOTING`：警示灯改为琥珀色故障闪烁；
- `SPENT`：屏幕熄灭、雷达垂下并停止；
- 断臂隐藏终端，断头与死亡保留熄灭设备直到本体正常回收。

高分辨率透明母图保存在仓库，确定性 PowerShell 脚本负责裁切、缩放和生成最终游戏 PNG。默认实例化与 `-NoInstance` 均需用同步截图校准设备轮廓、手持锚点、铁桶遮挡和死亡终态。

## 初始调参与投放

| 参数 | 初值 | 语义 |
|---|---:|---|
| 本体生命 | 270 | 标准普通僵尸本体 |
| 铁桶生命 | 1100 | 完整复用铁桶防具 |
| 架机时间 | 4 秒 | 可被预判和中断的未提交窗口 |
| 中断重启 | 5 秒 | 中断后允许玩家获得实际收益 |
| 成功次数 | 1 次/实体 | 只有正式提交才消耗 |
| 正式生成上限 | 1 只/波 | 防止全局信息长期不可用 |
| 生存权重/成本 | 2600 | 高于冰裂钻机，反映全局信息压力 |
| 自然出现波次 | 第 5 波 | 教学保底可在 7-6 第 3 波窄豁免 |
| 生存开放轮次 | 第 13 轮 | 位于现有冬日威胁之后 |

7-6 随机池精简为普通、路障、读报、铁门、小丑和气象干扰僵尸；7-8、7-9将其加入已有综合池。7-7不加入该类型。
