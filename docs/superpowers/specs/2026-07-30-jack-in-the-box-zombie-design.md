# 小丑僵尸（Jack-in-the-Box Zombie）设计 spec

日期：2026-07-30 ｜ 状态：主人已确认实现方案

参考实现：`D:\PVZ\PlantsVsZombies.NET-master\Lawn_Shared\Lawn\Zombie\Zombie.cs`

## 1. 资源与动画事实

- 使用 `Zombie_JackBox.reanim`，资源帧率为 12 FPS，时间线为 0～89。
- 剪辑：`anim_idle` 0～16、`anim_walk` 17～35、`anim_eat` 36～50、`anim_pop` 51～66、`anim_death` 67～89。
- 主人给出的代码帧号直接使用：`EatTarget@45`、`Explode@66`、`Die@89`，不再减一。
- 断臂轨道为 `zombie_jackbox_outerarm_lower`，断臂后替换为
  `IMAGE_REANIM_ZOMBIE_JACKBOX_OUTERARM_LOWER2`。
- 断头隐藏 `anim_head1`、`anim_head2`；依 C# 原版沿用带完整下巴的普通
  `ZombieHeadOff` 粒子，不覆写为小丑头部材质。

## 2. 行为状态机

状态只有 `RUNNING` 与 `POPPING`：

- `RUNNING`：500 点本体生命，按 C# 的 `mVelX=0.66～0.68` 生成实例行走速度。
  开盒倒计时按 `(450～749) / mVelX * 2` 厘秒换算；1/20 概率缩短为三分之一。
  倒计时在行走和啃食时都推进，冻结时暂停。
- 倒计时归零且仍有头时进入 `POPPING`：原子结束当前啃食，停止移动和手摇盒循环声，
  播放 `boing`，以原版 28 FPS 播放 `anim_pop`。
- 开盒 0.3 秒后播放 `jack_surprise`（2/3）或 `jack_surprise2`（1/3）。
- 动画第 66 帧触发爆炸。爆炸完成后自身立即回收，不进入死亡动画。
- `POPPING` 阶段拒绝普通 `TakeDamage`、拒绝重新啃食、不能被冻结；小推车和化灰等直接死亡链仍可结算。
- 未开盒前若掉头，则停止循环声且永远不再开盒，随后走基类无头流血和 `anim_death`，
  第 89 帧消失。

## 3. 爆炸契约

- 爆心取小丑当前碰撞箱中心，不复制 C# 800×600 的绝对坐标。
- 敌方小丑：对爆心附近全部僵尸（含魅惑僵尸）施加原版 1800 点燃烧结算，并杀死范围植物。
- 魅惑小丑：只伤害非魅惑僵尸，不伤害植物。
- 僵尸半径 115 px、植物半径 90 px；目标使用圆与实际碰撞矩形相交判定。
- 播放 `explosion`，调用 `ShakeBoard(4,-6)`，发射专属 `JackExplode`。

专属爆炸由四类可见元素组成：

- 紫色小云与大云，扩散宽度应覆盖约一个小丑伤害圈，不能只贴在爆心；
- `Zomboss_particles` 五种随机飞散碎片；
- 原版 `Sproing.png` 的“嘣”标识；
- 全部发射器都显式设置 `SystemDuration`，保证爆发结束后回收。

同类扩散回归同时修复樱桃炸弹 `PlantExplode.xml`：两者都使用低恒定逐帧阻力，
并以 AutoTest 断言实际世界包围盒宽、高至少 200px，防止粒子数量正常但全部挤在爆心。

## 4. 音效生命周期

- 正式出生时启动 `jackinthebox` 循环声；预览和普通 Setup 不播放。
- 多只小丑共享同一循环资源，以实例引用计数保证其中一只停止时不会误停其他小丑。
- 开盒时停止本实例的循环占用并播放 `boing`。
- 开盒中段播放一条 surprise 声，爆炸帧播放 `explosion`。
- 断臂、断头播放 `limbs_pop`。
- 掉头、死亡、销毁、切场景都必须释放循环占用。
- 读档不重播出生、开盒、惊吓或爆炸的一次性声音；仍在 RUNNING 的读档实例恢复循环声。
