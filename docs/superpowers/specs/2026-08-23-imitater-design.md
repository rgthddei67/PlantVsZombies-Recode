# 模仿者实现设计

## 目标

实现经典植物 `PLANT_IMITATER`：在选卡界面通过独立目标选择层指定一种已拥有且已注册的非模仿者植物；提交后卡槽保留模仿者身份与独立冷却，但费用、种植前提、落点合法性和预览表现均代理给目标植物。落种时先生成模仿者本体，等待约 2 秒后播放 `anim_explode`，在动画 80% 处发射原版变身粒子，结束后原地替换为带泛白滤镜的目标植物。

## 选卡与卡片契约

- 模仿者不进入现有主选卡分页；它作为固定入口放在主选卡栏右下方。原尺寸 `SeedChooser_ImitaterAddOn.png` 是紧贴主面板、底边对齐的固定背景，不跟随 Card 移动，目标选定后也始终保留。
- 点击尚未选中的模仿者时打开独立模态目标层；目标层创建一批独立 Card 实例，在 9×6 网格中展示全部已拥有、已注册、非模仿者且非紫卡升级的植物，允许选择已经加入普通卡组的同种植物。主选卡 Card 从不被搬进弹窗，且继续在半透明遮罩下绘制和移动，但 collider 暂时关闭、不能穿透点击；关闭时只销毁临时 Card 并恢复主卡输入。
- 目标层打开时禁止开始、恢复上次选卡和主分页输入；取消只关闭目标层，不改变现有卡组。选中目标后关闭目标层并把模仿者加入卡组。
- 弹窗临时卡和指定目标后的模仿者卡都使用灰色 SeedPacket variant、目标植物卡图与泛白卡图；固定木框留在原位，选中的 Card 自己飞入顶部卡槽。取消选中会清除目标，原位重新显示模仿者入口卡。
- 上次选卡用稳定字符串 `PLANT_IMITATER:PLANT_TARGET` 保存目标；旧的单植物枚举字符串保持兼容。关卡卡槽存档另存 `imitaterTarget`。

## 种植与变身契约

- Card 的 `PLANT_IMITATER` 是持久身份；`GetGameplayPlantType()` 返回目标，供费用、次数上限、升级前提、合法落点、鼠标预览和格子预览使用。
- Board 创建路径区分 `actualType` 与 `placementType`。普通植物两者相同；模仿者的 actual 为 `PLANT_IMITATER`，placement 为目标。占层、footprint 和累计种植次数按 placement 结算；紫卡在进入该路径前已被拒绝，普通蘑菇的昼夜睡眠由变身后目标自身 Setup 恢复。
- 变身时实例化目标植物，并用模仿者原有植物 ID 覆盖 EntityRegistry；Cell 中的 ID 不变，因此层与 footprint 原子保留。旧模仿者只退出对象生命周期，不释放已交给新植物的格位。
- 路灯花唯一配额在模仿者占位期间也按目标预留；模仿者提前死亡时释放预留，成功变身后同 ID 继续归目标路灯花所有。
- 目标植物使用原版 HSL `WashedOut` 滤镜（亮度×1.8、饱和度×0.2），不是纯白 overlay；魅惑菇、倭瓜、土豆雷、大蒜和睡莲使用 `LessWashedOut`（亮度×1.2、饱和度×0.3）。卡图、预览与正式植物共用两档参数，Vulkan batch/instance、并行回放与 OpenGL 3.3 慢路径保持一致。
- 模仿者本体的变身进度、目标、倒计时和粒子边沿进入 `SaveExtraData`；变身后的目标植物通过通用 `imitated` 字段保存泛白身份。读档在创建占位前先读取目标，以恢复正确占层和 footprint。

## 动画与粒子

- `Imitater.reanim` 的 `anim_idle` 作为等待轨道，`anim_explode` 按原版 26 fps 播放。
- 不新增 Animator 帧事件。`PlantUpdate` 读取当前帧；跨过 `anim_explode` 80% 时仅发射一次 `ImitaterMorph`，一次性动画结束后请求 Board 完成替换。
- `ImitaterMorph.xml` 从原版两发射器配置适配：云团和八帧 puff 贴图均注册为粒子纹理；所有发射器显式设置有限 `SystemDuration`，避免第一个发射器永久存活。

## 集成与验证

- `PLANT_IMITATER` 在当前无商店流程中暂作为 6-8 奖励；不移动既有枚举值。
- 模仿者从普通分页剥离后，普通植物分页仍维持原有数量与布局。
- 新增专项 AutoTest 覆盖：资源闭环、固定入口背景、独立临时 Card 目标层、紫卡排除、层级与恢复、目标费用/冷却、真实卡槽落种、等待与爆炸轨道、80% 粒子边沿、原版 HSL 泛白、占位与变身后存档恢复，以及默认实例、`-NoInstance` 与 OpenGL 截图。
