# 精英扶梯僵尸设计

日期：2026-08-06

## 目标与边界

新增 `ZOMBIE_ELITE_LADDER`，继承经典扶梯的携带、放置、攀爬、啃食、断肢、磁吸和死亡时间线，不新增动画帧事件。外观初始为深蓝工装与普通银灰扶梯；只有命中无限搭梯分支后，携带态、损坏态、断梯粒子、已放置扶梯和磁吸离体物才统一切换为安全金配色。

本体初始生命为 650，扶梯护盾沿用 500。生存模式第 15 轮进入候选池，正式波次每波最多生成一只，计数随当前波存档并在换波时清零。本次不改冒险关卡出怪表。

## 五秒整行扫描

出场后经过 5 个游戏秒一次性扫描当前行。计时不因啃食、冻结或放梯暂停，但服从暂停和全局时间倍率；预览、死亡和非 GAME 状态不推进。扫描只统计仍活动、非预览、非压扁植物的当前生命，叠层植物逐实体计入。

- 当前总生命严格高于 6000：获得无限搭梯；成功放置不消耗携带扶梯，但破盾或磁吸仍会失去扶梯。
- 当前总生命严格低于 6000：自身整体动画倍率改为 2.0；移动、放梯、啃食与死亡动画共同受影响。
- 投手数量严格多于射手：当前/最大本体生命同时增加 500。
- 投手数量严格少于射手：当前/最大扶梯生命同时翻倍。
- 生命恰好 6000 或两类数量相等时，对应分支不触发。

投手明确为卷心菜、玉米、西瓜和冰瓜投手。射手明确为豌豆/蘑菇/仙人掌/杨桃/香蒲等主动远程射击植物；防御、生产、地刺和即时植物不参与两类数量比较。

## 资源、共享扶梯与存档

换色脚本从经典扶梯 13 张部件图生成精英资源，并以 SHA-256 锁定输出；独立 reanim 只替换相应图片键，其中 `BODY` 与 `BODY2` 必须分别生成并强制断言。精英断梯使用独立 `ZombieEliteLadder` 粒子。四项增益在扫描结算时分别触发一圈缩小的安全金扶梯、青蓝速度流线、橙红本体脉冲和亮黄扶梯护盾闪光；一次扫描同时展示命中的两个分支，效果均在一秒内淡出且不入存档。

Board 共享 `Ladder` 增加 `CLASSIC/ELITE` 样式。样式决定绘制与磁力菇离体物贴图，并进入 `ladders[].style`；旧档缺字段时恢复为经典样式。无限能力变色不重置护盾破损档位，银灰 `damage1/damage2` 分别原位映射为黄色 `damage1/damage2`。精英僵尸保存扫描倒计时、完成标志、锁定能力、扫描统计和已应用分支，读档后不重复结算，并按恢复后的能力与破损阶段重新同步贴图。

## 验证

AutoTest 覆盖资源键、8300 高血量无限连续放两梯、300 低血量双速与双盾、四种增益粒子名与活动粒子数、6000/数量相等严格边界、僵尸与场景扶梯存档、精英断梯粒子，以及每波一只上限的存档与换波复位。最终用 `clang-release` 构建，并在主人当前桌面可见运行专项、`-NoInstance` 专项和经典扶梯回归。
