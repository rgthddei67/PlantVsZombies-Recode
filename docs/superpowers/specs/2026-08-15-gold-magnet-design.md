# 6-7 磁暴菇设计规格

## 目标

在第六大关 6-7（内部关卡 52）通关后奖励 `PLANT_GOLD_MAGNET`。该植物复用经典金磁菇的枚举、美术槽和磁力菇升级关系，但不实现原版金币收集；本项目将其定位为黑夜屋顶的战斗紫卡“磁暴菇”。

它要在接地僵尸令减速、冻结和黄油失效时提供独立的麻痹控制轴，同时保持三条限制：只有成功剥离僵尸装备才触发、没有直接伤害、不直接拆除接地僵尸天线路障。

## 数值

| 项目 | 设计值 |
|---|---:|
| 升级基础株 | 磁力菇 |
| 追加阳光 | 75 |
| 卡片冷却 | 50 秒 |
| 生命 | 300 |
| 吸取总充能 | 12 游戏秒 |
| EMP 半径 | 100 px 圆形范围 |
| 麻痹时间 | 2.5 游戏秒 |
| 直接伤害 | 0 |

磁暴菇继续沿用磁力菇的上下各两行搜索、距离优先、单次只吸一件装备和离体物飞行表现。它属于夜间蘑菇：白天睡眠，继承基础磁力菇的睡眠/唤醒进度，咖啡豆可以唤醒。

## 装备与控制交互

1. 只有 `Zombie::ExtractMagneticItem` 成功后才以被吸僵尸碰撞矩形中心结算 EMP；搜索失败、目标竞争失败或仅进入攻击动画都不触发。
2. EMP 只作用于活动、非垂死、非魅惑的敌方僵尸；逐只调用现有 `Zombie::ApplyParalysis(2.5f)`，由目标自己的永久/临时麻痹免疫和品种阶段决定是否接受。
3. 接地僵尸发放的30秒免控只含减速、冻结和黄油，因此不会阻止麻痹；接地僵尸天线路障自身不加入磁吸资格，也不会被 EMP 清除。
4. 绝缘僵尸整甲仍返回150点提取者本体反噬。顺序固定为“装备原子剥离并由植物接管 → EMP结算 → 反噬扣血”；即使反噬令磁暴菇死亡，装备和已触发 EMP 都不回滚。
5. 已经放到植物格上的场景扶梯仍可按普通磁力菇规则吸走，但不触发 EMP，因为没有僵尸导电载体。
6. 重复麻痹沿用目标现有语义，只保留较长的剩余时间，不累加时长。新刷出的僵尸不会追溯获得旧 EMP。

## 条件式轻量推演

推演不再用固定“每12秒一次”的控场频率折算磁暴菇，而是复现一次轻量磁吸事件：

1. 植物快照保存磁暴菇当前充能剩余时间；新种下的候选株从可触发状态开始。
2. 僵尸快照保存当前是否有合法磁性装备，以及本次提取会移除的头盔、盾牌或无额外生命的工具层。
3. 技能就绪时，只在正式搜索范围内存在合法目标才触发；按距离选择目标后消费一件模拟装备，并移除对应模拟护甲层。
4. 以目标当前位置结算100px、2.5秒麻痹，然后进入真实12秒冷却。同一件装备不会被后续触发重复利用。

该能力通过通用磁吸脉冲画像进入 `PlantDefenseMonteCarlo`，Board不按植物类型写特殊分支。没有可吸铁器时估值为零，铁器密集时则按目标数量和冷却自然增长；无磁性目标时用快照计数直接跳过扫描。普通爆区/蹦极、治疗、黑夜屋顶雷荷三类 rollout 循环调用同一事件函数，使植物对每种决策都产生一致影响。正式战斗仍以目标侧 `CanBeTargetedByMagnetShroom/ExtractMagneticItem` 为权威；推演快照只复制当下资格与 `GetMagneticSimulationLayer` 结果，不另建品种名单。未进入场景右边界的装备目标会等待入场后才可触发；白天候选卡由通用 `daytimeDormant` 画像保留阻挡生命但不虚构主动能力。

## 状态、存档与动画

`GoldMagnet : MagnetShroom` 只覆写充能时长和“成功剥离僵尸装备”钩子。READY/SUCKING/CHARGING、离体物飞行、音效和存档全部复用磁力菇，不增加平行状态或新存档字段。

使用独立 `GoldMagnet.reanim`，其原版包装轨只有 `anim_idle` 与 `anim_attract`；派生类让射击使用 `anim_attract`，充能和睡眠复用 `anim_idle`，白天另由通用 Z 指示睡眠。EMP在正式装备剥离边沿直接触发，不增加动画帧事件。屋顶花盆最终合成使用原生 `scale=1.0`、`offset=[-34,-44]`，保持水平居中并让下部叶片坐入盆口。

EMP视觉为约0.3秒的小型紫色圆环和少量火花，锚定被吸僵尸碰撞中心；表现范围不承担精确判定圈职责。复用已注册的 `PARTICLE_RAIN_CIRCLE` 和 `PARTICLE_STAR40`，无需新增位图。

- 6-7（内部52）奖励磁暴菇；6-6玉米加农炮和6-8占位保持不变。
- 专项覆盖真实屋顶花盆上的紫卡原位升级和世界包围盒、昼眠继承、12秒充能、范围内/外与魅惑目标、接地免控下仍可麻痹、绝缘反噬、扶梯不触发、快照往返、资源键和EMP粒子。
- 推演专项覆盖无铁器零收益、合法目标触发、装备与护甲层只消费一次、现有株剩余充能和100px麻痹范围。
- 奖励专项从6-7奖杯推进到6-8并断言只新增磁暴菇。
- 默认实例化与 `-NoInstance` 均做同步截图；最终验证使用 `clang-release` 可见桌面运行并检查退出码、日志、状态、断言和图片。
