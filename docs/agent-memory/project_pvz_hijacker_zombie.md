# 第六大关劫持者僵尸

## 数值与投放

- `ZOMBIE_HIJACKER` 为 1000 初始本体生命、50 每口伤害、普通移动；首次被 75% 雷荷锁定时当前与最大本体生命各增加 1000，单实体只应用一次。`gamedata.json` 权重/成本 2000、冒险常规出现波 9、生存第 15 轮起出现，正式每波最多 2 只。
- 6-4（内部 49）使用普通/路障/铁桶/铁门/劫持者精简池，第 7 波强制单只劫持者并消耗整波预算；6-5 使用普通/路障/铁桶/橄榄球/投篮车/劫持者组合池。

## 雷荷状态与选择

- 劫持者是正常波次僵尸，不由 75% 阈值生成。`Board` 的雷荷首次跨过 75% 时只从当时已经在场的有效同类中选择一次；选择当前 `body + helm + shield` 最高者，候选先按稳定 ID 排序，再只对同值最高组随机一次。之后新生成者不能补位。
- 场上至少存在一只有效劫持者时，小/中/大雨的雷荷基础输入分别在 1/2/3 之上固定增加 1.5 点/秒；多只不叠加，晴夜仍按原规则每秒漏 0.5。热路径只在劫持者专用弱索引首个有效候选处返回，不扫描普通僵尸。
- 选中者掉头或死亡会取消本轮劫持，资格不转移；掉臂不取消。取消不清空雷荷，满电仍走普通 4 秒预警和原放电。有效选中者把满电预警延长为 7 秒，最后 1 秒停止移动/啃食并播放 `anim_hijack`。
- 魅惑不移除技能。冻结、黄油和中立麻痹仍约束普通移动/啃食，但不延迟 Board 倒计时；终局动作通过固定 extra 倍率入口保持 100%，不受大雨、减速或定身改变时长。
- `EntityRegistry` 用 `ID → weak_ptr<HijackerZombie>` 稀疏索引覆盖 Add、带 ID 读档重建与周期清理。75% 边沿才遍历候选，Board 后续 Update/Draw 只按保存 ID 做 O(1) 查询；目标紫色脉冲由实体常数时间查询，不做每帧全场扫描。

## 处决快照

- 释放边沿先读取施法者当时当前可计生命，生存模式处决线上限 1200；气球等额外生命不计入。UI 在锁定期间实时显示 `处决线：N`，削血会同步降低。
- 同一前放电帧先快照所有目标再批量死亡。植物按格归并活动 `normal + pumpkin`，符合时两者一起死亡；`under` 层花盆/睡莲不参与也保留。僵尸按 `body + helm + shield` 比较，不区分阵营、品种、飞行/地下/蹦极阶段；符合者走通用处决死亡入口。
- 施法者在结算前先从 Board 清除锁定 ID，再逻辑死亡、关闭碰撞与索敌；另一只劫持者被批量处决不会连锁。普通放电继续在同一边沿按既有稳定 ID 快照结算。

## 动画、声音与资源

- `Zombie_Hijacker.reanim` 独立复制小丑时间线：idle 0～16、walk 17～35、eat 36～50、`anim_hijack` 51～66、death 67～89、ground 17～35；主人批准啃食第 45 帧与死亡第 89 帧事件，处决由 Board 定时边沿触发，不新增释放帧事件。
- 深紫黑电工服、厚框护目镜/侧表、紫黑接收器、铜线圈与伸缩特斯拉叉均由 `scripts/generate_hijacker_assets.ps1` 可复现生成。标志部件在 4× 分辨率绘制倒角、壳体厚度、铆钉、玻璃高光、内部电弧、线缆、褶皱与磨损后再缩回最终尺寸，禁止平涂矩形或儿童画轮廓。
- 断头隐藏 `anim_head1/anim_head2` 并抛出包含护目镜的专属单粒子；断臂换专属残端并抛出专属手臂粒子，接收器保留。75% 开始低嗡鸣，满电增强并警报，最后一秒急促；取消、死亡和释放都原子释放循环音所有权。成功处决与普通雷声同帧额外请求一次独立 `SOUND_HIJACKER_EXECUTE` 短促碎裂声，目标再多也不叠音，取消路径保持 0 次。

## 存档与验证

- `GameInfoSaver` 保存 Board 的选择已尝试、劫持者 ID、预警延长、终局阶段与本波已生成数；实体保存自身 phase、警报状态与锁定生命增量是否已应用。全部僵尸按原 ID 恢复后才 finalize Board 交叉引用，不重抽、不转移、不重复加血、不重播一次性反馈。
- 专项脚本为 `smoke_hijacker_execution.json`、`smoke_hijacker_cancel.json` 与 `smoke_hijacker_spawnlists_wave_cap.json`；分别覆盖魅惑+中立麻痹、75% 锁定加血与读档不重复、7 秒/1 秒时序、同帧处决与粒子，两只同场的雨中 +1.5 不叠加/晴天归零、单次 1800 植物伤害后剩 200、掉头取消不转移，以及 6-4/6-5 出怪池、教学波、每波上限和上限读档。
