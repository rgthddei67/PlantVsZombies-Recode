# 经典三叶草

2026-07-30 接入 `PLANT_BLOVER`：100 阳光、10 秒冷却，复用已导入 `Blover.reanim` 和
`blover.ogg`。`anim_blow` 与 `anim_loop` 统一以资源速度的 1.6 倍播放，在主人指定的全局
第 44 帧结算；预览不注册帧事件，演出进入 `anim_loop` 后继续播放，并在主人指定的全局
第 61 帧（最后一帧）死亡。

两段包装轨的边界必须直接切换：旧 `PlayTrackOnce` 返回轨固定带 0.5 秒 blend，会把
`anim_blow` 末帧和 `anim_loop` 起始段插值成资源中不存在的塌缩姿态（主人在第 55 帧实测）。
Animator 现已增加独立 `returnTrackBlendTime`，当前调用对进入/返回速度都传 1.6、进入/返回
混合都传 0；返回混合与返回速度一同进入通用存档，读档后不会退回 0.5 秒。

## 定向卡槽

- 每张三叶草 `CardComponent` 独立保存下一株的 `HOUSE/FRONT` 方向，默认朝前线。
- 右键直接命中游戏内三叶草卡槽即可切换，冷却中也允许；输入先于通用右键取消选择消费。
- 卡面右下显示方向箭头；三叶草卡图在通用卡图倍率上再乘 0.9，并与箭头同步水平转向；
  场上动画尺寸不变。
- 手持/格子预览镜像卡片方向，种下时把方向复制到实体；之后改卡不追溯已落地三叶草。
- 卡片方向、植物方向和是否已触发分别入档，旧档默认朝前线。

## 气球与天气

- 第 44 帧只处理仍在 `FLYING` 的气球；爆裂、落地、濒死和失活实例不响应。
- 朝屋后以 600 px/s 连续滑行，累计精确 400 px 后恢复普通飞行；重复同向三叶草会再累加
  400 px。朝前线以同速滑到 `SCENE_WIDTH + 80` 后才 `Die()`。
- 气球保存吹飞中标志、方向和朝屋后的剩余距离，读档可继续滑行。
- 当前有台风时，`Board::RedirectTyphoonFromBlover` 同时改持续风和正在进行的活动阵风方向，
  重置完整方向阶段并刷新方向视觉；不改台风强度、阵风预算/时长、已完成的植物换格或迷雾驱散。
- 三叶草本身从不写雾势或驱散量；普通雾回流导致驱散百分比自然下降不算三叶草吹雾。

等整体手感无误；随后明确校准为第 44 帧起效、第 61 帧消失，并要求卡图与方向箭头同步转向。
