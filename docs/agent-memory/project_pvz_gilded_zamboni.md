# 鎏金冰车僵尸与黄色冰道

## 当前实现

`ZOMBIE_GILDED_ZAMBONI` 使用金黄色车体、驾驶员衣物和帽子，2200 HP，基础驱动倍率 0.72，
比普通冰车慢。正式波次每波最多生成 1 只，计数随 Board 存档并只在推进新波时清零；
AutoTest 的显式直造不消耗额度。冒险 3-6（level 24）为 20 波
`{normal, cone, bucket, zamboni, gilded zamboni}`。

车辆在本行与相邻两行碾压植物，包含相邻水路；黄色冰道只铺在非水路并保持 30 秒。
Board 分行保存黄色左缘/寿命，旧档缺字段为空；黄色与普通冰道重叠时先截短普通段再绘制
黄色段，因此玩家只看到黄色，且两者都禁止种植。

## 速度与受击

每个仍存活且实际覆盖目标的鎏金冰车都是一个独立速度来源。普通僵尸必须处在该来源已经铺过
的黄色区间；鎏金冰车本体另含短距离车身覆盖，使相邻车辆可互相影响。每层对能力、寒冰、
雨势、台风等倍率分别应用 `1 + 2 × (m - 1)`，再把各分量相乘；两条活跃来源重叠会逐层
放大，例如大雨 `1.4→1.8→2.6`。来源死亡、车辆离开或范围变化后逐帧刷新层数。

自身连续 6/10/14 秒未受伤时基础蓄势为 ×2/×4/×8；任何本体伤害立即清零并回到 ×1，
最终能力倍率封顶 ×8。计时器和每个来源的独立黄色左缘入僵尸扩展存档。

地刺只造成 100 本体伤害，不爆胎、不伤地刺；大嘴花每口只造成 50 本体伤害，不能吞下车辆。
两者都通过车辆虚事件接入，不在植物侧硬编码鎏金类型。寒冰仍可减速，冻结最终优先停格。

## 验证

`smoke_gilded_zamboni.json` 覆盖 2200 HP、基础速度、三行铺路/碾压、黄色覆盖普通冰道、
单来源天气/寒冰放大、双车互相两层、6/10/14 秒蓄势与受伤归零、水路只压不铺、地刺 100、
大嘴花 50、同波上限和跨波重置。关键 dump 中两只鎏金冰车与重叠区普通僵尸均为
`goldenIceEffectStacks=2`，大雨动画速度投影为 260；可见运行退出码 0，日志以
`script finished OK` 结束。普通冰车、`smoke_night_rain` 和 3-6 出怪表可见回归也均为
正确窗口、退出码 0；`clang-playtest` 与 `clang-release` 构建通过且无编译器警告。
