# 第八大关机枪射手与极光树桩

## 玩法与投放合同

2026-08-29 已实现 `PLANT_GATLINGPEA` 与 `PLANT_AURORATORCHWOOD`：两者均为 225 阳光、30 秒卡冷和 300 生命的普通层紫卡。机枪射手覆盖双发射手，每约 1.5 秒在全局帧 60/68/74/80 发射四颗 20 伤普通豌豆；极光树桩覆盖火炬树桩。当前奖励为 8-3 极光树桩、8-4 机枪射手。

2026-08-29 北极星花与冰镜草实现时已完成奖励重排：8-2 北极星花、8-3 极光树桩、8-4 机枪射手、8-5 冰镜草、8-6 无奖励。机枪与极光的玩法数值保持不变，旧 8-2/8-3 奖励断言已由当前顺序取代。设计合同见 `docs/superpowers/specs/2026-08-29-polar-night-support-plants-design.md`。

极光树桩只转换审定豌豆射手家族的实际穿越弹丸，产生 50 点基础伤害的 `BULLET_AURORA_PEA`。一颗弹按实际飞行方向、再按稳定僵尸 ID 最多结算四个不同目标，同目标只命中一次；正常经过护盾/头盔/本体层，不绕过，免疫目标仍占命中名额。寒冰来源对实际目标减速，毒囊来源叠毒；前三次命中只发 `AuroraPeaPass`，第四次发独立 `AuroraPeaBreak` 并回收。冰墙承受 50 点非火伤并截停，屋顶平射遮挡同样强碎裂，不融冰或解冻。

## 转换、来源与存档

火炬与极光转换互斥，最后经过者决定当前弹型，但不重置极光命中历史，也不改写 `PlantDamageOrigin`。极光弹经火炬后变火豆，再经极光时依原发射植物恢复寒冰或毒素语义。`AuroraState` 用固定四槽侧车保存命中 ID、计数与首次声音状态；在途存档同时保存当前/分配弹型、两类树桩已命中列与原发谱系，对象池 `Reset()` 清空本轮侧车。

## 动画、资源与验证

机枪射手使用两个 Animator：根播身体 `anim_idle`，子 Animator 播头部 `anim_head_idle/anim_shooting`。原时间线没有 `anim_stem`，因此子 Animator 挂在 `anim_idle` 并抵消首帧 `(37.6,48.7)` 基准位姿。极光树桩复用火炬时间线，使用蓝紫树皮、独立染色嘴部和下移/放大的棱晶冠；极光弹为 48×30 的手绘能量核+棱晶外壳+尾迹，寒冰/毒素由同一母图确定性派生。

`smoke_gatling_aurora_torchwood.json` 默认可见 `clang-release` 专项覆盖资源键、紫卡覆盖、四帧四发、雪豆四目标与 Pass/Break 独立粒子、火炬/极光最后经过者、在途快照与 8-2/8-3 奖励；最终 116 条命令 ExitCode 0，`SaveSchemaTests` 通过，run.log 无粒子配置错误。
