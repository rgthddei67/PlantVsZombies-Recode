# 第六大关接地僵尸与通用控制免疫

## 玩法与数值

- `ZOMBIE_GROUNDING` 在 6-8（内部 53）首次出现，6-9 继续加入综合池；本体 270、啃咬 50、普通速度，天线路障 1200，成本 2000、`appearWave=6`、`survivalRound=9`，正式波次每波最多 2 只。
- 独立 `GroundingZombie.reanim` 复用普通路障全部时间线，只替换三阶段护具图；电紫/靛紫路障带铜色短天线、绝缘座和紫白端点。`scripts/generate_grounding_zombie_assets.ps1` 从普通路障确定性生成三图并锁 SHA-256，不新增动画帧事件。
- `GroundingZombie` 通过基类虚接口声明引雷类型身份、当前资格和天线世界锚点。仍戴着有耐久的天线路障、实体活动且未垂死才是新一轮候选；魅惑不取消资格。`EntityManager` 用按稳定 ID 有序的 `weak_ptr` 稀有索引收集候选，掉帽只让资格查询失败，不破坏类型索引。

## 统一满电选路

- 黑夜屋顶雷荷满 100 进入 WARNING 时，一次构造全部普通行和每只有效接地僵尸的引导路线。轻量蒙特卡洛开启时按每候选 32 rollout、10 秒时域、0.25 秒步长共同比较；局部随机只处理并列，不消费正式 `GameRandom`。关闭或推演失败时，有接地候选便在稳定集合中正式均匀选一只，否则随机普通行。
- Board 在选择边沿保存锁定行、是否引导和稳定 guide ID。随后换行、死亡、掉帽或后来出生都不重选；读档恢复同一事实。锁定实体失效时，本轮仍按植物专属路线放电，只跳过天线附着短弧和自身强化。
- 推演快照包含当前及未来种植画像中的减速、冻结、黄油、麻痹频率/时长，现有四类控制与临时/永久免控状态，以及已经进入前摇的寒冰菇待结算事件。普通路线模拟目标行植物停机、僵尸伤害/麻痹、湿坡数值和绝缘承接；引导路线模拟相同植物停机、全体僵尸免伤，以及有效引雷者按预计放电位置为 130 像素内同阵营僵尸发放 30 秒减速/冻结/黄油免疫。
- 五行加一只接地候选即 6 个候选、3 只推演僵尸和 3 株详细植物（含待触发寒冰菇）时，`clang-release` 最终专项状态记录默认实例 467 微秒、`-NoInstance` 448 微秒。开销只在满电边沿发生；每多一只引雷候选约线性增加 32×40 个纯数值时间步。

## 引导放电与免控

- 引导路线仍按目标行让普通植物停机 8 秒、活动径流湿坡植物停机 20 秒，并保留接地菇、避雷花盆等既有保护；本次不伤害、不麻痹任何僵尸。
- 放电瞬间锁定者若仍合格，以碰撞箱中心为圆心快照 130 像素内同阵营活动僵尸；每个目标立即清除减速、冻结和黄油并获得 30 游戏秒对应免疫。`PARALYSIS` 不在 mask 内，麻痹可保留、施加与刷新；灰烬与普通伤害完全不受影响。
- 范围只在放电边沿结算一次。强化发放后分别属于受益僵尸本体，目标走出范围、引雷者掉帽或死亡都不取消剩余时间；掉帽只阻止该接地僵尸参与下一轮候选。
- `ZombieControlEffect`、独立计时数组、位 mask、`GrantControlImmunity()` 和永久 mask 虚入口位于 `Zombie` 基类。冻结免疫只挡冻结定身：寒冰菇仍造成 20 点伤害且施加未被单独免疫的减速尾巴；黄油弹伤害与 `ApplyButter()` 定身分开；麻痹入口独立拒绝。临时计时入僵尸存档，旧档默认 0，读档修复“已免疫却仍受对应控制”的矛盾状态。

## 视觉、资源与验证

- WARNING 在天线尖端绘制小型紫白光点和两条短弧；DISCHARGING 叠加约 32px 四段引线，并在有效选中者上发射 `GroundingZombieLightning`。路障掉落使用 `GroundingZombieConeOff`，不污染普通路障资源。
- 资源闭环覆盖 reanim、三阶段运行时图键、reanim 贴图键、两种粒子配置和 manifest；默认实例化与 `-NoInstance` 使用同一权威 `build/clang-release/resources`。
- 专项 `smoke_grounding_zombie` 覆盖 270/1200、6 候选/32 rollout、锁定存读档、植物专属停机、130 像素内外与魅惑异阵营边界、清减速/冻结/黄油、仍可麻痹、冻结仍伤 20、掉帽后既得免控保留、免控存读档与 30 秒到期；`smoke_grounding_spawnlists_wave_cap` 覆盖 6-8/6-9 出怪表、每波限 2、直造不计数、换波清零与计数存档。纯数值测试锁定引导保全僵尸压力、普通高价值行可胜无效引导，以及寒冰菇待结算时优先覆盖附近攻击者的引雷路线。
