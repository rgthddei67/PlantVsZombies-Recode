# 冰车僵尸与冰道

## 行为契约

- `ZOMBIE_ZAMBONI` 是最后一个已实现类型，1350 本体血量，播放 `anim_drive`。
  车辆不啃食、不留普通阴影，免疫魅惑、减速、冻结、缠绕水草和植物直杀。
- 前进速度保留 C# 的相对曲线，但不再直接使用原版世界坐标：普通场景以
  `CELL_INITALIZE_POS_X=242` 为基准，基准后 X=300..700 在线性 5..25px/s 间取值，
  进入基准后 X<=400 时固定 10px/s；雨势和台风倍率继续通过 Board 公共入口叠加。
  当前仍禁止正式屋顶波次生成冰车；AutoTest 直造仅用于验证屋顶场地效果，不代表解封出怪。
- 寒冰豌豆仍正常造成伤害、播放车辆命中声并生成命中粒子，但先过 `CanBeChilled()` 总闸；
  冰车不会获得减速状态、蓝色覆色，也不会播放 `SOUND_COOLDOWNZOMBIE` 假反馈。
- 每帧用车辆专属 133×140 攻击矩形检查同排植物，水平重叠至少 20px 后调用
  `Plant::Squish()`。樱桃炸弹、火爆辣椒和倭瓜不碾；醒着的寒冰菇/毁灭菇不碾，
  睡着时可碾。地刺草/地刺王不走普通碾压；地刺第 25 帧命中后调用车辆拥有的虚入口
  `HandleCaltropHit(Caltrop&)`，供后续精英冰车覆写自身受扎语义。
- C# 的碰撞框、攻击框和冰道前缘先换算为相对车辆稳定视觉原点的坐标：碰撞框
  `(-68,+10,153,140)`、攻击框 `(-58,+10,133,140)`、冰道左端 `+50px X`。
  物理位置使用 `Transform + mVisualOffset`，不叠加低血量抖动；因此子弹框、碾压框、
  车辆贴图和冰道端盖共用同一基准，不再向右下偏移。
- 车辆按 2/3、1/3 血量阈值换两段破损贴图；二段每 0.25 秒补烟，低于 200 HP 时
  以每次更新 1/5 概率自损 3。低血量随机故障抖动仍保留，但从原先每轴 ±1px 收敛到
  每轴 ±0.35px；预览与满血驾驶不叠加这层抖动。
- 二段损坏烟雾以稳定视觉原点为基准，使用由原版逻辑点换算得到的 `(-41,+95)`；
  不再直接套用 800×600 原版的 `(+27,+72)`，以免烟雾落到当前车体下方。
- 普通冰车被地刺扎中后让地刺消失、车速归零并关闭碰撞，切二段破损与扁胎贴图；
  原版 `TirePop` 映射 `balloon_pop.ogg`，同时在稳定视觉原点 `(+29,+114)` 生成
  `ZamboniTire` 泥土碎屑/短烟。车辆按 C# 的 1/4 条件概率播放 `anim_wheelie2`，
  否则播放 `anim_wheelie1`，2.8 秒后走既有爆炸退出。受扎标记和剩余时间进入存档，
  读档恢复停止、碰撞与扁胎终态。

## 死亡与灰烬

- 普通死亡不会进入普通僵尸死亡轨道：本体同帧立即消失，在车辆稳定视觉原点
  `(+12,+73)` 生成 `ZamboniExplosion` 粒子并播放爆炸声。该值由 C# 的逻辑坐标
  `(+80,+60)` 相对其 `(+68,-23)` 绘制原点换算，再按主人要求上移 10px；不直接使用
  原版 800×600 坐标。粒子配方包含爆发云、车盖、零件、车轮和刷子。
- 灰烬伤害使用独立 `ZamboniCharred`。车辆本体仍同帧消失，不生成普通死亡粒子；
  残影锚定最后一帧画面位置，缩放为主人指定的 0.9，并以 +18px Y 校正缩小后的轮胎落地点。
  专属残影在第 53 帧移除；53 只属于灰烬残影，不延迟车辆本体死亡。
- `ZOMBIE_BOBSLED` 已从 `ZombieType.h` 删除；本任务不生成雪橇小队。

## 冰道与关卡

- Board 按行持有冰道左缘和剩余寿命。冰车出生后每帧立即刷新 30 秒寿命，不再等待
  原版 `frontX<860` 门槛；车仍在屏幕右侧时左缘钳在 `SCENE_WIDTH=1100`，进入画面后
  从屏幕最右端连续向左增长，而不是从房子一侧开始。
- 冰道禁止覆盖格种植，最后 0.1 秒渐隐。左缘、寿命随存档保存；旧档缺字段时初始化为空冰道。
  火爆辣椒把同行冰道寿命压到 0.2 秒。
- 屋顶按原版只在平台留冰：普通/鎏金冰道左缘都钳到坡顶 `X=642`，绘制 Y 固定取平台行中心，
  不沿坡面折线或连续弯曲。该路径由直造专项覆盖，正式出怪限制不变。
- 冰车不能生成在泳池水路或屋顶。`gamedata.json` 为权重 2000、冒险第10波出现、
  生存第7轮解锁；冒险 3-5（level 23）为20波
  `{normal, cone, bucket, zamboni}`。

## 2026-07-26 鎏金冰车扩展点

普通冰车将铺路、碾压行判定、地刺/大嘴花事件、损伤贴图前缀和基础驱动倍率提升为虚扩展点，
`ZOMBIE_GILDED_ZAMBONI` 复用同一 reanim 时序而不新增帧事件。载具动画和手动 X 位移现在
消费同一组能力、寒冰、雨势与台风倍率，避免只看起来加速而实际车速不变。详细数值、黄色
冰道来源叠层和 3-6 接入见 [project_pvz_gilded_zamboni](project_pvz_gilded_zamboni.md)。

试玩反馈后，普通死亡入口也改为通过 `GetDeathParticleEffectName()` 虚扩展点选择粒子：
基类仍返回 `ZamboniExplosion`，鎏金变体返回独立 `GildedZamboniExplosion`，防止换色车辆
死亡时复用普通蓝色车盖、车轮和滚刷。
