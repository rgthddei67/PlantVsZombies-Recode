# 第六大关急救员僵尸

## 玩法与数值

- `ZOMBIE_HEALER` 在 6-6 首次登场，复用普通僵尸骨架、移动和既有啃咬/死亡帧事件；本体 800、啃咬 50、权重 2400、`appearWave=3`、`survivalRound=7`，不新增动画帧事件。
- 出生从 6 秒共享冷却开始，施法前摇 1 秒。关闭轻量蒙特卡洛 AI 时，140px 内至少 3 名同阵营伤员（含自己）便群疗并对全部目标的每个现存生命层恢复 60，不限制数量；否则锁定 280px 内一名非自己的伤员，每层恢复 300。只有实际恢复生命才进入完整冷却，目标失效或零治疗在 0.5 秒后重试。
- 单疗优先当前黑夜屋顶已锁定劫持者；其他目标按现存本体/一类/二类层的最低剩余比例、再按稳定实体 ID 排序。多名急救员用 `EntityManager` 有序弱索引协调同帧选择与单疗预留。该索引只镜像 `weak_ptr`，主 `mZombies` 仍保留所有实体，`ForEachZombieInRow` 与专用索引计数专项一致。

## 生命层、状态与交互

- 治疗分别夹紧现存且大于 0 的本体、头盔和盾牌；已掉落、磁吸或部署的装备不重建，气球 extra health 不参与。通用 `RefreshEquipmentPresentationAfterRepair()` 让各品种虚检查从当前耐久重新派生完整/轻损/重损贴图，修复了原先只能单向破损的显示合同。
- `IDLE/AREA/FOCUSED/DISABLED` 分别使用折叠、绿色三加号、紫色单加号和烧焦垂下标志。施法优先于啃食：原子平衡食客计数并停吃，治疗结束后仅在原目标仍有效且仍处于 6px 咬合间隙时恢复同一目标。
- 断头始终永久禁疗；有效难度 `<=2` 时断臂永久禁疗，`>2` 继续治疗。魅惑取消旧阵营目标/预留但保留冷却。预览固定 `IDLE` 与 6000ms 冷却，不推进决策、声音或粒子。
- 存档保存状态、冷却/重试/前摇、单疗目标、待恢复啃食目标、累计战略等待、最近推演动作/统计和永久禁疗；读档修复无头、低难度无臂、零前摇施法等非法组合。

## 蒙特卡洛选疗

- 主菜单轻量蒙特卡洛 AI 开启时，急救员在 6 秒决策边沿比较一次群疗、每名未预留伤员的单疗，以及各动作延后 0.5 秒的副本；128 rollout、0.25 秒步长、7 秒时域，详细推进最多 16 只僵尸。群疗正式结算仍无目标上限，样本外伤员只以有界终局压力汇总。该短时域选疗预算与蹦极/精英小丑的长时域选点预算独立调节。
- 等待保持 `IDLE` 并在 0.5 秒后读取真实棋盘重推演；累计最多 2 秒且入档，达到上限后只留立即动作。同收益严格选择立即动作，等待必须实际提高进攻收益。魅惑侧模型不适用或推演失败时完整回退确定性规则。
- Board 快照包含植物/卡槽、僵尸本体/头盔/盾牌和其他急救员待结算治疗。当前已锁定劫持者强制进入样本；预警阶段按正式剩余秒数提交处决，充电阶段按当前雨势估算满电时间，超出时域的处决收益做时间折损。全部候选使用共同随机种子且不消费正式游戏 RNG。
