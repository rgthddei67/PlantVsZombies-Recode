# 经典巨人僵尸与小鬼

## 当前实现（2026-08-09）

- `ZOMBIE_GARGANTUAR` 为 3000 本体生命，不掉手、不掉头，也没有普通僵尸的 35 血流血临界；生命大于 0 时保持完整行动，归零才原子终止砸击/投掷并进入 `anim_death`，第 196 帧回收。生命低于 `2/3`、`1/3` 时按 C# 资源分别恢复两档身体、外臂、脚和头部创口贴/伤势材质，阶段由当前生命派生而不额外入档。
- 行走接触目标后进入一次砸击，第 93 帧压扁目标格全部活动植物层；魅惑巨人则对敌对僵尸造成 1800 伤害。砸击目标、结算防重与动作 phase 入档，死亡或魅惑通过 `OnMindControlled()`/统一撤销路径清理，读档还会修复动作与轨道不匹配的旧状态。
- 巨人降至半血且越过投掷锚点后只投一次小鬼。第 124 帧才是实际脱手：创建成功后配置阵营、抛物线和巨人剩余减速，再清除唯一权威 `hasImp` 并隐藏背部小鬼；第 130 帧只是动作尾部。离手前、离手后但投掷动作未完、动作完成三态均可存读档，禁止从场上小鬼数量反推库存。
- 右手武器每次正式创建按原版 65% 电线杆、25% 鸭子过街路牌、10% 普通僵尸随机，并保存具体结果；图鉴、预览和 5-8 不设特殊武器判断。巨人整体视觉偏移为 `[-62,-107]`，碰撞框继续锚定逻辑原点 `(-17,-38,125,154)`，避免视觉校准改变砸击范围。
- `ZOMBIE_IMP` 为 270 生命，状态为 `THROWN -> LANDING -> WALKING`。飞行位移、高度、重力和落地动画均消费减速后的时间；飞行/落地期间关闭地面碰撞、啃食、地雷、水草、冻结、黄油和地面弹丸命中，完整保存 phase、高度、水平/竖直速度与方向。
- 小鬼啃食帧为 44/55，普通死亡第 81 帧、化灰第 34 帧；巨人化灰第 42 帧。小鬼断头/断手粒子分别从 `anim_head1` 与 `Zombie_imp_outerarm_upper` 的世界轨道锚点发射，XML 不再叠固定实体偏移。
