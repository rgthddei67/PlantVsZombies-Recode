# 黑夜随机雨势天气

> 2026-07-29 范围更新：天气不再以“黑夜背景”为开关，而由 `Board::SupportsWeather()` 统一判定；冒险模式从 2-1（level 10）起均启用，因此日间泳池也使用同一天气状态机。白天无尽 level 1000 仍不启用，黑夜无尽 level 1001 与泳池无尽 level 1002 启用。下文大量“黑夜”描述是历史建设语境，当前以此段和源码为准。

## 当前实现（2026-07-21）

### 四大关迷雾（2026-07-29）

四大关 `NIGHT_WATER_POOL` 现有独立于雨势的 `FogWeatherIntensity::DEFAULT/SMALL/NORMAL/DENSE` 四档雾势状态机，由 `Board` 唯一持有。C# 原版雾线按九关制换算为 4-1 基准列 6、4-2～4-6 基准列 5、4-7～4-9 基准列 4；主人当前定案为：默认雾势保持原版长度并只画原版主层，小雾向屋侧扩 1 格、普通迷雾扩 2 格且两者都加 1 个错帧补层，大雾扩 3 格并加 2 个错帧补层。每层仍使用原生 210×190 雾片按 80×85 格距高重叠，逐格稳定二维伪随机选择 `fog.png` 的 8 帧，不铺固定白底幕。`fog.png` 由 `fog.jpg` RGB 与 `fog_.jpg` 灰度 alpha 合成，资源清单按 `Column=8/Row=1` 切分。

雾势独立计时：战斗开始 45～70 秒后首次抽取；随后按“原版默认雾休整 → 小雾/普通迷雾/大雾事件 → 默认雾休整”循环。默认段持续 50～80 秒，增强雾势事件持续 35～55 秒；事件中大雾概率随既有天气导演从主人当前的 45% 平滑到 85%，剩余概率在小雾和普通迷雾间尽量均分。阶段结束前 15 秒锁定准确雾势预报，和雨势预报同时显示但不复用雨势误报语义。

任何台风都会持续增加同一 `fogDispersal`：普通/强/超强每游戏秒分别驱散 0.08/0.16/0.28，完全驱散会提前结束当前增强雾势事件并回到默认雾休整；停风后每秒回流 0.06，恢复当前档位覆盖。吹向屋子时所有雾层向负 X 漂移，吹向前线时向正 X 漂移，最大 180px；层数不建立独立存档状态，全部消费同一逐格 alpha、驱散和偏移，因而不会留下补层残影。雾势、预报、阶段计时、驱散与偏移进入关卡存档；关卡 schema v3 把 v2 的旧 `CLEAR/DENSE` 值迁移为视觉等价的 `SMALL/DENSE`，v1/无版本旧档仍由当前关卡上下文保留 `StartGame()` 建立的原版默认雾。

`smoke_fog_weather.json` 覆盖非四大关 no-op、4-1/4-6/4-7 原版默认雾线、默认/小雾/普通迷雾/大雾的 0/1/2/3 格扩展与 1/2/2/3 层、前线/屋侧双向偏移、超强台风完全吹散、停风回流、雾势预报与隔离快照往返；视觉截图必须同时确认默认雾保持原版稀密度、增强雾势补层无固定白底幕、台风吹净后无残影。

### 雨势天气

黑夜关用间歇式小/中/大雨替代墓碑机制；白天背景不启用。战斗开始后 80～90 秒出现首场雨，完全放晴后仍保留 15～40 秒恢复间隔。天气导演强度取既有场次成长与独立压力曲线的较大值：新天气“续晴/小雨/中雨/大雨”权重从前期 15/40/40/50 平滑到满压力 0/10/25/65；导演达到 75% 后，若本轮新天气不是大雨，下轮新天气强制大雨，故后期最多只间隔一轮弱天气。该连续弱天气计数进入关卡存档，旧档默认 0。前期新雨仍统一持续 85～150 秒；满压力新小雨缩短到 45～70 秒、中雨 60～95 秒，大雨保持 85～150 秒。尾雨前期统一 45～80 秒，满压力小雨缩短到 20～35 秒、中雨 30～50 秒，大雨保持 45～80 秒。初始小雨结束时中雨/大雨/放晴权重为 30/45/30；中雨的“小雨/晴天”由 20/70 变到 15/95，大雨的“中雨/小雨/晴天”由 45/20/40 变到 55/5/40；新中/大雨各至多拥有一次权重 15/20 的同档续期。续期或切档后只允许衰减，尾端小雨必定放晴，雨链仍然有界。天气强度、阶段剩余时间、大雨闪电计时、小雨增强资格、同档续期资格、过渡来源雨势与过渡余时随关卡存档；瞬态粒子和地面水花不存档，`StartGame()` 按剩余天气重建。

天气预警：每个晴/雨阶段结束前 15 秒预抽取并锁定真实下一天气；公开预报准确率随天气导演从前期 75% 平滑提高，最高严格封顶 90%。误报只从当前动态非零权重、且不同于真实结果的候选中选择；满压力续晴权重为 0 时不会再预报续晴，弱天气保底要求大雨或无增强资格的尾端小雨只有单一合法候选时强制报准。预报与当前天气相同时，牌子明确追加“（持续）”。左上角面板用未缩放时间滑入/滑出，第一行显示当前天气，第二行显示公开预报与揭晓倒计时；天气揭晓后继续显示当前结果 5 秒，随后即使仍在下雨也会收回，直到下一次预警再出现。揭晓不一致时在面板下方弹出约 3.2 秒的非模态红色提示，显示“预报 → 实际”，不暂停也不抢输入。公开预报、真实下一天气、ready 标记和当前天气展板的剩余显示秒数均进关卡存档；失败提示的剩余时间、错误预报与实际天气也一起保存，读档从原动画进度继续，归零后不重播；只有主面板的滑动进度不存档。

大雨分级警报：真正进入新大雨前 5 个游戏秒，中央弹出文字横幅；无台风、台风、强台风、超强台风各有 3 句同级文案并等概率锁定，每档前两句为“七字，七字”且同句押韵的唐诗式对句，第 3 句用全大写英文制造突发灾难警报的反差。文字不直报等级，只通过逐级增强的辞势与冷蓝、金黄、橙红、绯红色阶暗示威力。`GameScene` 的提示由单实例改为按出现顺序保存的图片/文字队列，既有“一大波僵尸正在接近”与大雨警报可以同时存活，越晚出现越晚绘制。为了让提前提示可信，公开天气预报锁定时同步预抽取完整待生效台风初态与文案编号；当前台风、保底和玩法倍率仍到切入大雨时才改变。待生效等级、风向、首档计时、阵风预算与文案编号均进关卡存档，读档不重 roll。

大雨附加台风：每次真正进入新大雨阶段只判定一次，基础概率随天气导演从前期 75% 平滑升到满压力 95%；每次落空后下次额外增加 20 个百分点并封顶 100%，因此满压力大雨最多落空一次。保底次数随关卡存档，读档不重 roll，也不能靠反复读档清掉落空记录。命中后普通/强/超强台风权重从前期 40/45/45 平滑到满压力 15/45/40，强/超强合计 85%，超强占 40% 但仍不过半，并保留 15% 不移动植物的普通台风作为缓冲。强度只按 `超强台风 → 强台风 → 台风 → 结束` 单向衰减，不在同一场大雨中重新增强；超强/强/普通台风衰减前分别维持 55～70、50～65、50～55 游戏秒。风向每 15～25 游戏秒独立二选一重抽，抽中当前方向则继续维持。台风期间天气面板常驻并显示实时风向；普通台风显示“持续风（无位移）”，强/超强台风显示阵风倒计时或阶段结束。强度衰减会重新显示 5 秒当前天气通知，普通台风消散后面板恢复原本的预报生命周期。

台风玩法：僵尸自主水平位移先应用大雨 1.40，再乘台风相对倍率；敌对僵尸顺/逆风在普通、强、超强三档依次为 1.08/0.92、1.14/0.86、1.20/0.80，魅惑僵尸因实际移动方向相反而交换顺逆风。台风不改 Animator、攻击或技能计时。普通台风没有阵风位移；强台风等待 12～16 秒、单次 1 格、活动 1.8 秒且每阶段最多 3 次，超强台风等待 14～17 秒、单次 2 格、活动 2.4 秒且每阶段最多 2 次；等待上限均短于对应最短衰减时间，避免自动流程尚未起风就先降档。活动阵风开始时锁定强度与风向，植物结算点一次性预抽在 25%～75% 进度内；衰减与转向计时在这段短阶段暂停，结束后才继续。阵风按风向从前缘逐格结算植物：目标有植物则留在原格，吹入弹坑或越过地图边缘则直接死亡。弹坑本身保留，不能作为挡风墙保护相邻或后方植物。

活动阵风同时对全部存活僵尸施加独立于自主行走的物理漂移：强/超强峰值为 18/32 像素每游戏秒，使用 `4p(1-p)` 包络从 0 平滑升到峰值再回落，单次总漂移约 22/51 像素，明显小于植物 1/2 格。冻结和啃食中的僵尸仍会连同 Transform/碰撞箱一起被吹；魅惑只改变自主行走方向，不改变空气的物理吹向。吹向前线时横坐标钳在画面右缘外 60 像素，低于既有 +65 像素清理线，防止刚出生僵尸被阵风误删；吹向房屋不设额外保护，保留天气威胁。阵风把啃食者吹离目标时由正常碰撞退出链停止啃食。

轻型植物子弹响应实时风向：豌豆、寒冰豌豆以及未来火豌豆按自身 `velocityX` 判断顺逆风；普通/强/超强三档水平速度倍率依次为 1.05/0.95、1.10/0.90、1.15/0.85，命中伤害倍率依次为 1.05/0.95、1.08/0.92、1.12/0.88。孢子、投掷物、重型弹丸、篮球和僵尸豌豆不响应。倍率只在 `Bullet::Update()` 与 `Bullet::BulletHitZombie()` 的公共结算点从当前 Board 台风状态派生，不改写基础速度/伤害，故风向翻转会立即影响在途子弹，放晴自动还原，存档仍只保存基础值。`Bullet.cpp` 的风力档案表必须与 `BulletType` 数量和顺序完全一致；新增或重排枚举而未明确选择风力响应会触发编译失败。

植物换格把逻辑 `row/column`、Cell 占用、Transform 与碰撞箱在随机结算当帧立即切到目标格，再以 0.45 游戏秒纯视觉偏移让本体、阴影和血条平滑追赶。存档只记录已经结算的目标格，不记录视觉偏移；因此滑动中保存/读档会直接落在目标格，不会卡在半格。台风强度、风向、强度衰减余时、转向余时、阵风等待、剩余预算，以及活动阵风的锁定强度/方向、总时长、余时、植物结算余时和已结算标记均入关卡存档；读档继续剩余僵尸漂移，且植物至多结算一次。僵尸实际漂移后的 Transform 本来就在僵尸存档中；风线粒子与植物视觉插值仍属瞬态，读档后按逻辑状态重建或归零。

倍率口径：基础僵尸小/中/大雨倍率为 1.15/1.25/1.40；独立天气压力在普通关从 40% 波次进度开始、到 75% 达到完整压力，黑夜无尽则从第 8 轮到第 20 轮单独 smoothstep，完整压力下三档平滑到 1.20/1.35/1.55。30 波普通关的第 20 波历史断言约为 86% 压力；2026-07-27 当前源码实测为 97%，后续须重新核对压力曲线。倍率统一进入 `Zombie::UpdateAnimSpeed()` 的 extra 层，组合式为 `GetAbilityAnimSpeedMultiplier() × slowFactor × rain`，冻结优先置 0；正式波次或轮次推进会刷新现存僵尸。植物小/中/大雨倍率由前期 1.10/1.15/1.20 随同一压力平滑到 1.00/0.97/0.93，只通过 `Plant` 辅助方法影响攻击、生产、成长和恢复，不改全局 delta，也不影响索敌、受伤、死亡、爆炸清理或卡片冷却。僵尸与植物倍率都由已持久化的波次/轮次派生，不新增存档字段；只有影响未来抽取的弱天气保底计数需要单独存档。

视觉：`RainLight/Medium/Heavy.xml` 位于两个 `build/<preset>/resources/particles/config/`，复用 WhitePixel，使用细、低透明、冷蓝、逐滴亮度不同的斜雨丝。小雨为初始 72 粒、每秒 80 粒、alpha 峰值 .25；中雨为 52/60/.25，但通过更粗、更长、更快及更暗的幕保持强度差异，大雨为双层发射器。台风期间大雨改用 `RainHeavyTowardHouse/Front.xml`：吹向屋后以 X=-430/-480、正 28°～37° 形成左斜雨，吹向前线以对称正 X 与负角度形成右斜雨；翻向时 `ParticleSystem::StopEffect` 只停止旧雨继续发射，在途雨丝自然淡出，新方向按剩余雨时立即接管，不能用 `ClearAll()` 误杀爆炸和水花。天气通过正的运行期时长把发射器切成循环模式，`SpawnMaxLaunched` 只作为可复用池容量，不再用累计总配额硬撑整场雨；`Board` 每帧核对当前雨势发射器，若被清理或异常停止会按剩余时间自动补发。地面水花沿用原版 `Rain_splash1～4` 与 `Rain_circle` 贴图，每次在 9×5 草地网格内随机落点播放约 0.3 秒的水花与扩散圆圈；按较大游戏窗口定稿为小/中/大雨平均约每秒 5/10/20+ 次（间隔 0.16～0.24、0.08～0.12、0.02～0.04 秒），落点距网格边缘保留 18px，避免素材跑出屏幕。`ParticleRotation` 显式使用时走“世界中心旋转后再拉伸”的矩阵路径，避免细长贴图角度被压回竖直。暗幕在默认世界粒子之后、UI 之前绘制，统一压暗背景、实体、雨丝、爆炸和命中飞溅，但不压卡片、按钮与文字；当前 alpha 小/中/大为 34/55/110。仅大雨触发程序化闪电：每次固定 10 段冷白主干与 3 组二段分叉，使用独立视觉随机序列避免扰动天气/出怪；0.42 游戏秒内播放主放电与较弱回闪，并在云层和草坪落点绘制有限半径蓝紫散射光。闪电在世界暗幕后、UI 前合成，不再调用寒冰菇的全屏白闪；路径、光照与视觉序列均属瞬态，不入存档。

风线视觉：两个 preset 都有 `WindTowardHouse.xml` 与 `WindTowardFront.xml`，共用原创 `WindStreak.png`，分别从画面右/左边缘外横穿逻辑画面。该 32×256 RGBA 纹理由内置 `imagegen` 在纯品红背景生成单根冷蓝风痕，再按技能流程去色键、验证透明角与半透明边缘后缩图入库；尖端、亮芯和柔和光晕让它在复杂草坪上可见而不再呈硬白直线。每批仍为 10 粒，`ParticleScale [.32 .50]` 与 `ParticleStretch [.75 1.10]` 形成约 61～141px 的随机长度，峰值 alpha .22。三档强度只由 `Board.cpp` 顶部发射间隔 0.30/0.20/0.10 秒控制，因而普通最疏、强台风居中、超强台风最密；风向翻转时立即发射新方向，旧方向粒子在最长 1.15 秒寿命内自然淡出。粒子对象不进存档。

声音：对照 C# 原版 `Challenge.InitLevel()` 的 `PlayFoley(FoleyType.Rain)`、`TodFoley` 中 `SOUND_RAIN` 的 flags=5（Loop + MuteOnPause）以及 `Board.DisposeBoard()` 的 `StopFoley(Rain)`。复用原版 `rain.ogg`，本实现通过 `AudioSystem::PlayLoopingSound/StopLoopingSound` 按资源键唯一追踪循环声道；小/中/大请求音量为 0.20/0.28/0.48，仍乘主音量与音效音量。切档时僵尸倍率、植物倍率、暗幕 alpha 与雨声音量共用 2 游戏秒 smoothstep 过渡，旧雨丝自然收尾并与新发射器短暂重叠；雨转晴时等淡出结束才停止循环声。SDL_mixer 的声道音量会跨播放保留，因此循环状态同时保存 `Mix_Chunk*`：停止、查询和调音前校验声道仍属于该资源，回收后恢复 `MIX_MAX_VOLUME`；普通音效播放也主动复位取得的声道，避免复用低音量雨声声道后随机“吞音效”。

## 资源与验证

- 后续新增雨天专属能力、精英僵尸雨势强化、雨天变异/条件生成或继续修改天气状态机时，先使用 `.agents/skills/adding-rain-weather/SKILL.md`；新僵尸、植物、粒子或生存词条同时叠加各自技能。
