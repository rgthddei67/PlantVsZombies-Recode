# 第八大关北极星花与冰镜草

## 当前状态

2026-08-29 已完成玩家可感知设计定案，尚未实现。权威规格为
`docs/superpowers/specs/2026-08-29-polar-night-support-plants-design.md`。当前源码仍按 8-2 机枪射手、8-3 极光树桩、8-4 无奖励运行；不得把本条的奖励重排、两株植物或验证边界描述成当前实现证据。

## 奖励重排

后续实施顺序已定为 8-2 北极星花、8-3 极光树桩、8-4 机枪射手、8-5 冰镜草、8-6 无植物奖励。该调整让玩家在 8-3 首次保证白毛风前取得导航工具，并保持极光树桩先于机枪射手、冰镜草在热感狙击僵尸完整教学后才可用。

## 北极星花

`PLANT_NORTHSTARFLOWER` 暂定为 125 阳光、30 秒卡冷、300 生命的普通层非攻击植物。每株先蓄能 12 秒并保持就绪；覆盖范围为自身逻辑格周围 3×3。范围内自动植物确因三格雪盲失去远处合法目标，或自动/手动抛射物即将受强风偏行时，最近的就绪北极星花在动作提交前开启 8 秒领域，使当次动作立即取得导航。

领域内植物无视雪盲但保留原目标合法性；受风弹体在生成时快照风切免疫，飞出范围、领域结束或来源植物死亡都不回滚。重叠领域只按有无结算；同次请求按曼哈顿距离、稳定植物 ID 选择一株，同逻辑步的输出植物按稳定 ID 依次处理。每株独立计时，不设每行、同时或全场上限。

死亡、铲除或带走会立即终止新导航并让远目标恢复既有丢失规则，在途弹体不回滚。表现为八角星花、罗盘充能、极光柱、3×3边界、受益星标和导航弹星尾；不新增动画帧事件。阶段、余时和弹体导航快照未来入档，加载不重播反馈。

## 冰镜草

`PLANT_ICEMIRRORGRASS` 暂定为 100 阳光、20 秒卡冷、300 生命的普通层非攻击植物。出生零镜，每 12 游戏秒逐面凝结，最多两面；两层均可拦截左右任一方向、确实穿过本格且能够伤害植物的敌方水平直射弹。每面完整抵消一枚后破碎，不设生命、不反射、不伤害或施加状态。

镜面是本体附属拦截层，不占格、不接受啃食/铲除/范围伤害；合格弹体顺序为外镜、内镜、南瓜、普通、承载层。抛射、爆炸、近战和地面效果旁路。凝镜不受极夜三仪表或白毛风影响；植物离场同时清除镜面与进度。库存、下一面 0～12 秒进度未来入档，加载不重播凝结或碎裂反馈。

视觉以新蓝青草丛、双弧形晶片和双环晶芽显示库存及进度；拦截使用约 0.4 秒白蓝碎镜，与热脉冲红橙命中叠加，避免误判弹体消失。玩法不新增动画帧事件。
