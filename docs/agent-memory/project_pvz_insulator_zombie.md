# 第六大关绝缘僵尸

## 身份、防具与表现

- `ZOMBIE_INSULATOR` 是 6-2 首次登场的普通骨架品种，本体 300；胸甲是一个
  `HELMTYPE_INSULATOR` 一类防具生命池，1200 生命，不存在额外分段生命。
- 胸甲按剩余生命 `>800`、`401..800`、`1..400` 派生完整/轻裂/重裂三张低细节贴图。
  附件跟随 `Zombie_body` 的完整仿射变换，并用 `drawAfterAllTracks=true` 延迟到全部本体轨道之后，
  因此身体和手臂不会盖住胸甲。破甲、磁吸、死亡与读档统一刷新 follower 显隐。
- 三张 72×72 PNG 位于权威 `build/clang-release/resources/image/reanim/`，由
  `scripts/generate_insulator_armor.ps1` 可重复生成并锁定 SHA-256；此前精细参考图未直接入库。

## 干燥、湿润与雷荷

- 干燥且有甲时，Pea/Snowpea/Toxicpea/Puff/Star 和仙人掌尖刺基础伤害减半；火球、投掷物、
  大喷菇与灰烬按原伤害逐层结算。尖刺在按倍速累计帧伤前经目标虚接口缩放，保留小数余量。
- 干燥绝缘者可为同阵营、同排、1.5 格内的地面目标承接黑夜屋顶放电。Board 在一次排序 ID
  快照中按距离再按稳定 ID 选唯一提供者；每个目标只承接一次。普通瓦面每目标扣甲 75，湿坡
  基础目标为 120，均不向目标或本体溢出。成功后过载 15 秒，重复只刷新；过载让自主动画/移动
  倍率为 2.2、单口伤害 50→100，通用冻结/黄油/麻痹仍优先。
- 站在活动径流所选行的坡段时保持湿润；离坡后残留 6 秒并入档。湿润会关闭轻弹减伤、承接和
  过载，植物来源对胸甲伤害乘 1.5；倍率只消费胸甲所需的原始份额，不能把放大溢出灌入本体。
- 放电瞬间仍位于湿坡时固定扣胸甲 360 且不溢出，并沿用当前湿坡放电的 5.5 秒麻痹；仅残留湿润但已离坡时仍按
  普通瓦面 75/0.75 结算。无甲后恢复普通僵尸放电链。

## 磁力菇、出怪与存档

- `ExtractMagneticItem` 一次卸下整件胸甲，离体物使用当刻裂纹贴图，并在通用
  `MagneticItem::extractorSelfDamage` 返回 150。磁力菇先进入吸取/充能并接管离体物，再直接扣
  自身本体 150，绕过南瓜与防御词条；第二次吸取致死也不会让目标胸甲复原。
- 6-1 不自然刷新；6-2、6-3、6-4、6-6、6-7、6-9 进入池，6-5/6-8 暂退用于复习节奏。
  正式 `ResolveWaveZombieType` 所有波次统一每波最多 2 只；第三只返回哨兵、直造不计数，计数只在
  新波/生存轮清零并进入关卡存档。生存候选从 round 12 开始。
- 实体保存湿润余时、过载余时与湿甲小数伤害余量；裂纹阶段从甲生命派生。Board 另保存当前波
  绝缘僵尸计数。旧档缺字段均取中性 0。
