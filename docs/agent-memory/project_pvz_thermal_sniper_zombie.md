## 已定玩法

`ZOMBIE_THERMAL_SNIPER` 为 800 本体、无独立防具、普通僵尸 0.8 倍移速和 50 啃食。玩家成功种植时，本行全部就绪个体各自经过 0.3 秒可中断瞄准，向原位置发射 1800px/s 热脉冲；伤害为触发植物的基础最大生命。每只独立装填 3 秒，正式出生也从完整装填开始；齐射没有行级共享冷却。

子弹可双向飞行，途中命中第一株可受击植物即正常伤害并消失；每发重新按南瓜、普通植物、承载层解析，overlay 不拦截。原触发位置是最远终点，植物消失后剩余子弹到原位置空爆，绝不继续清扫后排。只有命中原触发实体时才绕过即时植物的充能无敌；已经提交的灰烬或其他效果不回滚。模仿者只在最初种下时触发，并按模仿目标基础生命快照，同 ID 变身保持原目标资格。

断臂不影响能力；断头、魅惑永久关闭能力，魅惑和警铃草可取消未离膛射击，已经离膛的子弹不回滚。冻结、黄油和麻痹暂停瞄准/装填，减速延长实际时间。白毛风雪盲不限制热感监听，强风不偏移高速直射弹。

## 投放与表现

8-5 第 3 波独立保底，之后自然生成，每波最多 3 只；8-6 从第 1 波进入自然候选、第 2 波额外保底，每波最多 4 只并与适应头盔组合。两关均不设同时或累计上限。权重/成本 3000、自然最早第 4 波、生存第 17 轮，冒险上限不套入生存。

主体复用普通僵尸时间轴；热感目镜和能源箱用静态 follower，肩炮用独立子 Animator，玩法按逻辑计时提交而不新增帧事件。高可读反馈为红橙锁定线、亮白橙红粗曳光、命中残响和终点空爆。锁定线、枪口粒子与弹体共用真实肩炮口世界锚点；视觉轨迹从炮口线性收束到原植物格中心，碰撞仍按锁定逻辑行判定，避免弹体看似跨行或凭空出现。完整阶段、锁定、伤害与在途轨迹均已入档，加载不重播反馈或种植事件。
