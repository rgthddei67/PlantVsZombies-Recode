# 搬搬藤与植物整组搬运

2026-09-05：主人批准 9-1 奖励搬搬藤（75 阳光、20 秒冷却），点击卡片→来源→合法完整空占地，成功后付费。不能交换，不受中间岩壁阻挡；同格四层与多格 footprint 的承载、扶梯整组瞬移。模仿者不能模仿此工具，已有模仿者仍可搬运。

- `BoardRelocation.cpp` 保存原实体，检查水陆/屋顶承载、冻土、雪穴、岩壁、冰道和弹坑。升级植物移动不要求重建基础株，也不消耗新种配额。
- `Plant::CanBeRelocated()` 拒绝失活、无占格、死亡、蹦极或冰像封存；即时植物和动作中的倭瓜/海草/加农炮/大嘴花在目标自有覆写中收紧。睡眠寒冰菇/毁灭菇可搬，唤醒或引爆阶段不可搬。
- `Zombie::ReleaseRelocatedPlant` 先解除旧啃食，维护被啃计数与走路动画；落点自然重新接触，不提供无敌。
- `CardSlotManager` 只保存未提交来源稳定 ID，取消/读档不重放事务。搬运后正式实体与卡槽存档保留格位、血量、生产/装填进度及卡片冷却。
- 动画使用独立 `CarryVine.reanim`，派生缠绕海草完整藤臂和抓取轨；生成的叶篮通过原面部运动保持连接。水面轨移除，不能删掉承担抓取图的 `Layer 29/32`。无新增帧事件。反馈是无占格无实体 ID 的预览对象，0.65 秒余韵、末 0.2 秒淡出。
- 紧裁切卡图在 `Card::DrawPlantImage` 独立居中：4px 左右内距、8px 顶距、40px 图区高度，场上 gamedata 偏移不参与卡图修正。

验收入口：`smoke_carry_vine.json`（110 步）、`smoke_carry_vine_edges.json`（66 步）与 `autotest/verify_carry_vine.py`。检查真实点击扣费/取消、跨墙、多格承载、扶梯、旧/新啃食、锁定门禁、同 ID 数值与存档，及 9-1 真实奖杯奖励和两帧图鉴动画。所有游戏验证用可见 clang-release。

开凿僵尸与 9-2 正式开放不在本次实现范围。

最终验证：clang-release 编译与 Win7 导入审计通过；上述两项专项及 `smoke_imitater_morph`（63 步）均以可见窗口退出 0，status/run.log 与本轮截图核对通过，状态比较脚本通过。已修正紧裁切卡图居中和抓合分件锚点；资产哈希锁复验通过。植物、僵尸、reanim 技能已同步并通过 quick_validate。参数表见 `docs/superpowers/specs/2026-09-05-carry-vine-design.md`。
