# 经典忧郁菇与紫卡升级

`PLANT_GLOOMSHROOM` 是 6-2 通关奖励；6-1 与 6-3 保持无植物奖励。数值遵循原版：
150 阳光、50 秒卡冷却、300 生命，必须覆盖同格普通层的大喷菇。集中映射
`PlantUpgradeRules` 同时供 Board 种植门禁、卡槽可用性和紫卡绘制使用。

## 升级种植合同

- 正式种植只接受活动、存活、未压扁且未被蹦极锁定的大喷菇；空格和其他植物拒绝。
- `Board::CreatePlant` 先保存基础株睡眠与唤醒剩余时间，把 Cell 普通层切换到新忧郁菇 ID，
  再让旧大喷菇死亡。旧株释放格位时只清自己的 ID，因此不会误删新株；睡莲/花盆承载层和
  南瓜层原样保留。读档直接恢复已升级实体，不要求临时重建大喷菇。
- 白天升级继承睡眠或咖啡豆唤醒进度，夜间清醒株继续清醒；主体生命按新株重置为 300。
- 场上没有可升级大喷菇时紫卡置灰。紫卡底板来自主人提供的 450×70 `seeds.png` 第二个
  50×70 区域，运行时裁切并独立叠加忧郁菇立绘；普通卡底不变。

## 原版攻击与存档

- 每 2 秒开始一轮攻击；不新增动画帧事件。主人转换的 reanim 基础为 12fps，
  `anim_shooting` 以 `14/12` 覆盖恢复原版 14fps，并与当前攻击倍率同比例加速。
- 每轮云雾时间为 0.64/0.92/1.20/1.48 秒，伤害时间为 0.74/1.02/1.30/1.58 秒；
  每段 20 点。范围覆盖自身行及相邻行，横向按植物逻辑中心左右各 1.5 格与僵尸 collider
  重叠判断；跳过魅惑、死亡和不可索敌目标。
- 大喷系伤害修正逐目标结算。加固门只让自身门盾按每段 10 点上限承伤和吸收溢出，
  不会像单向大喷菇那样截断环形攻击的其他目标。
- 存档保存轮次计时、攻击内时间及下一云雾/伤害序号；加载按已跨越时间修正下限，防止旧档
  或缺索引档重放已经结算的段数。通用植物存档继续负责睡眠、唤醒和一次性 Animator 状态。

## 八炮口粒子合同

`GloomCloud.xml` 使用东、南、北、西和四个对角共八个 emitter，每口初始爆发 5 颗。
本引擎会让 `EmitterOffsetX/Y` 生效两次，因此配置值取原版炮口局部偏移的一半；出生点再用
2～8px 圆形散布，Position 轨迹按方向从炮口逐粒子扩散。不要照抄原版不受支持的
`Away/Circle` Field，也不要把偏移与外扩同时写成原版全量，否则会出现粒子离炮口过远或
多颗完全重叠成一点。特效名由文件第一个 emitter 的 `Name=GloomCloud` 注册。
