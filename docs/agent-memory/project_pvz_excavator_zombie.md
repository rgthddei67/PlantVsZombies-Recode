- `ZOMBIE_EXCAVATOR` 追加为52，独立 `ExcavatorZombie` 动画名复用普通僵尸时间轴。800本体、普通战斗、装饰矿灯帽和不可磁吸凿岩机；8游戏秒成功开墙一次、打断后5游戏秒重试。
- `MineGridPlanner.cpp` 比较实际绕行成本与开通后距离，净收益严格为正；已连通矿道允许右行，但施工路径禁止左两列。Board 原子提交永久共享地形与玩家退款，个体保存阶段/墙/施工点/余时，预留索引读档从有效个体重建。
- 取消保持已承诺移动边；啃食期间不计重试，啃食结束才重新计5秒；硬控暂停、减速半速、断臂保留、断头/死亡/魅惑禁用。已成功状态保持损坏工具，读档不重放烟雾或开墙。
- 9-2内部74，200阳光20波；第3波保证一只配基础怪，第4波起六种池。开凿者每波≤1，精英小丑沿用既有每波≤2，不另加本关专用数量限制。9-2通关后图鉴加入该类型。
- 帽挂 `anim_head1`，凿岩机挂保留的 `anim_innerarm2`。命名 follower 必须显式开启可见。断头为单张头帽合成粒子；原断臂/死亡帧事件不变，没有新增帧事件。母图、生成器和 SHA-256 锁位于 `scripts/`。
