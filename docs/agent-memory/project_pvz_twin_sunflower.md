# 经典双子向日葵与生产型紫卡升级

`PLANT_TWINSUNFLOWER` 是 6-3 通关奖励：150 阳光、50 秒卡冷却、300 生命，只能覆盖同格
普通层向日葵。集中 `PlantUpgradeRules` 映射同时驱动 Board 门禁、卡槽可用性与紫卡底板。

## 生产与存档合同

- 普通向日葵继续每 20 游戏秒生产一颗普通阳光；主人指定的强化双子向日葵每 15 秒同时生产
  两颗，即生产周期比普通株短 5 秒。两颗阳光各自随机横向出生，避免完全重叠。
- `SunFlower` 持有共享生产进度、发光状态和存档字段；品种虚接口只返回生产间隔与单轮数量。
  新升级双子以 10 秒初始进度进入 15 秒周期，和普通株一样约 5 秒后发光、再等 0.55 秒结算，
  避免紫卡刚落下立即兑现资源。
- 发光中途保存后，加载恢复同一双子实体和生产状态；剩余发光时间结束只生成一次两颗阳光，
  不提前或重复。没有新增动画帧事件，主人提供的 `anim_idle` 整体循环直接使用。

## 紫卡与资源合同

- 原子升级先把 Cell 普通层改为新双子 ID，再令旧向日葵死亡；花盆承载层和南瓜层不变。
  空格或其他植物拒绝升级；读档直接恢复升级实体，不要求临时创建基础株。
- 卡图、`TwinSunflower.reanim` 与三张独立分件进入权威 `clang-release` 资源；reanim 另复用共享
  向日葵头/双层花瓣和豌豆叶片。AutoTest 合计断言 11 个实际引用贴图键全部可取。
- 紫卡底板继续裁取 `seeds.png` 第二个 50×70 区域；没有合法向日葵时卡片置灰。
