# 雾夜第四大关早期出怪节奏

## 当前阵容

| 关卡 | 内部关卡 | 波数 | 进入时关键植物 | 本关定位 | 完整出怪池 |
|---|---:|---:|---|---|---|
| 4-1 | 28 | 10 | 海蘑菇；尚无路灯花 | 只体验雾视觉，以受击后突然加速的读报制造雾中突发压力 | 普通、路障、读报 |
| 4-2 | 29 | 20 | 已取得路灯花 | 启用雾中索敌限制与雾火经济，再加入高速高耐久旧敌人 | 普通、路障、读报、普通橄榄球 |
| 4-3～4-9 | 30～36 | 未定 | 路灯花 | 等待后续雾关敌人和植物方案，不在本次提前编排 | 当前无权威条目，运行时仍回退普通僵尸 |

原版十关制雾关的 4-1/4-2 分别为 10/20 波，并用小丑盒承担前两关的突发威胁，
4-2 再加入普通橄榄球。本项目尚未实现小丑盒，因此保留原版波数和“先突发、后高速重压”
的角色递进，以普通读报暂代小丑盒；不把未实现枚举或 `weight: 0` 类型写入出怪池。
