原版十关制雾关的 4-1/4-2 分别为 10/20 波，并用小丑盒承担前两关的突发威胁，
4-2 再加入普通橄榄球。2026-07-30 经典小丑已实现，故移除普通读报占位，恢复
“先随机突发、后高速重压”的角色递进。完整行为见
[经典小丑僵尸](project_pvz_jack_in_the_box_zombie.md)。
4-3 在仙人掌已经取得后引入经典气球僵尸，形成第一关正式空中索敌教学；主人随后把
普通橄榄球与普通海豚加入该池。4-4 保留主人当前 25 波、700 初始阳光综合池，并在末位
保留每波最多 1 只的精英小丑。4-5 是 4-4 结算解锁双向射手后的首个可选卡关；在矿工
首次教学池中加入已经于 2-8 学过的加固铁门，让玩家能把反向两连发用于背击绕门，且
仍把矿工放在预览数组末位保持本关主题。4-6 继续保留加固铁门，并引入爆破工头。

C# 原版十关制后期雾关先用普通、路障和跳跳教学，再在下一关加入铁桶与气球；本项目
按九关制及主人指定把该递进落在内部 34/35。4-7 用 20 波四类型精简池首次教学跳跳，
且跳跳禁刷水路，因此水行只承受前三类的泳池变体。4-8 增至 25 波并加入普通海豚和
气球：普通/精英海豚维持水路机制，气球复习仙人掌/三叶草，跳跳仍置于数组末位保持预览主题。
完整行为分别见
[经典气球僵尸](project_pvz_balloon_zombie.md) 与
[经典跳跳僵尸](project_pvz_pogo_zombie.md)。

4-9 增至 30 波，当前 12 类型终局池同时复习舞王、撑杆、冰车、小丑、气球与矿工路线，
并以普通/精英跳跳收尾；精英首次撞到高坚果会消耗缓冲器、造成 600 伤害并继续前跳，
第二次才折杆。精英每波最多 1 只。完整行为见
[精英跳跳僵尸](project_pvz_elite_pogo_zombie.md)。
