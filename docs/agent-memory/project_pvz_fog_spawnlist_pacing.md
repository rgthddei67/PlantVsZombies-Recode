原版十关制雾关的 4-1/4-2 分别为 10/20 波，并用小丑盒承担前两关的突发威胁，
4-2 再加入普通橄榄球。2026-07-30 经典小丑已实现，故移除普通读报占位，恢复
“先随机突发、后高速重压”的角色递进。完整行为见
[经典小丑僵尸](project_pvz_jack_in_the_box_zombie.md)。
4-3 在仙人掌已经取得后引入经典气球僵尸，形成第一关正式空中索敌教学；主人随后把
普通橄榄球与普通海豚加入该池。4-4 保留主人当前 25 波、700 初始阳光综合池，并在末位
保留每波最多 1 只的精英小丑。4-5 是 4-4 结算解锁双向射手后的首个可选卡关；在矿工
首次教学池中加入已经于 2-8 学过的加固铁门，让玩家能把反向两连发用于背击绕门，且
仍把矿工放在预览数组末位保持本关主题。4-6 继续保留加固铁门，并引入爆破工头。完整
行为分别见
[经典气球僵尸](project_pvz_balloon_zombie.md) 与
[精英小丑僵尸](project_pvz_elite_jack_in_the_box_zombie.md)。

  第 21 个图鉴条目。

  逐张确认无越界，4-5 的加固铁门与末位矿工均清楚可辨，`run.log` 无失败或看门狗。
