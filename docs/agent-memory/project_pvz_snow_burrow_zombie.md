# 第八大关潜雪僵尸

## 当前合同（2026-08-28）

- `ZOMBIE_SNOW_BURROW` 在 8-1 首次登场，700 本体生命、50 啃咬、普通步速，无头盔或二类护盾；雪帽和雪铲只承担视觉身份。
- 正式出生立即提交第一次潜雪，向前最多两格；每帧重找路径内最近的战斗顶层植物并在其右侧出雪。自然出雪完成时重新取得该格当前顶层并造成 150 点 `ZOMBIE` 来源伤害，因此南瓜头会独自承伤。
- 本体首次降到 350 或以下时停止啃食并开始 0.8 秒前摇。前摇归零才提交第二次一格潜雪并清除减速；冻结、黄油和麻痹沿基类硬控暂停前摇且不被清除。未提交前摇可中断，取消后等待三游戏秒再重试；提交后的地下移动和冲击不可回滚。
- 地下阶段保留 collider 供地面能力及既有全局入口使用，但 `CanBeTargetedByProjectile(false)` 为 false。`Zombie::ForceSurfaceFromGroundHazard()` 默认 no-op；地刺先按地面危害资格与 collider 结算 20 伤，再向目标请求出雪，听雪草则只请求出雪而不造成伤害。潜雪僵尸接受后取消本次自然冲击；若当时已达半血且第二次潜雪未提交，才写入三秒重试，满血强制出雪不预埋未来冷却。
- `SnowBurrow.reanim` 保持矿工轨道名与既有 66/81/127 帧事件，确定性脚本同步派生蓝灰工装、混合皮肤分件中的红袖口、雪地 `dig*`/`rise*` 合成帧和宽雪铲；红袖口只选择性换色，不污染绿色前臂与手。雪帽无耐久，断头图与雪帽预合成为单粒子；断臂使用同色专属蓝灰残臂与粒子。

## 波次、教学与存档

- 8-1 每波最多一只且敌对活动实体加延迟雪穴事务同时最多一只；全关保证至少一只真正从活动雪穴提交出生。雪穴预警被封只把已提交事务退回右侧，并且不消费全关雪穴保底。
- 8-2 不增加新僵尸；自然风教程计划保持湿度安全，因此不形成雪穴。每波与同时上限均为两只。换波只清每波累计数，不绕过仍存活或待出生实体占用的同时名额。
- Board 保存本波累计数、全关雪穴保底提交标志和延迟事务的教学标志；实体保存 phase、余时、地下起止/目标、目标格、次数、重试、冲击提交与落地状态。读档钳位非法数值，第二次地下阶段永不返还已提交次数。

## 验证入口

- `smoke_snow_burrow_zombie.json`：资源键、地下锁定、灰烬、强制/自然出雪、南瓜顶层、地刺、半血中断与重试、减速清除、硬控暂停、断肢和多阶段快照。
- `smoke_snow_burrow_wave_rules.json`：8-1/8-2 每波与同时上限、换波、快照，以及 8-1 雪穴保底延迟事务。
- 普通内容只需默认 Vulkan 的可见 `clang-release` 路径；没有修改渲染后端时不扩到 `-NoInstance` 或 OpenGL。
