# 第七大关组合威胁与寒潮植物

## 难度方向

主人要求第七大关回应“来点难的”，但难度来自组合、时序、路线和注意力争夺，不靠统一增加生命或攻击。僵尸规模控制为五种重点类型：气象干扰僵尸让本轮已公开寒潮预报失效且清除预报准备；冰裂钻机在冻土蓄力后沿本行释放持续地裂；冰墙工程师建立可持续推进、吸收直线火力并迫使自动投手优先拆墙的冰墙；冰像处刑者锁定冻土区高价值植物并以三次锤击完成处决；雪橇突击队在冻土冲撞后把成员向同行后方和邻行散开。它们应以“干扰预报→让预埋失误”“冰墙牵制投手并掩护蓄力”“雪橇打乱阵线→处决高价值目标”等编组出现。

## 2026-08-26 出怪重排

旧表把大量已学杂兵与旧机制同时塞进第七大关，导致重点类型在正式加权抽取和选卡预览里都被稀释。2026-08-26 的重排不再把“看清新僵尸”误做成低压教学：7-1～7-9 固定为 25～45 波，仍保留原有奖励与首次登场，但每关都由冬季主机制加一组不同的高速、绕后、远程或爆破压力组成。普通僵尸只保留作首波低点数回退，后期不再用路障/铁桶堆数量充数。

红眼巨人以 `weight: 4500` 只进入 7-8/7-9；Board 对冒险正式波次执行每波最多三只的硬上限，计数随关卡快照保存，生存/无尽刻意不消费也不读取该上限。鎏金冰车不进入冬日花园：黄色冰道会继续放大冰瓜等已有减速，反而削弱“让冬季组合主动施压”的目标。

## 植物顺序

奖励顺序固定为 7-1 雪锚果、7-2 融雪投手、7-4 伏霜雷、7-6 警铃草、7-7 炉芯花；7-3、7-5、7-8 和 7-9 无植物奖励。对应的首次可用关为 7-2、7-3、7-5、7-7、7-8。7-6 首次让气象干扰僵尸在玩家没有警铃草时完整生效一次；7-7 首次让玩家只凭警铃草处理冰像处刑者，通关后才获得炉芯花。

完整设计规格见 `docs/superpowers/specs/2026-08-24-winter-area-plants-design.md`。五株寒潮植物与五种重点僵尸现均已实现；跨品种组合继续通过目标拥有的窄接口接入，不在调用方维护具体类型表。各单位真实契约与验证证据见下方主题文件。

## 雪锚果首版契约

`PLANT_SNOWANCHORNUT` 是 7-1 通关奖励，初始调参为 100 阳光、30 秒冷却、3000 生命。它只能在未冻结格提前种植，所在格按 Board 当前真实温度成为冻土时自动进入锚定姿态；融化时退出。当前合同为存活且锚定期间可反复承压，以实际生命作为剩余次数；资格由 Board 冻土、活动态与生命派生，不保存次数状态，旧档 `winterBraceSpent` 字段直接忽略。

植物基类提供通用冬季冲击请求/响应：普通植物返回未拦截；雪锚果仅在当前格冻结、活动且生命大于 0 时原子响应。雪橇碰撞获得“拦截且禁止散射成员”的响应，地裂获得“拦截且后续伤害最多为 1/3”的响应；同一道地裂经过多株雪锚果不会继续叠乘。威胁方仍拥有伤害值、动作提交时机、音画和下车/传播位置；未来实现不得在僵尸侧维护雪锚果类型表。雪锚果不影响冰墙、预报干扰或处决，也不获得通用伤害减免。

## 2026-08-24 融雪投手实现

`PLANT_MELTSNOWPULT` 是 7-2 通关奖励，当前调参为 125 阳光、7.5 秒冷却、300 生命、约 2.86～3.0 秒一次投掷。普通融雪团和盐晶均造成 20 点本体伤害；一次准确寒潮预报的出现沿把每株库存直接补至上限 3，新种下的融雪投手若正处于有效预报也从 3 发开始。气象干扰通过 Board 唯一入口让本轮预报失效，并清空所有已落地植物的库存与尚未出手盐晶；已经离手的盐晶仍独立飞行和入档。

盐晶额外携带 200 点独立冰制层腐蚀值，不得把未用完的腐蚀折算为本体伤害。同行存在冰墙时融雪团和盐晶都优先瞄准墙体：普通团只结算 20 直击，盐晶结算 20 直击＋200 腐蚀；未来冰制护甲僵尸仍通过 `Zombie::ApplyWinterCorrosion` 的中性虚接口接入。Board 的 `coldWaveForecastDisrupted` 与融雪投手库存、蓄力状态、空中盐晶均进入正式关卡快照。

## 2026-08-24 冰墙工程师实现

`ZOMBIE_ICE_WALL_ENGINEER` 为 800 本体＋370 安全帽，复用路障死亡/啃食时间轴而不新增帧事件。完全进入草坪且已有冻土后立即部署 600 生命未完成墙并停步施工 4 秒；墙立刻挡平射，施工受冻结、黄油与麻痹自然暂停，施工墙被拆、断头、死亡和魅惑会使半墙碎裂并消费能力。完工在同一对象上硬化至 1800 生命，之后工程师死亡不拆墙。

冰墙每游戏秒向房屋推进 14px，在同行最近植物 collider 右侧保留间隙停住；`THAWING` 或高于冻结温度时每秒融化 120。同行平射弹在僵尸碰撞前命中墙体；卷心菜、玉米/黄油、西瓜/冰瓜及融雪团/盐晶自动投手在同排有墙时优先锁墙，伤害与状态不穿透到墙后或邻行僵尸。普通手动/测试抛射仍可越墙，玉米炮不受影响；火焰伤害两倍，盐晶额外结算 200 独立腐蚀。工程师每正式波最多一只，接入 7-3、7-5、7-8、7-9；7-4、7-6/7-7 分别给钻机、气象干扰和处刑者保留清晰教学空间。

安全帽、橙黄反光背带、工具带和双箍制冰罐随既有身体/领带/路障轨道运动；墙体三档贴图与四套粒子由 `scripts/generate_ice_wall_engineer_assets.ps1` 确定性生成并锁定 SHA-256。施工阶段、计时、目标墙位、能力消费、墙体位置/生命/融化余量/完成态/施工者 ID 及每波计数均进入正式快照。`clang-release` 全量 LTO、378 项 Win7 导入、`SaveSchemaTests`、`SaveMigrationTests` 通过；工程师专项扩至 129 条命令并在默认 Vulkan 与 `-NoInstance` 可见路径通过，出怪表、融雪投手及冬日花园父回归同次 Release 通过。

## 2026-08-25 伏霜雷实现

`PLANT_FROSTMINE` 是 7-4 通关奖励，初始调参为 50 阳光、30 秒冷却、300 生命。准确寒潮预报预测其所在格将冻结时从 `DORMANT` 进入 `CALIBRATED`；真实冻土到达后提交为 `ARMED`。预报干扰只把尚未兑现的校准退回休眠，已经武装的埋伏不随干扰、回暖或下一轮预报撤销，并在存档往返后保持。武装态不可啃食，只选择碰撞范围内活动、未魅惑且可受地面机关影响的目标；同帧有多个目标时按稳定僵尸 ID 取最小值，飞行目标不会踩雷。

爆裂先打断目标尚未提交的特殊动作，再结算 1000 点目标自有冰制层腐蚀和 600 点植物来源常规伤害，腐蚀不得溢出本体。该顺序可完整破坏冰裂钻机 900 点钻机层，把未提交蓄力退回移动且保留重试资格，不产生地裂；普通杂兵会被直接炸倒。三阶段均使用独立完整立绘而非换色，武装态明显埋入冰雪；卡图、碎冰与霜环粒子均有独立资源，可由 `scripts/generate_frost_mine_assets.ps1` 从锁定概念源复现。完整合同与最终 Release 证据见 `project_pvz_frost_mine.md`。
