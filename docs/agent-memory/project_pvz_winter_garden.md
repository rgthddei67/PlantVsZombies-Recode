# 第七大关冬日花园、寒潮与冻融线

## 关卡与地图

冒险 55～63 显示为 7-1～7-9，统一使用 `Background::WINTER_GARDEN`、5 行 × 9 列平地和白天音乐。`AdventureProgression::LAST_ADVENTURE_LEVEL` 为 63；寒潮植物奖励已接入 7-1 雪锚果、7-2 融雪投手、7-4 伏霜雷、7-6 警铃草、7-7 炉芯花，其余关卡不发植物。五株寒潮植物与五种重点僵尸现均已实现，组合契约见 `project_pvz_winter_area_content_plan.md`。

雪锚果的锚定资格直接读取 `Board::IsCellFrozen`，不保存温度或重复保存冻土范围；实体只保存一生一次的消费结果。其普通/锚定材质切换与冻融线同源，因此寒潮存档先恢复 Board 后即可静默重建正确外观。完整能力、未来雪橇/地裂所有权边界和专项证据见 `project_pvz_winter_area_content_plan.md`。

正式背景资源为 `resources/image/background_wintergarden.png`，以原版白天草坪构图和当前 1100×600 网格为基准改造：保留房屋、五行草坪和 80×100 逻辑格对齐，在屋顶、边缘灌木、石板与草坪外围铺积雪，并让右侧棕色裸地也被不规则积雪覆盖。资源键为 `IMAGE_BACKGROUND_WINTERGARDEN`，需经 `resources.xml` 注册和 AutoTest 加载断言闭环。

温室实体遮挡视觉第 1、2 行的防线入口，因此冬日花园只在逻辑行 2～4 创建三辆小推车。`Board::CanHaveMowerInRow()` 是初始化、显式创建和 `CreateMowerWithID()` 旧档恢复的统一门禁；不能只隐藏绘制，否则旧档会恢复碰撞与触发实体。

## 寒潮温度与冻融线

温度是独立于 `RainIntensity` 的 Board-owned 环境维度，且只由寒潮状态机控制。`CALM` 保持 +6°C 35～60 秒；下一轮在进入 `CALM` 时一次性锁定强度、最低温、三段总时长和冻融线轮廓：弱/普通/强寒潮权重为 35%/45%/20%，最低温基准分别为 -5/-8/-11°C 并各自加入整数 ±1°C 波动；降温分别为 21～25/18～22/15～19 秒，低温维持为 35～50/45～65/55～75 秒，回暖为 24～30/28～36/34～44 秒。强度越大平均降温越快，但每轮全部结果锁定后不再重抽。

7-8（内部 62）与 7-9（内部 63）首次进入 `GAME` 时不走上述首次随机抽取：先固定 `CALM` +6°C 12 游戏秒，随后锁定一轮 -12°C 强寒潮，依次为 15 秒降温、50 秒极寒维持、30 秒回暖（寒潮本体共 95 秒）。12 秒自然落在 20 秒预报窗口内，因此开局立即显示准确强寒潮预报；戴夫对话、选卡和暂停都不消耗该计时。7-8/7-9 分别固定霜线轮廓 1/2，避免脚本事件额外消耗随机数。回暖结束后照常进入 35～60 秒 `CALM`，再调用原有随机 `RollNextColdWave()`。

阶段、余时、当前温度、强度、目标温度、降温/维持/回暖总时长、冻融线轮廓、初始化标志和 7-8/7-9 的 `openingColdWavePlanInitialized` 标志全部进入关卡快照。旧档缺开幕标志时迁移为未消费，恢复后的 `StartGame` 会重建 +6°C 的 12 秒倒计时并锁定固定计划；旧档缺随机计划字段时仍以此前的强寒潮 -12°C、20 秒降温、57.5 秒维持、32 秒回暖和轮廓 0 完成当前一轮，下一轮再进入新随机规则。

`CALM` 余时进入最后 20 游戏秒时，天气面板增加一行寒潮准确预报，并显示已锁定的弱/普通/强寒潮及本轮最低温；开始降温后同一位置显示对应强度、降温/低温持续/回暖实况及阶段余时。文案直接读取 Board 同一阶段、计时和锁定计划 getter，不复制未来结果，也不进入允许误报的雨势候选、pending 或预报失败卡片。

0°C 起从僵尸侧向房屋推进冻融线：0°C 冻最右 1 列，此后每降低 2°C 多冻 1 列，-12°C 达到 6 列上限，因此 1～3 列永久安全、4～9 列为最大冻土区。冻土范围只读取当前实际温度，不直接按强度枚举；因此不同强度和同强度的 ±1°C 波动会自然得到不同最大范围。逻辑只按整列查询，视觉可以跨过边界少量出霜。冻土拒绝新的正式种植和直接正式创建；已经存在的植物保留，读档/初始化/预览路径不因恢复顺序被误删。

温度不再作为天气栏第三行短暂显示。`GameScene` 在左侧常驻绘制独立温度计：卡通木框贴图使用真实透明管腔，代码在后方绘制暖色/冰蓝液柱，并从 Board getter 读取 +6°C 上限、0°C 结冰线、-12°C 下限与归一化液柱比例；当前温度单独显示在仪表下方。球泡程序圆扩大到木框内缘下并使用 64 段，最终可见轮廓由贴图透明内缘平滑裁切，避免低段数三角扇的折面边缘。

冻土主体使用 `IMAGE_WINTER_FROST_OVERLAY_V2`：一张透明、连续、无网格的雪斑/霜枝/冰晶纹理按温度派生的浮点视觉列数连续伸缩，左缘带 24px 不规则溢出；+2°C 到 0°C 先从 0 平滑推进至 1 列，之后每降 2°C 连续多推进 1 列，各整数交点与正式冻结格线一致，回暖反向退去。视觉宽度不入档且不参与种植资格；alpha 在首列以内由 0 平滑到 75，再随覆盖范围升至 245。每轮寒潮从主体原轮廓与两张独立霜枝变体中锁定一个编号（0～2）并入档；变体 1/2 是 ImageGen 生成的纯黑底霜枝贴图，以加色混合叠在主体左缘，黑底不覆盖草坪，前缘会换形但不会逐帧跳动。不要恢复逐格蓝色矩形或格线。ImageGen 候选若烘入棋盘格必须拒绝接入；纯黑加色素材还须检查右半区与四角接近黑色。游戏内须检查三种轮廓、半列/列间过渡、1 列浅冻和 6 列重冻截图。

两张霜枝的可复用 ImageGen 提示词共用约束为：1536×1024 单层加色覆盖素材，整幅纯黑背景，不要透明棋盘、文字、草坪或外框；只在左侧约 35%～40% 画手绘浅冰白/冷青霜枝、细冰晶与柔光，必须从左边缘长入，右侧保持纯黑，并贴近原版 PvZ 的 2D 手绘低细节美术。变体 1 指定“上部双冰舌、中段留空、下部细分叉”，变体 2 指定“中段蛇形主叉、上下错位小分叉”，以免两图只是镜像。

## 降雪与台风

低于或等于 0°C 时，同一 `RainIntensity` 只把降水表现派生为 `SnowLight/SnowMedium/SnowHeavy`；雨势阶段、持续时间、植物/僵尸倍率和导演权重保持不变。跨过 0°C 时先停止旧降水效果，再用当前雨势重建雨或雪，避免叠加。雪天显式关闭循环雨声、地面雨滴水花和普通大雨闪电/雷声；雪粒子必须覆盖整个 600px 战场高度，不能只聚在屏幕上沿。

冬日花园 `SupportsTyphoon()` 恒为 false。pending 预抽/消费、开始、恢复、逐帧更新、阵风、测试强制入口和概率投影都服从该门禁；不是仅把新台风概率设为 0。进入地图或恢复快照时不得留下活动或待生效台风。
