# 冰墙工程师与独立冰墙

## 身份与投放

`ZOMBIE_ICE_WALL_ENGINEER` 数值为 800 本体、370 安全帽、权重 2200、第五波起、生存第 11 轮起，每个正式波次最多生成一只。冒险接入 7-3、7-5、7-8、7-9；7-1/7-2 不提前泄露，7-4、7-6/7-7 分别为钻机、气象干扰与处刑者教学留白。

工程师复用 `ConeZombie.reanim` 的完整死亡、啃食和断肢时间轴，没有新增动画帧事件。初始及三档破帽都通过 `GetConeTextureKey()` 换图；身体轨道承载冰蓝工装、橙黄反光背带、工具袋和双箍制冰罐，领带轨道改为悬挂冰凿。可复现资产生成器为 `scripts/generate_ice_wall_engineer_assets.ps1`，输出哈希在脚本内锁定。

## 施工合同

工程师 collider 完全进入草坪且场上已有冻土后立即进入 `BUILDING`，不再长途走到霜线。施工第一帧在其前方原子创建 600 生命未完成墙，立刻挡住同行平射；工程师停步 4 游戏秒并周期发射 `IceWallBuild` 碎冰。冻结、黄油和麻痹由基类早退自然暂停计时；施工墙被摧毁、断头、死亡、魅惑、冻土消失或全场已有其他墙时永久消费本次能力，不会在旧墙破裂后补建。

施工期通过通用 `GetInterruptibleSpecialActionRemaining` 暴露剩余时间；警铃草等外部工具调用
`InterruptUncommittedSpecialAction` 时原子撤销半墙但不消费能力，工程师恢复移动并可在资格仍满足时
从完整 4 秒重新开工。该可重试路径与上述自然终止的永久消费严格分开，完工墙不再进入中断接口。

完工在同一对象上原子硬化：清除 builderID、恢复至 1800 生命并开始推进，随后工程师恢复行走。施工期墙保存施工者 ID，施工者死亡会拆墙；只有硬化后工程师与墙生命完全独立，工程师死亡、断头或魅惑不拆除完工墙。

## 冰墙合同

`IceWall` 是由 `GameObjectManager` 持有的独立 `GameObject`，Board 只保存弱引用。施工态 600 生命、固定重损外观且不移动；硬化态 1800 生命、半宽 34px，以 14px/游戏秒向房屋移动。同行植物存在时在最近植物 collider 右缘外保留 8px 间隙停下，无植物时越过房屋侧回收。`THAWING` 或环境温度高于冻结阈值时以 120 生命/游戏秒融化，保留小数伤害余量。

所有同行非抛射、非玉米炮弹道在 `CollisionSystem` 僵尸回调之前以运动线段检查墙体，命中后不再伤后方僵尸；未显式锁墙的测试抛射和手动玉米炮仍越墙。卷心菜、玉米/黄油、西瓜/冰瓜、融雪团/盐晶这五个自动投手家族在同排有墙时即使没有僵尸也会起手，并在发射帧优先锁定墙体；锁墙弹忽略沿途僵尸，落点只对仍在允许移动余量内的同行墙结算，原墙消失时落空而不改投。锁定意图进入在途弹道存档并由对象池复位。

火球和毒火球对墙两倍。普通投手按自身直击伤害结算：卷心菜 40、玉米粒 20、黄油 40、西瓜 120、冰瓜 100、融雪团 20；黄油不把墙后僵尸定身，西瓜/冰瓜只播放墙上命中反馈，不向墙后或邻行结算溅射/减速。盐晶另在 20 直击后施加 200 独立腐蚀，腐蚀不溢出到任何僵尸。

## 存档与验证

工程师额外保存施工阶段、剩余时间、目标墙中心、粒子节拍和能力是否消费；读档会修复断头、魅惑或零剩余时间的非法施工态。Board 保存每波工程师计数；墙保存行、连续中心 X、当前/最大生命、融化小数余量、完成态和施工者 ID。旧档缺施工墙字段时按既有完整墙恢复，缺整个墙字段时保持空墙。

`smoke_ice_wall_engineer.json` 在 `clang-release` 默认 Vulkan 与 `-NoInstance` 可见路径均执行 129 条命令至 command 128、exit 0、`status=passed`；覆盖资源键、数值、完全进场且距霜线仍超过 50px 时开工、600 生命施工墙立即挡豌豆、施工者死亡拆墙、施工者麻痹时墙碎仍立即收口、施工快照、硬化回满、完工后工程师死亡留墙、抛射越墙、火焰双倍、盐晶 20＋200、回暖融化、每波上限和中心 X=519 的植物停点。两个渲染路径的施工截图均目验墙体前置且工程师装饰完整可见。`smoke_ice_wall_engineer_spawnlists.json` 覆盖 7-1～7-9 分布；融雪投手和冬日花园父回归同次 Release 通过。全量 LTO 编译、378 项 Win7 导入、`SaveSchemaTests` 与 `SaveMigrationTests` 均通过。
