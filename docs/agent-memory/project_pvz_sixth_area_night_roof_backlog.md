# 第六大关黑夜屋顶延期设计

## 当前状态（2026-08-04）

- 主人计划在原版第五大关之后新增完整第六大关，继续使用 `NIGHT_ROOF`，并加入原版没有的
  植物、僵尸及部分原版紫卡。
- 本主题只记录候选方向；第五大关完成前不实现、不锁定数值，也没有构建或 AutoTest 证据。
- 昼夜屋顶因共用斜坡几何而沿用同一套较轻“坡面径流”，见 `project_pvz_roof_runoff.md`；第六大关
  未来在径流之上再叠加独立雷荷核心系统，两套机制并存而非互相替换。

## 候选核心：雷荷与导电瓦路

- `NightRoofCharge` 由 `Board` 持有，作为与 `RainIntensity`、既有坡面径流并行的屋顶电荷，而不是
  新增雨势档位或替换冲刷。径流继续由斜坡与降雨触发，电荷只负责导电瓦路及放电玩法。
  晴夜缓慢漏电，雨势提高积累速度，现有大雨闪电提供一次增量；台风只在单一交互点改变泄放方向。
- 电荷达到阈值后锁定一条导电瓦路并提前数秒预警，再沿平台到屋檐放电。锁定路线、倒计时和
  会影响未来结算的状态进入关卡存档；逐格发光等可派生视觉不保存。
- 基础放电暂定为双刃效果：命中僵尸时造成伤害或短定身；普通花盆替上层植物绝缘，但上层植物
  短暂停止行动。优先使用短时行动惩罚，不直接扣花盆生命，避免底层死亡后留下非法上层植物。
- 候选新植物包括前期的接地菇，以及把花盆升级为本行/本列避雷与反击节点的“避雷花盆”紫卡。
  若实现花盆原位升级，必须先定义上层植物保留、铲除优先级、存档重建和台风整组搬运。
- 适合在第六大关恢复的原版紫卡候选为双子向日葵、忧郁菇、冰瓜和玉米加农炮。钢地刺与当前
  地刺系禁止屋顶的规则冲突，除非另行修改承载与地形契约。
- 候选敌人包括能把放电路线引向自身所在行并吸收雷击强化的天线僵尸，以及免疫屋顶放电的
  绝缘僵尸。具体关卡教学、复习和综合顺序等第五大关完成后再设计。

## 候选新僵尸：全场血量处决

### 主人转述的玩家提议

- 行为近似小丑僵尸：技能释放时施法者立刻死亡。
- 释放瞬间令全场当前总血量小于等于施法者的植物与僵尸全部死亡。
- 植物总血量包含同格普通植物与南瓜头；屋顶花盆完全豁免，也不计入比较值。
- 僵尸总血量包含本体、一类防具和二类防具的当前剩余生命。

### 当前推荐语义

1. 比较施法者**释放瞬间的当前总血量**，不是最大生命；必须在施法者自杀前保存处决线。
   玩家在读条期间削弱或击杀它，便能降低处决线或取消技能，这是全场效果必要的反制窗口。
2. 所有资格必须从同一帧的冻结快照计算，再统一执行死亡。禁止边遍历边杀：若先杀南瓜再判断
   内层植物，会把本应作为一个组合的血量拆开并产生顺序依赖。
3. 植物按逻辑格归并：`normal + pumpkin` 的活动当前生命相加；组合符合条件时两者一起死亡，
   `PLANT_FLOWERPOT` 保留。只有花盆的格子不成为目标。
4. 僵尸以 `max(0, body) + max(0, helm) + max(0, shield)` 比较；符合条件时直接走死亡入口，
   防具不再逐层扣除。已经死亡、正在回收或非活动实体不参与。
5. 被处决的另一只同类僵尸不会连锁释放技能；技能只能由自身正式释放节点结算一次。
6. 全场范围必须给出明显且足够长的声画预警，并实时表达当前处决线或即将被处决的对象；
   预警时间与僵尸最终锁定动作分开，避免它长时间停止行动成为固定靶。

### 已确认的雷荷联动与反制节奏

- 主人于 2026-08-04 接受“长天气预警、短最终锁定”的方案。雷荷达到约 75% 时，由 `Board`
  从当时已经在场的同类中锁定一只本次劫持者并开始约 6～8 游戏秒的全局预警；候选在此后才
  生成的同类不能临时抢占本次放电。
- 全局预警期间，劫持者继续正常移动、啃食和受伤，仅增加明确的引雷标记。放电前约
  0.9～1.2 游戏秒才进入最终锁定，停止移动和啃食但保持可受伤；具体数值是未来首轮原型起点，
  仍需在第六大关开发时实测调节。
- 雷击真正落下前杀死劫持者会取消全场处决；倭瓜、樱桃炸弹等灰烬或高爆发手段保持有效硬解，
  不增加灰烬免疫、锁血或“死亡后仍释放弱化处决”等隐藏反制惩罚。
- 劫持者被提前杀死不会清空 `NightRoofCharge`，原定普通放电按既有剩余时序和导电瓦路继续；
  同一次放电的劫持资格不转移给其他同类。每次放电最多一只能够劫持。
- 平衡主要由卡位、阳光、花盆和灰烬冷却形成的资源税，以及高波次成本、关键波最多一只和
  同波其他压力负责；若它过弱，优先调整出现时机、同波组合与预警起点，不缩短到不可反应，
  也不靠抬高生命来变相抬高处决线。
- 雷荷、预警、锁定劫持者 ID 和普通放电未来状态归 `Board`；僵尸只保存自己的最终锁定阶段、
  剩余时间与已结算标志。读档不得重新挑选劫持者、重置雷荷、转移资格或重复释放。

### 设计价值与主要风险

- 优点：规则一句话即可理解；当前生命让集火施法者成为自然反制；南瓜提供组合生命保护；
  花盆豁免避免一次技能摧毁屋顶基础设施。全阵营弱单位一并死亡还能成为僵尸方的献祭成本。
- 风险：若基础生命过高，它会直接清空绝大多数 300 生命植物；若生存模式生命倍率同时放大
  处决线，后期可能失控。正式定数值前应优先让基础处决线落在“普通植物会死、坚果和完整南瓜
  组合会活、普通僵尸会死而常见防具僵尸会活”的可读区间，并评估是否需要处决线上限或限制出场。
- 风险：全场击杀同阵营僵尸可能显著帮助玩家清波。它应使用较高波次成本、每波上限，或与处决线
  以上的高耐久护卫组合；不能像普通小丑一样大量随机出现。

### 实现前必须由主人定案

- “全场”是否无视阵营；魅惑后是仍无差别处决、改为只杀敌对阵营，还是直接失去技能。
- 特殊额外生命层（例如气球）是否计入僵尸总血量；当前提议只明确本体、头盔和二类盾。
- 植物 `under/overlay` 中除花盆外的层如何处理；第六大关屋顶主路径没有睡莲，但通用直造测试
  仍需明确一致语义。
- 最终锁定的精确时长、释放帧号、断肢断头和死亡表现；任何动画帧事件必须等主人查看最终
  reanim 后给出帧号。
- 基础生命、出怪成本、关键波投放表和生存模式处决线上限；雷荷联动方向已经确认，但所有数值
  仍在第五大关完成后再定。

## 未来实现边界

- 该僵尸属于复杂状态机，正式开发前走完整 brainstorm → spec → writing plan。
- 全场结算应由一个语义明确的 Board/僵尸入口负责，复制植物与僵尸实体 ID 后，以冻结快照产生
  目标集合，再执行施法者自杀和批量死亡；不要在每种植物或僵尸内复制比较规则。
- 阶段、剩余读条和已结算标志进入实体存档；读档只继续既有阶段，不重播一次性预警或重复结算。
- AutoTest 至少覆盖等于边界、差一血、南瓜组合、花盆豁免、三层僵尸生命、同类不连锁、
  读条中削血/击杀、魅惑语义、快照往返、暂停与倍速。
