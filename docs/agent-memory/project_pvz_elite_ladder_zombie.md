# 精英扶梯僵尸

日期：2026-08-06

## 当前契约

- `ZOMBIE_ELITE_LADDER` 继承 `LadderZombie`，复用经典 85/194 啃食与 131 死亡帧事件，本次没有新增帧事件。
- 初始 650 本体生命、500 扶梯护盾；生存 `weight=2600`、`appearWave=15`、`survivalRound=15`。正式 `ResolveWaveZombieType` 每波最多生成 1 只，计数入档、换波和生存轮清时归零；直造夹具不消费限额。
- 出场 5 个游戏秒后一次性扫描同行活动、非预览、非压扁植物的当前生命。计时独立于冻结/啃食/放梯，但服从暂停和全局 timeScale；扫描结果和剩余时间完整入档，读档不重复结算。
- 总生命严格 `>6000` 获得无限搭梯；成功放置不消耗携梯，但破盾/磁吸仍移除能力载体。严格 `<6000` 时自身整体动画倍率为 2；恰好 6000 不触发任一血量分支。
- 投手严格多于射手时当前/最大本体生命 +500；严格少于时当前/最大扶梯生命 ×2；数量相等不触发。投手显式为卷心菜、玉米、西瓜和冰瓜，射手使用精英实现中的主动远程植物白名单。

## 动态外观与粒子

- 深蓝工装始终保留；携梯初始是普通银灰。无限分支命中后，携带扶梯按当前 `ArmorBrokenState` 原位切到安全金 `base/damage1/damage2`，不恢复护盾生命、不重置破损档位；Load 恢复能力字段后重新应用同一材质入口。
- `LadderStyle::CLASSIC/ELITE` 属于 Board 共享扶梯。样式决定已放置对象绘制与磁力菇离体贴图，并进入 `ladders[].style`；旧档缺 style 时恢复经典。精英只有获得无限能力后才放置金梯，普通分支放置银灰梯并消费。
- 携梯贴图、已放置梯、磁吸离体物和破盾粒子都由当前无限状态选择；未无限使用 `ZombieLadder`，无限使用 `ZombieEliteLadder`。
- 四项扫描反馈：无限为 10 架缩小金梯环，2 倍动画为青蓝速度流线，+500 本体为橙红星芒/脉冲，2 倍扶梯为亮黄护盾环/星光。同次扫描同时显示命中的血量和数量分支，均在一秒内回收且不入存档。
- 换色脚本 `scripts/recolor_elite_ladder.ps1` 从经典资源生成 13 张精英部件图和 `EliteLadder.reanim`，14 个输出用 SHA-256 锁定。`BODY2` 必须独立生成；仅有 reanim 引用而无文件会在启动时产生缺图错误。
